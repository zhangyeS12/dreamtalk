## 实现

- 前批 HTTP 类型化组装、命令拆分、adapter 公共支撑、更新包与数据库保护模块拆分随本版交付。发现并修复未配置模型时可选回复生成服务被错误当作必需接线的问题；保留真实必需服务漏接的启动拒绝。
- HTTP 响应按业务拆至 wire_contracts，实际请求模型通过 AST 读取，生成客户端类型／守卫。客户端业务 JSON 结果全部校验，写请求绑定同源模型；二进制、multipart、SSE 传输及原生宿主控制协议保留各自边界。契约回归约束响应模型接线及扩展字段／整数保留。
- Pyright standard 从19个文件扩到61个文件，含 HTTP 全目录及 LLM 执行／记账、存档协调、主动联系持久化和生产组装，不设错误忽略基线；不是全仓类型化。
- UI 导航、草稿、目录、身份、事件、世界时钟及操作反馈各有状态所有者；宿主 presence 生命周期单独管理。补充迟到读结果／失败隔离、事件草稿身份隔离、重复操作及编辑倍速保护回归。
- 随版包含此前已确认的双人联系规则和文档去重；双人联系实际节奏／模型表达仍待用户反馈，不自动触发。
