# dreamtalk 0.1.84 · 大资料与后台联系优化

- 修复离线联系因私聊角色超过16位或角色资料过长而停止的问题：候选分批轮选，长资料按本次输入预算提取参考，原角色卡内容保留。
- 大世界书改为分页编辑，跨页修改统一预览后保存，未加载的条目也会保留。
- 优化活动、在线主动联系与公共背景的输入准备，单条异常资料不会拖停其他候选；保留权限、来源、费用及失败任务不自动重试的规则。
- 修复大量会话导致未读读取失败、角色版本较多时追踪失败，以及后台只扫描前一批世界配置的问题。
- 区分资料准备提示和真正的生成失败，修复资料后可在下次符合条件时继续准备，不补发旧失败任务。

提供完整 Windows x64 安装包、便携 ZIP 及原应用内更新频道。沿用原应用标识、数据位置、更新公钥和五位置存档，不需要清空数据。

仍为预发布体验版。隔离回归、CI 和 build-only 打包不等于真实升级、存档恢复或模型效果已验收；实际应用内升级仍由用户确认。更新签名不等于 Windows 发布者证书，配音与视觉模型权重需要另行准备。
