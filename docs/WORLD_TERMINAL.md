# 世界内的通信终端

2026-10-04，Desktop **0.1.36**。用户批准优化进入世界后的界面，要求有材质、层级和空间关系，减少方块堆叠。此切片覆盖聊天、通讯录、设置和个人身份；书架和三维启动保持已有设计。

## 视觉结构

深蓝灰外壳承载品牌、当前世界和四个固定入口；月白阅读面承载正文；偏暖纸面的会话目录和设置目录形成轻微材质差异。银蓝色用于选择和主操作，Logo的淡金仅用于导航细节。界面色值使用OKLCH，兼容原组件的颜色变量；错误、未经历、已经历、跳过继续保留独立语义。

每个页面只有一个连续的工作面。选中行以背景区分，角色卡阅读页采用大头像、姓名、阵营、操作与正文的档案结构；段落通过留白和排版分组，不重复嵌套卡片。正文约15px，辅助说明约13px，限制长段落行宽。CSS只作用于`.world-workspace`，不污染书架、启动和开发检查器。

## 实际接线

- 聊天目录、会话标题、角色消息和流式草稿复用已上传头像；没有图片时显示姓名首字。`useChatAvatars`按稳定角色卡根ID读取已有本地资产，当前目录共享一次元数据读取和去重图片读取，不逐消息请求、不调用模型。离开或依赖改变会取消请求并释放Object URL；不同世界和新一轮读取不能使用已释放的旧URL。
- 私聊和群聊标题复用`ConversationHeading`；刷新记录直接可见，长期记忆、会话摘要、聊天回忆收进原生`details`。键盘可展开，Escape收起并返回焦点；选择工具后收起，再开启原有面板。没有引入浮层或额外UI框架。
- 消息按显示日期添加分隔；离线消息使用既有剧情发送时间，实际生成时间仍在“时间详情”。数据顺序不改变，原`data-message-id`、分页、已读和滚动锚点仍保留。
- 通讯录的姓名与大头像在档案页首，打开会话入口紧邻；头像上传/移除放在“编辑角色头像”中。角色卡编辑/导入、阵营编辑和真实三维关系网继续使用原实现。
- 设置保留七类目录与已保存摘要；只改变层级、间距和表单视觉。应用/当前世界范围、费用授权、失败反馈、保存/刷新及草稿语义不变。
- “我”以真实已保存通用称呼显示首字和署名，通用资料、绑定身份和世界专属描述组成连续的个人档案。不会根据未保存输入生成额外身份事实。
- 世界事件保留聊天获知和公共动态两部分；聊天获知按真实获知日期分组，引用、来源、世界时间、变更与批注仍可查看。公共动态仍由用户手动标记经历；不把隐藏活动变成监控面板。
- 窄窗口保留聊天返回入口，通讯录的阵营/关系网可直接进入，设置目录横向滚动；`hidden`优先于布局样式，减少动态效果关闭非必要过渡。

## 边界与复用

没有新增玩法、持久化、迁移、费用策略或后台开关，也没有换技术栈。没有捏造最近消息、角色状态或未读数量；现有会话目录没有最近正文，因此只显示真实名称、会话种类和未读提示。没有新运行依赖。成熟方案与许可评估见[复用记录](research/2026-10-04-world-terminal-reuse.md)。

## 验收入口

源码检查与构建结果以[交接第6节](../HANDOFF.md#6-交付与证据)为准，实际视觉与交互仍由用户验收：

1. 打开已有私聊/群聊，确认头像、日期分隔、流式、分页、已读红点、发送与失败恢复正常；工具可用鼠标和键盘操作。
2. 切换通讯录，查看档案、上传头像，回到聊天观察更新；阵营长名称和三维图直接操作仍可用。
3. 在设置和“我”编辑后切换入口，确认草稿、费用确认和错误提示完整保留。
4. 缩窄窗口，确认返回按钮、工具、输入框、阵营和设置目录没有被遮挡；检查高缩放/减少动态效果。

不得把构建成功记为上述运行验收通过。
