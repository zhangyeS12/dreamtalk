# dreamtalk 0.1.78 · 存档保护与媒体可靠性更新

本版增加整份本机存档备份、恢复和升级保护，并修复云端图片分析密钥与图库说明问题。提供完整 Windows x64 安装包和便携版，仍为预发布体验版。

- 书架和设置新增“数据与备份”：自动／手动备份、选择备份磁盘、导出与导入 `.dreamsave`，以及恢复前保留当前数据。备份包括世界、聊天和关联素材；不包含 Windows 安全凭据中的密钥正文或本地模型权重。
- 新版卸载器保留用户数据，清空数据移至应用内独立确认。安装／升级替换文件前先备份；未完成备份时停止安装。启动核对实际存档位置，异常时进入恢复入口；未完成更新保留回退材料。
- 保留应用内更新入口，补充缺失程序清单时的受控修复升级路径；未知旧目录不自动清理，恢复不自动重发聊天、配音或后台模型任务。
- 修复云端图片密钥首次保存与读取失败：统一引用格式，并在保存及使用时核验世界归属。保存设置不会调用模型验证密钥。
- 每个图库条目的说明独立，修改一个角色的说明不会串改其他图库。旧说明保留，聊天历史保留发送时快照；图片分析不会覆盖分析期间另行编辑的说明。
- 联网图片与聊天消息一起保存，取消或未提交时不单独留下图片；旧网络孤立素材按引用保守回收，保留用户导入和历史图片。
- 搜索前增加关键词保守过滤，拦截后保留文字、不追加搜索。群聊增加不含正文的本地调用及耗时诊断，原有 Token 预算、选人和发送频率保持。

升级前请从托盘选择“退出并停止后台运行”，再使用应用内更新或安装完整新版。便携版需完整解压；不要只复制 EXE，不要用旧程序打开已升级的同一存档。新版无法追溯替换已分发的旧卸载器；旧版若仍出现“删除应用程序数据”，不要选择。

存档保护降低升级或误操作的风险，不代表能覆盖硬盘损坏、磁盘空间不足或所有中断场景。建议在应用中另存一份备份到其他磁盘。真实备份、恢复、0052迁移、跨版安装／更新及回退尚待用户验收，工程端没有运行这些场景。

本地配音此前已有具体用户确认；官方免费云端最新版和付费配音API仍待确认。本版云端图片分析、说明隔离、联网取消／回收、关键词过滤误判与群聊性能仍需实际使用确认。过滤无法识别所有私人信息。

本次仅做源码、格式／类型、必要编译及静态发布载荷核对，没有运行自动测试、应用、安装器、模型或真实存档迁移。配音与视觉模型环境、权重独立，不在下载包中。

SignPath 免费签名申请已提交，正在等待回复，尚未获批；当前下载仍无 Windows 发布者证书。现有 Tauri 更新签名用于验证更新完整性。
