# dreamtalk 0.1.91 · 上下文读取与后台诊断优化

## 本次更新

- 保留角色卡原始快照，并为模型提出的动态词条保存逐字引用与置信度，时间线可回看建议依据。
- 私聊回复准备按 `world_id + conversation_id` 精确读取会话，当前角色卡只追踪目标根导入的有效版本链。
- Director、在线主动联系和离线联系增加脱敏结构化后台诊断，记录固定阶段、任务 ID、世界 ID、代际和失败码，不记录聊天正文、提示词、模型回复或凭据。
- 保留消息编辑与多候选回复、聊天分支与检查点、高级世界书触发，以及 0.1.90 的应用标识、签名和固定更新频道。

## 验证边界

本次版本准备包含 Python 3.13 Core 编译、Ruff、Pyright、前端 lint／TypeScript、隐私门禁和 build-only 发行检查；本轮不自动触发 GitHub Actions，不运行真实应用、安装器、模型、后台付费任务或用户存档。真实升级、旧用户库迁移、后台故障日志和模型效果仍需用户验收。
