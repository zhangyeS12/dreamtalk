## 已实现

- **完整图片凭据链路**：前端只生成标准小写 UUID，Python 转为 `SecretRef(UUID(...))`；保留失败重试复用引用和保存成功后清理旧引用。旧前缀引用可通过重新填写密钥修复，不自动猜测或搬运密钥。
- **世界归属**：复用 Rust 的媒体凭据注册表，新增严格的 `media_credential_upsert` 私有控制帧，包含世界 UUID、引用 UUID 和原受控密钥字段。启动与运行中写入使用同一路径，Core 只接受桌面主进程传来的归属；设置保存和分析读取都检查归属，不能拿普通聊天／配音引用或别的世界引用代替。私有帧仍走既有有界管道、固定字段和原大小上限；不改公开 API 版本、密钥存储位置或 Tauri 架构。设置保存最多等待 2 秒本地控制帧同步，不探测服务商或调用模型。
- **独立说明**：0052 只增加可空图库条目说明，迁移在数据库内复制既有资产说明，不读取聊天正文或图片字节，不补造历史。列表、搜索、候选、发送和收录统一使用条目说明，原图和默认分析可复用。编辑不会改其他库；发送历史保留说明快照。分析带当前条目 ID，成功后只条件更新该条目，分析期间另行编辑的说明不覆盖。已有分析复用，不自动重试失败素材。禁止有损降级。
- **避免新孤立图片**：搜索下载及可选分析的结果暂存当前任务内，每轮仍最多一张、8 MB。消息、图片字节、收录及发送回执在原聊天写事务内一起提交；取消、失败或准入拒绝不单独保存图片。网络与模型等待期间不持有该写事务。独立的分析计次回执仍保留，未保存图片不退还云端次数，也不自动重放。
- **旧孤立素材回收**：沿现有启动恢复，在没有运行中生成的阶段，每次最多清理 32 张旧网络资产；原始用户导入不在候选内。全部图库条目（包括已移除条目）和全部聊天附件元数据均保护引用；遇到无法解析的历史附件时保守跳过。保留计次／费用回执，不压缩或替换整个数据库文件，不扫描聊天正文。
- **搜索外发前过滤**：沿既有一次查询，在 DDGS 前规范化并限制为短主题词，拒绝 URL、邮箱等标点结构、长数字／令牌、精确门牌和明显私人字段。整条拒绝而非改写后再次搜索；仅记固定原因标签，保留自然文字，无追加模型调用。此过滤无法保证识别所有私人姓名、地址或秘密；不是完整隐私检测器。联网授权、SSRF／重定向／大小限制不变。
- **群聊诊断**：复用本地结构化日志，按任务上下文记录整轮、选人和回复耗时，选人／回复逻辑调用数、准入阻止数和成功 Token 预留数，含失败／取消。逻辑调用不同于底层 HTTP 次数；预留包含路由重试及最终未派发的预留，实际收费仍以既有账本为准。不写聊天、关键词、角色资料、密钥或私有身份，不外发统计，不改变 32 条保护上限、选人或整轮预算规则。

没有引入新依赖；复用既有安全凭据库、私有控制协议、SQLAlchemy 聊天事务、Alembic 和结构化日志。没有复制第三方产品源码。
