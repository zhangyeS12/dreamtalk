# dreamtalk 0.1.37 · 观星室体验版

本版以 Logo 的日月星轨为基础，更新启动和进入世界后的界面。作为预发布体验版提供 Windows x64 完整便携包；源码采用 Apache-2.0。

## 下载和开始

- 下载附件 **dreamtalk-0.1.37-windows-x64.zip**，完整解压后运行 `dreamtalk/dreamtalk-desktop.exe`。不要只复制 EXE；请保留 `core/`。
- Windows 10/11 x64，需要 [Microsoft WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。无需安装 Python、Node 或 Rust。
- GitHub 自动提供的 **Source code** 是源码归档，不是可运行程序。
- 创建世界，在“模型设置”配置自己的模型服务和 API Key，然后在通讯录创建或导入角色卡、打开会话。模型调用可能产生服务商费用，后台功能默认关闭。
- 程序尚未签名，没有自动更新。更新前先从旧版托盘退出程序并备份重要应用数据；开启自启动的用户须在新版显式保存更新启动位置。

## 本版变化

- 真三维启动镜头重新编排：20条深浅光轨、双天体遮挡和星尘纵深；保留原 Logo、前台首帧至少1.5秒及真实就绪后进入书架。
- 世界内界面采用墨蓝、月白、银蓝与暖金，整理聊天工具和输入区，扩大阅读空间。
- 聊天目录和通讯录支持本地已加载名字筛选；人物档案突出头像与阵营，设置、个人资料和世界事件采用统一视觉层级。
- 包含已有的长期记忆、群聊、日常、相遇、共同休闲、主动联系、阵营与三维关系网实现。0.1.37没有新增Core行为或数据库迁移。

## 检查与限制

- 已完成 ESLint/TypeScript、CSS静态检查、文档链接及 build-only 编译。发布阶段核对源码与构建哈希、包内容和下载资产。
- 本轮未运行自动测试、GUI smoke、真实存档迁移或付费模型验收；没有最新版整体验收结论。既有CI定义保留，发布提交按项目当前约定跳过CI，不宣称CI通过。
- 构建保留非阻塞告警：JS chunk体积、STATIC_VCRUNTIME弃用、PyInstaller可选hidden import和jieba语法提示。真实运行兼容性仍需反馈。
- 完整离线演化、完整World Builder、运行世界备份/分支和自动关系成长仍未实现；退出程序或关机后不会运行本地模型任务。

附件 `SHA256SUMS.txt` 用于核对下载文件，包内 `BUILD_INFO.json` 标明源码提交和程序哈希；许可证在 `LICENSE` 与 `third-party-licenses/`。使用指南见包内 `README.md`，完整手册在 `docs/`。

通过 [GitHub Issues](https://github.com/zhangyeS12/dreamtalk/issues) 反馈版本、系统和复现步骤即可；请勿提交 API Key、个人存档或完整私聊。
