## 设置填写

模型已接入。在“设置 → 表情与图片 → 图片分析与用量”填写：

| 字段 | 值 |
| --- | --- |
| 分析方式 | 本机Ollama视觉模型 |
| 服务地址 | `http://127.0.0.1:11434` |
| 完整视觉模型名称 | `qwen3-vl:4b-instruct-q4_K_M` |
| 每日分析次数 | 保持10或自行调整为大于0 |
| 分析输出Token上限 | 建议512，在原32～1024允许范围内 |

先保存，再在表情库显式点击“分析图片”。需要导入后自动分析时再开启对应选项。本机路线无需API密钥；云端外发授权不启用。

重启电脑后通过独立目录中的`start-image-model.cmd`启动服务。脚本不注册开机启动，发现其他进程占用端口时保留，不关闭配音服务或未知程序。真实存档、设置保存、图片识别效果与并行配音仍待用户验收。
