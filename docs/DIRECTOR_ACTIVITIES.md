# 世界自动活动体验说明

本版实现已获批准的 Director 批量规划与基础角色日常。它还不是完整自主世界。

1. 关闭旧窗口，打开本包 dreamtalk-desktop.exe。旧数据会按原流程增量升级到当前版本；请勿再用旧程序打开已升级存档。
2. 在当前世界选择自己的身份；通讯录打开要参与的角色私聊，使已确认角色卡实例化。打开聊天不会设置物理地点。
3. 设置 → 角色初始活动地点，选择尚未设置的角色和“家”或手动添加的场所，点击“确认初始地点”。设置不调用模型，不移动玩家或已有地点的角色。
4. 设置 → 世界自动活动 → 开启 → 首次确认后台模型用量。若此前因无可规划角色停止，设置地点后显式点击“重新规划”；该操作是新的模型任务。采用当前已配置模型，各提供商使用同一治理。
5. 等待规划状态完成。角色可以开始休息、工作或自由活动；已有多个地点时可移动。只有“家”时可先选择家作为初始地点，不虚构新地点。
6. 查看聊天中的世界事件：只显示自己实际获知的变化。点已有“聊聊这件事”自行发送，或问角色近况；角色只参考自己的亲历记录，开始活动不保证任务成果。

每批6小时世界时间；少数偏差取消对应候选，至少2条且达原批50%失效才提前续批。输出上限为模型cap与8192的较小值，独立于每轮聊天额度，仍服从既有硬Token/金额预算。规划失败/空输出/重启遗留不会自动付费重放；“重新规划”明确开启新任务。

每世界默认关闭。暂停后不执行候选或开始新批；已发给模型的请求可能仍产生费用。关闭自动活动阻止未来工作，已提交事件保留，迟到模型结果不会重新启用。彻底退出应用时没有AI后台进程；可以另行设置关闭窗口到托盘，后台Core仍会运行。返回时不补造已经错过的活动：尚在有效时段的候选可按当前时间开始，已过结束时刻的候选expire；旧窗口外不生成未规划的历史。

当前容量：最多16名已放置角色、32个地点、64候选/批，必要输入64KiB；超出时明确提示并停止，不静默漏掉角色。输入含已接受角色卡的描述/性格/背景、同世界位置及当前世界已公开的世界书背景；不含隐藏条目、私聊、摘要或私人记忆。世界书按来源常驻/字面关键词条件选择，关键词匹配角色名和各自当前地点名；明确限制生成类型时需允许quiet后台生成。共享聊天已有最多16条、title/content共12KiB背景上限，规划读取最多512条公开启用条目、每条关键词/条件16KiB，超限提示且不派发模型。未来计划没有普通UI浏览入口。

日常事件只表示“开始活动”及可选位置变化；结束计划时段只释放占用，不宣称完成了工作或取得成果。单角色离线问候/邀请已作为独立开关接入，见[离线消息](OFFLINE_MESSAGES.md)。尚未实现多人主动联系、剧情相遇、关系推进、丰富地点编辑和完整离线活动重建。

本轮只做源码复核、Ruff/ESLint/TypeScript和编译打包，没有运行测试、迁移、应用或真实API。实际开启、计划质量、事件与知情隔离、暂停/关闭/恢复仍请按你的体验验收。


## 公共背景参与日常规划（本版新增）

在“设置 → 角色卡与世界书”保存世界书，并把希望日常规划参考的条目逐条设为公共背景。常驻背景无需关键词；普通关键词可使用角色名或其当前地点名。条目详情同时显示聊天与日常规划的参与条件，未支持来源条件不会猜测为可用。用户已具体授权这一数据范围发往当前配置模型；首次开启自动活动时也说明数据范围和后台用量。

公开/隐藏或更新内容不会另行触发模型调用，新资料等下一次正常批量规划。若本批选入背景在开始模型任务前或返回计划时已经隐藏/更新，则停止并提示，返回计划不接纳，绝不自动重放。已经开始的请求可能产生用量；已经提交的真实活动保留，已经接受的批次不会因后来的背景编辑重写历史。旧版无背景字段的计划可继续按原窗口处理，无新增迁移。

建议先用简短常驻公共条目体验，打开要参与角色的私聊并明确设置初始活动地点，再开启自动活动观察实际亲历事件。模型有机会选择更符合设定的活动，但本版动作仍只有休息、工作、自由活动及已有地点移动，不创建背景中提到的新地点或宣称完成任务。公共条目不能因此授予私人知识，计划未执行前仍不是已发生事实。功能与隔离验收由用户完成，工程端不运行应用、测试或真实API。


## 添加活动地点

现在可以在“设置 → 活动地点”手动添加家以外的场所。保存不调用模型；已开启自动活动会在下一次常规规划把这些真实地点列为可选范围，旧批次不重写。这里不会显示角色当前在哪儿，也不会移动玩家。背景描述仍在世界书填写并逐条确认公共；详细操作见[活动地点](ACTIVITY_LOCATIONS.md)。


## 程序开关与离线时间

当前自动活动运行在本地Core中：电脑开机、应用未退出、世界未暂停并且自动活动已开启时执行；可以把窗口最小化或切换到其他页面。退出应用、关机或进入系统睡眠后不持续执行AI活动。它不是云端常驻服务。

重开时，未暂停世界按离线经过时间和倍率推进WorldTime；暂停世界不补进暂停时长。已有计划只在仍有效的时段按当前时间启动，已过时的候选过期，旧窗口耗尽按已有规则继续规划；不完整重建关机期间的生活、亲历事件或成果。已经中断的模型请求不自动重放，需手动处理；已发出的请求可能已经产生费用。

单角色离线主动私聊已实现独立默认关闭的入口：满足真实离线时长且有合适理由，恢复后最多一条；同理由去重、未回复抑制、Busy/暂停取消。详见[离线消息](OFFLINE_MESSAGES.md)。自动活动开启不自动开启联系；多人Episode与完整离线世界重建仍未实现。
