# dreamtalk 0.1.87 · 角色扮演与玩家身份

- 优化聊天提示编排：角色卡决定人物身份与扮演方式，开场白、对话示例和历史后的补充要求分别发挥作用；聊天不再默认等于远程通信，动作和场景描写可以正常呈现。
- 通讯录新增“世界风格”，可为当前世界设置题材、内容尺度和叙事风格，预览确认后用于私聊、群聊及主动联系。模型的实际表现仍取决于所用服务。
- 角色引号内的台词显示为黄色，动作、场景和神态使用默认颜色；流式与保存后的文本使用同一套显示规则。
- 修复世界风格和用户身份预览／确认请求缺少内容类型、导致无法保存的问题。
- “我”页可以直接导入玩家专用 JSON／PNG／CHARX 角色卡并绑定身份，无需先添加通讯录角色或初始地点，也不会新增 NPC 或三维关系网节点；原有身份和世界书来源继续兼容。
- 放宽合法回复正文的格式限制，支持动作括号与 Markdown；异常辅助字段尽量不影响完整正文，失败提示更具体，不会自动重复调用模型。

提供完整 Windows x64 安装包、便携 ZIP 及原应用内更新频道。沿用原更新公钥、应用标识和数据位置，不需要清空数据。已有通讯录角色不会因玩家卡导入而被自动删除。

仍为预发布体验版。用户已反馈当前本机效果基本符合预期；此前获准的合成数据／模拟服务回归覆盖相关保存和编排链路。本次发行不运行 CI、自动化测试、应用或安装器，仅进行静态检查、编译、载荷与签名核对及下载摘要核对；真实旧版升级、存档迁移、恢复和更广模型场景仍待用户验收。角色卡兼容不代表支持酒馆全部宏、插件或脚本。
