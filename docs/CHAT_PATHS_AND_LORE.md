# 消息版本、聊天路线与高级世界书

本文说明已批准的三项聊天能力。当前实现、工程检查与用户验收分别见[状态清单](PROJECT_STATUS.md)；聊天路线不等于世界时间线分支或整库存档。

## 使用入口

- 私聊／群聊每条消息的“消息操作”：编辑消息、新建候选回复、从此分支、保存检查点。纯图片／表情没有正文编辑或候选入口。
- 标题旁“会话工具 → 分支、检查点与候选”，或会话内“分支与候选”：选择、命名和分页读取已有路线。
- 世界书编辑器每条条目下“高级触发与插入位置”：调整概率、计时、递归、互斥组与历史插入深度。保存仍须预览、确认；修改条件后按既有规则重新确认公开范围。

## 消息与路线

原消息及原路线保留。编辑会从该消息之前创建路线，再保存修改后的独立消息；旧路线之后的内容不进入新路线。修改玩家消息不会自动调用模型，可显式生成回复；修改角色正文也不会凭空生成记忆或世界事件。带正文的媒体消息保留原附件。

新候选为同一条玩家消息创建独立尝试与路线，确认后才生成，可能收费。私聊生成另一份回复；群聊重新生成整轮，选人和各位角色继续共享该次尝试的输入＋输出硬额度。已保存候选可切换，切换不调用模型；没有后台批量生成或自动付费重试。

检查点保存截至所选消息的固定记录，创建时不切换。选择检查点时只读，使用消息的“从此分支”再继续聊天。普通分支立即选中，后续消息只加入该路线。路线名称可修改，列表按创建时间分页，不以小数量上限丢弃旧路线。

预览绑定当前路线、版本、消息与内容。并发变化会要求重新预览；保存不确定时复用原请求回执，不能借重试重新生成。回复运行中或结果未知时不能改路线，须先核对已有回复；会话有主动邀请等待答复时也不能通过分支绕过该门禁。后台写入进行中同样拒绝切换；只读检查点不作为新主动联系的投递目标。

路线只管理聊天记录与从这些记录派生的上下文。世界时间、物理位置、已提交事件／关系、模型账本、费用及世界配置不会回退。

## 上下文与来源隔离

当前路线的成员消息先在 SQL 中过滤，再分页、检索或组装提示词。历史原句、已参与群聊、长期对话记忆、聊天获知事件、摘要、来源读取和聊天导出使用同一边界。切换时清空界面消息页和旧来源面板，保留未发送的聊天草稿。

以玩家原句为来源的记忆也绑定实际提取它的角色回复；只继承问题、不继承该回复时，不提前获得这条记忆。记忆替换按可见后继判断，切回旧路线可恢复旧记忆。摘要必须连同全部基底版本的来源都可见，不能仅凭最新修订本身没有新来源就跨路线继承。旧记录无法唯一确认提取回复时，保留原记录，不猜测它属于新路线。

人工记忆开关、置顶与忘记仍是原有世界／玩家／角色范围的管理操作，不作为聊天路线回退的对象。聊天分支不分裂 NPC 身份、地点或三维关系网。

导出绑定已预览路线及截止位置；导出过程中切换路线会失败，不能拼接两条路线。已读状态沿原有持久机制保持，查看另一候选不会伪造新消息。

## 高级世界书的支持范围

公开授权与有效版本过滤先于触发。递归只扫描已经获准提供的条目正文，不读取隐藏条目、其他世界或角色私密资料。

| 条件 | 当前行为 |
| --- | --- |
| 主／次关键词 | 保留大小写、完整词及四种次级逻辑；扫描最近消息，默认沿世界书设置，最多32条、16Ki字符扫描缓冲。 |
| 概率 | 开启后按0～100%选择，常驻和递归条目同样适用；同一来源及玩家问题使用稳定抽签，刷新、容量重排和同题候选不重抽。 |
| 延迟 | 当前路线至少有指定数量的消息后才可触发。 |
| 持续 | 首次实际纳入通过容量检查的请求后开始；持续期内不再要求关键词或抽概率，不因重复命中续期。 |
| 冷却 | 持续结束后等待指定消息数；没有持续期时从首次触发开始计算。计数是聊天消息数，含双方消息，不是现实时间或世界分钟。 |
| 递归 | 已激活内容可命中后续条目；支持最早层级、不被递归触发、不继续触发递归，以及来源世界书关闭递归。最多32层，使用有界递归文本。 |
| 互斥组 | 同名组只选一条，按优先级、顺序、稳定ID决定；未实现酒馆的加权随机分组模式。 |
| 插入位置 | 留空放在背景资料区；深度0放在历史后，深度1放在最后一条历史前，依此类推。按实际保留历史计算，深度过大时放在最早保留历史前。 |

持续／冷却以不可变消息为锚点持久保存；分支继承可见前缀的计时，舍弃未来的触发不影响新路线。改正文、来源或触发配置后旧计时失效。容量裁剪掉的条目不新建计时回执，内部计时标识不发给模型。

背景仍经过既有最多16条／12KiB选择和整轮模型硬额度检查；超出容量时省略完整条目，不破坏当前问题、角色卡或强行截断正文。深度背景作为明确标记的补充资料块插入，不冒充历史角色台词，也不覆盖系统角色卡及世界风格。后台日常规划不使用聊天计时条件。

正则／模板关键词、额外角色资料扫描、向量触发、脚本、扩展插件和其他酒馆插入模式不在本次执行范围。相关原始元数据继续保留；不支持的限制条件会说明原因，不声称完整酒馆行为兼容。
