# dreamtalk 0.1.53 · 全面更新体验版

这次更新整理了近期的角色管理、活动、关系、资料导出与应用更新功能，也把项目主页改成面向普通用户的安装和使用说明。

## 角色、地点和活动

- 通讯录角色不再受 16 位总量限制，每位角色都需要初始地点。自动活动从全部角色中轮换选择，每批可设置 1～16 位，默认 8 位；角色越多，轮到每人的时间可能更长。
- 地点不再受 32 个总量限制。不同分支可以有同名地点，同一父地点下仍避免重名；地图和角色位置显示完整路径，减少混淆。
- 初始地点是常驻中心，可以设置常驻倾向、锁定、隐藏分支和开放角色。未锁定角色可在父、子、兄弟地点间移动，跨地区远行概率低，离开后更倾向返回。
- 地点图使用嵌套圆和角色头像展示包含关系及实际位置；只有处于同一地点才可以相遇。

## 群聊、删除和资料导出

- 群聊支持解散：从列表消失并停止发言，已有记忆和原消息来源保留。
- 书架支持删除整个世界：确认后清除世界书、角色、地点、阵营、聊天和记忆，恢复空白书位。操作无法撤销。
- 角色卡、空阵营和未被占用的地点提供删除入口。删除角色保留历史，相关旧会话变为只读。
- 角色卡可导出 V2 / V3 JSON，世界书可导出 World Info JSON，完整已保存聊天可导出 TXT / JSON。资料导出不含完整运行存档，角色 JSON 不打包头像；当前不支持聊天文件导入。
- 完善尚未绑定玩家身份时的角色导入与初始地点确认提示，避免误以为必须重复创建角色。

## 相识关系与聊天

- 移出阵营时可选择切断或保留该阵营提供的联系。曾真实相遇建立的相识始终保留，仍共同所属的其他阵营也继续提供联系。
- 私聊与群聊参考当前有效的关系，避免沿旧规则把已经切断的阵营联系继续当成熟人。
- 群聊优先参考当前谈话涉及的已知角色与相关关系，减少无关资料占用。
- 改进关系读取和地点图整理方式，减少角色、地点较多时的重复处理。

## 模型、更新和使用说明

- 书架配置为默认模型，各世界可以保存独立服务商、模型和密钥，再恢复默认；每轮聊天额度仍为本机共用。
- 支持多类模型服务，提供超时、回复长度与高级兼容选项；保留严格整轮额度，并明确显示不足时所需预留。
- 有新版本时展示更新说明，支持稍后、更新与不再自动弹窗；书架仍保留“新更新”入口。确认更新后保留数据，并处理对应自启动、快捷方式及此次更新管理的旧程序。
- 继承旧版安装清单修复与频繁更换封面时的缓存回收改进。
- 重写项目主页、安装说明和设置手册，说明每个页面、选项、费用来源与删除后果。

## 使用提醒

本版仍为预发布体验版。已进行源码、格式、类型、编译打包及静态文件核对；未由工程端运行应用、安装器、自动化测试、真实存档迁移或付费模型验收。

首次使用请先设置自己的模型服务。后台功能默认关闭，开启后可能产生费用。旧版没有更新器时须先彻底退出，再安装完整新版；不要用旧程序打开已升级的存档。更新签名不等于 Windows 发布者证书。

资料导出不是完整世界备份；删除世界无法撤销。完整离线生活重建、一键构建完整运行世界、完整存档恢复与云同步目前尚未提供。
