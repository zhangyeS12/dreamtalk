# 世界档案库（桌面 0.1.16）

启动后的首页是横向世界书架，初始只看见一排书脊，不默认抽出任何书，也不显示右侧简介或创建表单。每本有名字的书对应现有世界档案；白灰色空白书只作为添加入口，不保存演示世界，也不限制真实世界数量。每圈至少12本，总数为max(12,世界数+1)：0个世界12本空书，5个世界加7本空书，12个世界加第13本空书，更多世界仍保留一本空书。每圈末尾接回第一本，宽窗口也可持续循环；重复看到同一本世界书仍是同一个档案。书距已略增。文字封面默认与朝向用户的书脊使用同一个世界名；图片封面标题可留空，留空不自动补字；可在右侧下方“编辑封面”改展示标题，或上传正面、书脊、背面图片，见[封面说明](WORLD_COVERS.md)。

## 浏览与进入

- 鼠标悬停时书轻轻向前抽出，离开后归位。已有世界与空白书行为一致。
- 点击已有书时，书完整抽出并转向展示封面，随后右侧显示世界名称、已确认世界书摘要、真实世界时间与进入／管理入口。首次进入没有身份的世界时打开“我”，完成从家进入；已有身份进入聊天。
- 点击空白书时，同样抽出后才显示“创建世界”和“导入世界书”。选一个入口后再填写世界名；确认创建档案后，在展开的管理区域手动填写、联网生成，或选择世界书JSON文件。
- 检查草稿、预览并确认保存。取消世界书草稿不删除已经创建的世界档案；隐藏／公共背景范围仍逐条设置。
- 切换书时前一本归位、新一本抽出；再次点击所选书、“归位”、书架背景或Esc取消，右侧信息收起。方向键、Home／End移动书本焦点；Enter／Space与鼠标点击一致。取消后焦点返回原书。方向键到末尾会回到第一本，向左亦然。
- 按住书本或书架背景左右拖动，松手后自然减速；短按选择书，拖动不会误触选择。不再需要底部拖动条。左右按钮和方向键同样首尾循环。窄窗口的信息在书架下方；系统减少动画时即时切换。上次进入的世界仅用于恢复书架浏览位置，不会自动选书或进入世界。

循环拖动直接使用Embla Carousel8.6.0（MIT），原始许可随包保留，见[复用记录](research/2026-10-02-world-shelf-loop-reuse.md)。抽出的书与详情保持在展示位置，背后书排仍可拖动。

书架采用共享透视、六面书体、书架背板／底板／前缘和接触阴影。动效只有浏览状态变更，没有持续漂浮。右侧信息等当前书抽出完成才出现；后台标签暂停动画时有界面兜底，不会因此阻止正常操作。

## 编辑与刷新

已有世界的“管理 / 导入世界书”复用手动／联网草稿、文件导入、更新、预览确认和公共背景设置。角色卡的新建、联网生成、导入和编辑位于世界内“通讯录 → 添加角色卡”；设置按应用与当前世界分类，见[设置手册](SETTINGS_HANDBOOK.md)。页头“模型设置”复用原配置界面，可在进入世界前配置联网创作使用的模型；保存会重启核心并重新连接，不测试密钥或产生模型费用。

创建结果未知时保留原名称和请求ID，再次点击“核对上次创建结果”，避免重复创建。明确名称校验错误允许修改。已有模型／世界书编辑或未提交的名称表单，在切书或离开时提示确认。离开并不取消已发起的模型任务；它可能继续产生用量。

页头始终有“刷新书架”；读取失败提示也有刷新入口。刷新只读状态和摘要，不重放联网生成。世界状态通常每15秒只读更新，所选摘要按真实世界ID加载并防止迟到结果串入其他世界。

## 信息与运行边界

- 选书只预览，不创建／绑定玩家，不自动暂停／恢复世界，不改变后台授权，不计作玩家在线，也不加载／标记聊天已读。明确进入业务界面后才报告该世界的桌面可见状态。
- 返回书架不停止Core。已开启的自动活动、动态池、离线联系继续按既有授权和开关运行。
- 简介来自已确认世界书；不展示假消息、推算未读、关系数值或全知活动。管理设定不等于角色获得知识，更不等于真实世界事件。
- 隐藏条目默认隐藏；角色或已授权后台规划所需条目仍需逐条确认公共背景。
- 世界ID、存档、兼容协议、模型预算和开机后台模式沿用，本次封面展示新增0030设置/图片绑定表，已有世界与聊天记录保持；工程侧未迁移真实存档。

## 更新与验收

从旧托盘“退出并停止后台运行”，直接运行完整的 `settings-feedback/dreamtalk/dreamtalk-desktop.exe`，保留同目录core。本机已生成完整目录，不必再次解压ZIP。在世界内“设置 → 后台运行”核对桌面版本0.1.16；需要开机启动新目录时显式点击“保存并更新启动位置”。已有角色、世界书和聊天沿用原存档。

源码审查、ESLint／TypeScript、release编译与包内字节核对不代替实际体验。按AGENTS第20节未修改／运行自动化测试，也未启动应用／浏览器／桌面检查、真实模型或用户存档诊断。既有ProductApp测试仍含旧首页和设置下拉切世界断言，需要后续获准适配；没有删除、跳过或弱化。

用户验收重点：直接按住鼠标拖动及松手不误选、双向跨越首尾、书位数量与书脊名称、宽窗口持续循环，初始无默认详情，已有／空白书悬停与抽出，快速换书与取消，空白书后出现创建／导入入口，草稿与未知结果保留，已有世界进入／返回，窄窗口、键盘和减少动画。三图封面已实现，真实保存、裁剪和重启仍待用户验收。


## 默认模型配置（0.1.43）

书架“模型设置”保存默认模型；没有独立配置的世界继承它。进入世界后在设置保存模型，只修改该世界，已独立的世界不会随默认更改。书架管理已选世界的卡／书联网生成也使用该世界的有效配置；预览仍不调用模型。详见[设置手册](SETTINGS_HANDBOOK.md)与[本轮记录](maintenance/2026-10-08-world-model-config.md)。公开0.1.42仍使用原全局模型，本地0.1.43尚未发布。
