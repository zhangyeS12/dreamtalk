# 后台启动与离线期间的消息

## 开启方法

1. 退出旧程序，完整保留新便携包的 dreamtalk 文件夹，打开 dreamtalk-desktop.exe。启动按原流程增量升级到0027；不要再用旧版本打开已升级存档。本轮没有替你执行迁移或修改用户配置。
2. 选择世界和“我”的身份，在通讯录打开希望参与的角色私聊，使角色实例化；配置可正常使用的聊天模型。
3. 设置 → 后台运行：可开启“登录电脑后自动启动，保持窗口隐藏”和“关闭窗口后继续在托盘运行”，点击保存。默认两项均关闭。托盘双击打开；右键“退出并停止后台运行”彻底退出。便携程序文件夹移动或删除会影响已注册的自启动路径；更换包后可关闭再开启自启动，注册新位置。
4. 设置 → 离线期间的消息：默认6个真实小时，允许1–168小时。首次开启明确确认后台模型用量和输入范围。应用只绑定一个世界/玩家作为离线联系目标，在另一个世界开启会替换目标。自动活动与离线联系是分别控制的开关。
5. 首次开启/修改时长只记录基线，不立即补发。退出/关机/睡眠经过设定时长后，登录后台启动或手动重开共用恢复流程。仅窗口隐藏、最小化或暂时不聊天，不算Core停止执行的离线间隔。

## 收到什么

一次恢复最多选择一个角色，生成一条自然问候或之后聊聊/休息的邀请；模型也可以决定不联系。Busy、暂停世界、无合适已打开角色、身份变化、同理由已处理或上条主动私聊仍未获回复都会跳过。不会按每个6小时段补发，也不会因为玩家没有回复而不断催促。

消息显示离线区间内、由规划选择的剧情时间。例如21:00退出、07:00重开，可以显示22:35。真实模型调用、用量和消息创建仍发生于07:00之后；点击“时间详情”查看真实生成时间。聊天记录按持久位置追加，旧记录与真实创建时间不重写。未读根据真实投递记录保留；实际打开可见会话后才标已读，隐藏窗口不自动消除未读。

后台隐藏窗口、其他世界或界面在线记录到期时，本地绑定玩家不被自动当作现场事件的见证者。位置不消失、不移动；已经获得的事件知情记录保留，正常角色见证规则不变。

## 模型、费用与输入

复用当前配置模型、路由和Token/金额硬预算，适用于已有各提供商适配器。Director一次有限计划选择角色/目的/时段，Character单独写最终台词；最多两个有限模型任务，单次输出不超过8192或模型更低上限，实际用量按网关记录。与每轮聊天额度、自动活动的6小时世界时间分开。

输入仅为离线前冻结的已接受角色资料、逐条确认的公共世界书背景和已有活动意图。选人和台词不读取或外发私聊正文、摘要、隐藏条目、私人记忆或未知事件；本地消息标识/位置只用于去重，不发给模型。已有计划不表示离线活动已经执行，更不表示取得成果或见过玩家。资料、玩家消息/身份/状态发生变化时，取消不再适用的结果。

每分钟轻量记录Core在线和合规输入；正常退出再保存一次，崩溃可有约一分钟误差。系统时钟向后调整不会产生负时长或倒退基线。每次恢复先持久记录，再发起模型调用；失败、被中断或模型不联系的结论不会自动付费重放。关闭开关停止未来联系，在途请求仍可能计费。它不是关机时运行的云服务。

## 当前范围与验收

本版仅单角色离线主动消息、托盘与后台启动，不包含多人Outreach Episode、在线状态下持续主动消息、关系推进或完整离线活动/成果重建。轻量在线状态与消息回执属于操作性数据，不生成历史WorldEvent或强行给玩家知识。

依当前AGENTS仅做源码审阅、Ruff/ESLint/TypeScript及编译打包，没有新增/修改/运行测试、应用、真实API或用户存档迁移。由用户实际验收启动、托盘退出、休眠/重启恢复、Busy/暂停、未读和模型质量。编译和文件哈希核对不代表运行验收。
