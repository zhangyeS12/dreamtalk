# 安卓封面上传修复发行记录

本轮按用户明确要求准备安卓 0.1.6／1006 个人测试预发布。沿原安卓签名、独立源码分支发布，不改变 Windows 主分支、发行、更新频道或 Latest。

主要变化是三个封面入口共用的 Android 素材发布适配与现有 Pillow 的 WebP 编解码补齐。模块契约、成熟实现来源、固定版本和许可见[图片处理](ANDROID_IMAGE_PIPELINE.md)。本轮沿用户长期明确要求不运行、触发或等待 CI，源码提交带跳过标记，独立分支不匹配 Android 推送工作流；发行构建使用本轮授权的 SkipCI。

完整发布前核对源文件及实际提交的隐私、源码与 APK 内 Core、固定编解码扩展及许可、原证书 v1／v2／v3、16KB 对齐、固定检索资源、品牌与迁移。发布后另核对标签、四项附件匿名完整下载及 Windows 隔离。

源码标签中的文档保留发行准备快照；实际当前结果只见[状态清单](PROJECT_STATUS.md)及其引用工程记录。
