# 存档

当前版本提供一个自动存档、四个手动存档；导入不加载，加载会切换完整数据并覆盖自动档，启动时保存一次。发行状态见[状态清单](PROJECT_STATUS.md)和[0.1.90发行记录](maintenance/2026-10-25-release-0190.md)。合成数据检查已通过，原生窗口、真实存档及Windows更新连续性仍待验收。

消息、资料编辑和世界变化继续即时保存。存档是额外保险；正常更新继续使用原数据，不需要手动加载。

## 入口和文件夹

书架“检查更新”旁点击“存档”，也可在世界内设置的备份分类进入。首次选择专用文件夹，应用只使用五个固定位置。更换文件夹不删除旧文件；旧`.dreamsave`可以显式导入手动位置。

从上到下为自动档及四个手动位置。清单超过五条时不读取后续存档文件。名称可修改，右下角显示数据保存时间。将自动档另存为手动档时保留原保存时间。

## 保存

- 每次启动，在当前数据和书架检查完成后保存一次自动档；下次启动覆盖它。刷新页面、切换世界或设置导致的Core重启不额外覆盖。
- 首次指定文件夹时，补做本次尚未完成的自动档。位置不可用时保留当前数据和原存档，并提示重试。
- 手动位置可保存当前数据，已有内容须确认替换。“另存自动存档到此处”复制那份自动档，不保存当前运行进度。
- 每份包含全部世界、世界书、角色卡、身份、记忆、聊天及图片、音色参考等关联数据，不包含模型权重或可重建缓存。
- 新文件生成和校验成功后才发布到清单。沿现有单份32GiB、10万文件限制，写入失败不先删除原位置。

## 导入与加载

“导入文件”使用文件选择器；展开“指定存档文件路径”可填写完整`.dreamsave`路径。导入只替换所选手动位置，不改变当前游玩数据，也不覆盖自动档。

每次打开页面都会显示：

> 加载手动存档会立即切换全部世界、角色和聊天等数据，同时覆盖自动存档。若要保留原自动存档，请先将它另存到一个手动位置。

明确确认加载后，程序等待任务结束、停止Core，在临时副本检查结构和迁移，然后切换全部数据、更新自动档并重新连接书架。旧生成任务不重发；自动活动、主动联系、离线联系及世界动态保持关闭，需用户重新开启。

本机API配置、Windows密钥及模型路径保持本机原配置，不能沿用他人电脑设置。费用、预算及调用保护保留本机记录，不随剧情回退或继承对方额度。较新或损坏的存档停止加载，不以删除原数据换取继续。

## 故障与更新

加载在原数据旁保留本次恢复工作材料，并以日志记录完成情况。自动档清单作为完成标志；中途退出后，下次启动先完成或回滚切换，再开放业务。外置磁盘不可用时保留日志和文件，不以空数据替代。异常启动页面也提供五个存档位置；当前数据未确认时不能反向覆盖存档。当前费用保护记录本身损坏时会停止恢复并保留材料，需要工程修复，不静默丢弃已知用量。

更新、安装和迁移仍有独立保护快照，不占用四个手动位置。更新先验签、排空任务、正常停机、备份，再核对原记录及关联文件；校验失败不继续安装。未完成更新的检查点不能被普通自动档覆盖。旧保护材料保留异常恢复入口，不自动转入五个位置。

卸载保留当前数据及独立存档。普通界面不提供“清空本机数据”，也不删除多余存档。导出包含私人聊天和素材，请自行选择分享对象；应用不自动上传。
