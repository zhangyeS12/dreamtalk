# 活动地点

在设置中选择世界，找到“活动地点”，输入例如“六分街录像店”“咖啡馆”或“学校”，点击添加。手动添加不需要API。保存成功后会显示通知；地点属于当前世界，切换世界会读取另一个目录。名称1–120字，“家”由进入世界时自动创建；同世界规范化同名会提示重复。

目录显示你手动创建的地点和初始家，不显示角色的位置、正在发生的隐藏事件或未来安排。它是本地创作配置，不是玩家获知事件的记录。新地点不自动移动玩家或角色，不把世界书中的地名自动变成真实运行地点。目前不提供重命名、删除、层级、路线、地图或玩家前往按钮。

启用世界自动活动后，地点名称会发送给你配置的模型用于下一批日常规划。添加地点本身不调用模型，也不马上打断旧批次或额外付费重规划；Director下一次常规规划才考虑新增地点，模型不一定每批选择每个地点。可以在世界书补充场所背景并逐条设为公共；素材仍需已有激活规则匹配，内容不是运行事实。

自动规划最多32个实际地点，包含初始家及已有运行地点；尚未进入世界时会为家保留一个名额。输入和创建记录在Kernel同一事务保存；相同请求重复提交返回已保存结果，不再创建。

连接失败不会自动重试。名称和原请求保留，可以“用原请求重试”，也可以“刷新地点”只读查看。看到同名仅是提示，同一次请求的回执才确认保存结果。草稿和原请求在当前编辑会话内保留；关闭应用后可查看目录再创建，同名限制防止重复添加。切换世界或创建另一个世界前会提示未保存修改。

新版本源码包含0026_local_location_catalog增量迁移，不回填或公开旧后台地点。开发交付只做静态检查与编译，不代用户运行迁移、真实API、应用或测试。请使用原本的数据目录体验升级，核对保存、重开、跨世界和下一批规划效果。


## 界面重复修复（2026-09-29）

## 设置角色初始地点（桌面版0.1.2）

在当前世界选择自己的身份，在通讯录打开希望参与活动的角色私聊，然后到设置 → 角色初始活动地点，点击“刷新角色与地点”。选择尚未设置的角色和家或本世界手动创建的地点，点击“确认初始地点”。不预选家、不批量放置，不需要先发送消息。只有群聊的角色需先打开私聊。

这里设置的是角色第一次进入物理世界的位置。它不修改已有位置，不提供之后的当前位置、路线、活动或隐藏事件浏览。已设置的角色只显示“已设置初始地点”，更新角色卡不会重新放置同一个角色。角色位置在世界内共享，切换玩家身份不会让同一个角色重新获得初始位置。

保存通过原Kernel PlaceCharacter执行，expected_state_revision固定为空；当前身份/私聊角色和地点目录权限、是否已有状态及16名已放置角色容量在同一写事务检查，之后保存原CharacterPlaced事件、状态和请求回执。新可选activity_player_id仅在本入口启用，旧默认命令指纹与事件格式保持。没有新表或迁移，不把私聊或世界书内容当成物理位置。

设置本身不调用模型，不自动开启自动活动、移动玩家、立即打断旧批次或请求付费重规划。已开启的自动活动按正常批次运行；若原来因没有已放置角色而停止，用户可在世界自动活动中明确选择“重新规划”。开始活动或选择地点不保证任务成果，也不授予过去事件知识。离线主动私聊仍不要求初始地点。

网络失败保留角色、地点及原请求。可以“用原请求重试”确认回执；即使角色后来已经开始活动，匹配回执也不会再次放置。刷新只读，看到“已设置”本身不证明是本次请求保存，需要原ID确认。未知结果不会自动提交；切换世界、新建世界或切换身份前提示尚未确认的设置。确定的拒绝提示具体原因。

本轮只有静态检查、Core/桌面编译和打包，未运行自动测试、应用、模型调用或用户存档迁移。请自行验收保存、重开、重复点击、切换世界/身份及下一批自动活动；版本/路径可在后台运行设置核对。
