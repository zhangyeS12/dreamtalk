# 长期聊天记忆与近期经历

本页描述当前源码行为。版本、发行和已通过的具体场景见[状态清单](PROJECT_STATUS.md)；检索细节见[上下文与召回](CONTEXT_AND_RECALL.md)。长期聊天条目、用户确认的会话摘要和有 Observation 证据的亲历记忆是不同来源。

## 使用与更正

1. 正常私聊或群聊，向角色表达重要身份、偏好或约定，在会话菜单的“长期记忆”查看条目、来源及时间；群聊按成员查看。
2. 可以搜索、加载更早条目、置顶、停用或查看来源原文。原文回看仍核对当前世界、玩家和原会话权限，不额外调用模型。
3. 同主题补充可以并存。明确纠正由同次回复提出 replaces，经逐字原句、说话者、来源和权限校验后建立新旧版本关系；不按主题同名自动覆盖。群聊只更新各成员获准的副本。
4. 关闭自动记录仅停止该角色后续新条目写入，已有有效记忆仍可使用。停用或已被替代的条目在新检索前排除；原聊天和过去参考记录保留，这不是删除聊天。已被替代的旧条目不能直接恢复使用。

## 提取、检索与费用

OpenAI-compatible Chat Completions、OpenAI Responses、Anthropic Messages、Gemini Interactions 四类已配置文本路由共用可选的同次事件／记忆注释。完整 JSON 或完整 JSON 代码块经本地校验，最多新增4条记忆；不要求开启原生 JSON Schema。完整普通台词也可成功保存，只是该次没有新注释，不会另调一次 API 补提取。空正文、截断或损坏的 JSON 沿回复失败流程处理。具体型号／代理能否稳定返回有效注释仍须按场景验收。

当前检索融合 jieba／FTS5 词法结果和本地 BGE 向量，查询结合当前问题与同会话前两句。核心身份、偏好、约定按种类分桶，置顶与相关条目共同分配空间。长期条目最多16条、合计8KiB；相关历史原句最多4条、完整数据合计8KiB。固定模型不可用或语义工作超时时退回关键词，并在“本次参考内容”说明；渐进索引不保证当次已搜索全部历史或一定命中同义表达。

索引／向量在本机处理，运行时不下载模型，不向外部 embedding 服务发送历史。提取随正常聊天调用完成；进入聊天提示的记忆、历史及注释仍占输入／输出 Token。查询、置顶、停用、来源回看和确定性生命周期处理不额外调用模型；会话摘要的显式生成是另一个可能收费的任务。

记忆按世界、玩家、角色隔离；私聊来源只供对应角色，群聊公开原话只供固定成员。检索重新核对来源、当前聊天路线、授权和有效状态，不能凭旧索引读到别人的私聊、隐藏世界书或私人观察。

## 活动与共同经历

角色回答近况时另读本人已提交的实际活动、近期移动与获准终态。活动开始、到期结束、放置引起的中断均由既有 Kernel／调度链路处理；活动时段结束不等于工作完成、物品收益或关系成果。世界暂停不推进到期，关闭自动活动停止新规划，已开始活动仍可自然结束；完整退出不运行，也不补造离线活动。

旧版只有 finished 标记、没有真实终态事件的记录不会被改写。历史开始不能覆盖当前状态，目击他人也不能变成本人参加；相遇与共同休闲已实现，仍须各自授权和实际事件。范围见[亲历召回](EXPERIENCE_RECALL.md)、[终态召回](EXPERIENCE_STATE_RECALL.md)和[共同休闲](SHARED_LEISURE.md)。
