# 在聊天中回忆角色经历（桌面0.1.24）

0.1.23连接卡顿修复已由用户回复“已验收，没问题”。本版继续补角色经历召回，保留原生库预加载和现有长短期记忆。

角色日常实际发生后，可以在私聊或群聊问“你之前在录像店做了什么？”“你有没有看到铃去休息？”；使用自己世界已有的角色、地点名字。系统按当前问题和前两句在该发言者有权亲历的记录中找依据，再提供给正常回复。未开启自动活动、没有对应观察或查不到时，角色应表达不确定。

原先只有最近12条观察，旧经历容易被新的活动挤掉。现在在近128条授权事件中使用已有分词/FTS5，保留近期资料并最多补4条话题相关的旧经历；最终仍最多12条/8KiB，不额外调用模型。自己的最新活动快照单独保留，问近况不能拿过去活动当现在。

角色可以说自己做过什么，或者目击另一角色做过什么。目击活动不能证明两人聊天、共同工作或形成关系；群聊也不是物理相遇。聊天原句、长期聊天记忆与真实亲历仍是不同来源。后台未知经历不会因此直接列入玩家事件页，玩家可在自然聊天中获知。

没有新增设置、依赖或存档迁移。先从旧托盘退出后台，再直接运行完整的experience-recall/dreamtalk/dreamtalk-desktop.exe，在“设置 → 后台运行”核对0.1.24；使用自启动时显式保存更新位置。本机完整目录无需再解压，保留core/和原app-data存档。

请在已有活动的世界体验：追问具体地点/角色的较早经历，换角色/世界，核对只有对应观察可用；再问“现在呢”，确认仍以当前本人活动为准。词法召回暂限近128条，不能保证同义说法和远历史，也不保证模型每次正确使用证据。真正的角色相遇还未实现，见[方案](proposals/2026-10-03-character-encounters.md)。工程端没有运行自动测试、应用、推理或付费API；本版效果待用户验收。

## 0.1.25真实碰面也可召回

[角色相遇](CHARACTER_ENCOUNTERS.md)已按批准方案接入，默认关闭；仅Kernel实际提交的CharactersMet才进入双方/授权在场者的观察检索。投影标出event_type、两名参与者ID与participant/witness；不会把目击他人相遇说成本人参加，也不把短暂打招呼编成私聊、任务成果或关系变化。较早的“相遇待批准”属于0.1.24先行实现时的边界，本次方案已获得明确批准。范围仍近128条词法候选、最终12条/8KiB，运行效果待验收。

## 0.1.26问候语义与节奏

真实碰面的观察投影增加encounter_stage=brief_greeting、relationship_effect=none，明确问候不证明交换姓名、正式介绍、私下谈话、共同任务或熟悉程度提升。既有授权背景的亲缘/熟识仍保留。没有新增正式介绍/任务/关系动作；观察的近128条词法检索和最终12条/8KiB上限保持。持续同场普通问候、每角色新增对象和每批执行数量的限制见[相遇说明](CHARACTER_ENCOUNTERS.md)。完整0.1.26包位于encounter-pacing/dreamtalk；无需额外API判断记忆。
