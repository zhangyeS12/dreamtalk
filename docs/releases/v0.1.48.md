# dreamtalk 0.1.48 · 更新校验修复

- 修复 Windows 安装包主程序与交付清单摘要不一致，导致应用内更新被拦下的问题。
- 安装包构建增加直接解压核对：主程序、Core、资源和清单逐文件匹配后才允许交付；不运行安装器。
- 提供 0.1.46／0.1.47 原安装包的一次性清单修复工具，只接纳已核实的原交付文件，保留原清单和严格更新校验。

包含 0.1.47 的角色卡／地点删除、历史保护，以及世界独立模型、常驻与远行、封面缓存回收、更新提醒和全局静音。

旧 0.1.46／0.1.47 安装版出现“程序文件与交付清单不符”时，可运行 Release 附带的 repair-update-manifest.ps1，核对通过后再点击应用内更新；也可退出程序后手动安装完整新版。便携版保持完整目录使用。世界和聊天数据保留。

此版本为预发布体验版；实际跨版本更新、恢复、系统入口和旧文件清理仍由用户验收。更新签名不是 Windows 发布者证书。
