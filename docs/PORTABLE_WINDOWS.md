# dreamtalk · Windows 安装与使用

本版0.1.85新增设定身份与逐角色初始认识，可选择明确人物、编辑公开介绍和故事起点并预览确认。保留一自动四手动存档、双人共同邀请、校园示例、启动与升级保护、角色配音及聊天图片。应用仍为Windows x64预发布体验版，使用你自己配置的聊天模型。

## 开始使用

1. 使用安装包按提示安装，或完整解压便携ZIP后打开dreamtalk文件夹中的dreamtalk-desktop.exe。不要只复制EXE或在压缩包中运行。
2. 在书架右上角配置默认聊天模型。可点击“体验校园示例”，预览并确认后创建带三位同学的高中世界；也可自行创建世界、设置身份并在通讯录添加角色。
3. 通讯录的“表情包”管理公共／角色专属／我的表情；聊天输入区可发送自己的表情。公共与专属按世界隔离，我的表情跨世界共用。
4. 需要配音时，在通讯录绑定参考人声或.voicecard，进入设置→角色配音选择路线、开启并保存。播放成功缓存六小时，重新配音可试听后决定是否替换。

本地配音使用另行部署的IndexTTS2.5；可选图片分析使用另行准备的Ollama视觉模型，例如Qwen3-VL4B Instruct Q4_K_M。下载包不内置这些权重或角色录音，也不自动下载。没有视觉模型时，手动填写表情说明仍可使用表情库。

本地配音和本机图片分析不限每日次数；云端费用／次数规则保持。已登记的本机服务随dreamtalk启动，开启并保存程序开机后台启动后也随登录启动。旧配音桥接可在设置中点击“一键修复本地配音”；修复只处理已核对可信且空闲的本项目服务，不自动重发配音。

用户确认本地配音效果、角色发表情和新上传表情识别问题解决；免费云端最新版和付费配音API仍待确认。联网找图与自动图片分析默认关闭。详细操作见[角色配音](CHARACTER_VOICES.md)、[表情与图片](CHAT_MEDIA.md)、[完整设置](SETTINGS_HANDBOOK.md)和[本次更新](releases/v0.1.85.md)。

## 更新已有版本

启动有新版本时可查看说明，选择“稍后”或“更新”。勾选“不再自动弹窗”后，书架仍保留“新更新”入口。

更新在确认后才下载，保留世界和聊天，并尝试更新已启用的自启动与对应快捷方式，清理此次更新管理的旧程序。其他目录的手动副本或下载压缩包不会被扫描删除。失败时保留恢复材料并提示处理。

没有更新器的旧版先从托盘“退出并停止后台运行”，再手动安装完整新版；仅关闭窗口可能仍在运行旧程序。便携版手动换目录后，在新版“设置 → 后台运行”点击“保存并更新启动位置”。

0.1.46 / 0.1.47 若因旧清单问题拒绝更新，请看[更新修复说明](WINDOWS_UPDATES.md)。不要用旧程序打开已经升级的同一存档。

## 数据、导出和删除

数据保存在本机用户目录，不在便携程序文件夹中。Windows 默认数据位置为 %APPDATA%/app.livingworld.desktop；重要数据可在应用完全退出后保留完整副本，避免只复制正在写入的单个数据库文件。

角色卡可导出 V2 / V3 JSON，世界书可导出 World Info JSON，聊天可导出 TXT / JSON。导出不调用模型，角色 JSON 不打包头像，世界书包含隐藏条目。资料导出不是完整世界备份，目前没有聊天导入；五位置存档操作见[存档手册](DATA_BACKUPS.md)，加载前需明确确认。当前发行状态见[状态清单](PROJECT_STATUS.md)。

解散群聊保留记忆与来源；删除角色保留历史、相关会话只读；删除世界会永久清除该世界的所有资料、聊天和记忆，书位恢复空白。请仔细阅读确认提示。

## 运行与反馈

托盘中继续运行时，已开启的后台功能可以工作。彻底退出、关机或睡眠后不会继续调用模型，也不会补造未发生的完整生活。

本轮源码已完成获准的隔离CI；发行构建仅build-only并静态核对文件、签名和下载，不运行已安装应用、外部模型或真实存档迁移。用户确认本地配音、角色发表情和新增素材识别的具体体验；免费云端／付费配音、其他场景与老存档／自动更新仍需继续验收。

通过 [GitHub Issues](https://github.com/zhangyeS12/dreamtalk/issues) 提供版本、操作步骤、预期与实际表现，分享截图前遮住密钥和私人聊天。源码采用 [Apache-2.0](../LICENSE)，第三方许可在随包 third-party-licenses 和 docs/licenses 中。
