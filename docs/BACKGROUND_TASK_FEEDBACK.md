# 后台任务状态体验（桌面0.1.21）

退出旧托盘程序后打开完整新版目录。在“设置”的角色活动、离线联系、世界动态分类查看状态和下一步入口。各开关独立，刷新只读取；新的模型任务继续使用原授权和预算。

## 自动活动

暂停、正在规划、计划就绪、等待模型与任务失败分别显示。失败优先说明已记录原因，不被“世界暂停”盖住。之前缺角色地点，但现在已经设置好时，提示点击“重新规划”，不要求重复放置。该按钮是新的模型调用；状态刷新不会重试。

需要修改模型、角色初始地点或世界书时，可以直接前往对应入口。返回书架仍保留未保存内容离开确认。不会展示未获知的角色活动计划；想知道角色近况可进入聊天询问。

## 世界动态

显示正在生成、等待发布和等待手动处理进度。待发布为零但本批处理未达80%时，说明还差多少条，并可前往世界事件标记“已经历”或“跳过”。它不是生成失败；显式“生成新一批（调用模型）”入口仍保留。程序不会通过刷新绕开阈值或付费重放。

公共背景准备情况显示本次读取的世界书/条目/公开/启用数量，以及核心返回的公开条目参与条件。数量不代表本次一定可用：自动活动匹配角色名和地点名，世界动态匹配世界名及公开标题；来源类型限制、常驻、次级条件和容量仍由核心选择。不要为消除提示公开暗线。刷新失败不报成0条，刷新背景不改变公开范围或触发新批。

## 离线联系

开关已开启与本次恢复结果分开。首次开启和刷新不会立刻发消息；Core仍运行（包括留在托盘）不算离线。最近在线基线是程序运行期间更新的记录，不是下一次消息预约时间。

同理由已处理和本次没有联系使用普通状态提示。旧的“没有联系”码未细分资格/未回复/模型决定等原因，界面明确说明不能确定具体是哪一种。资料暂不可用也不等于角色卡已丢失，先核对已确认角色和私聊即可。失败或取消恢复不会因重新保存开关补发；下一次真实合规恢复继续按原规则判断。

## 用户体验重点

1. 没有模型时能前往模型设置；没有初始地点时能定位设置，不创建新地点或移动玩家。
2. 暂停后看到等待恢复；任务已失败时仍能看到原因。刷新不新增模型用量。
3. 已公开条目数量与书架实际范围一致；仅公开而未触发时，不显示虚假的“可用条目”数量。
4. 事件池无待发布内容时能按提示去标记进度；离线联系正常跳过不再像保存失败。
5. 保存过程中切换设置分类，再回来不会永久显示保存中；连接失败保留上次状态并明确未能核对。

本轮没有运行应用或模型，也没有修改用户存档；静态检查和编译不能代替以上体验验收。多人主动联系、剧情相遇、关系推进和完整离线活动重建仍未完成。
