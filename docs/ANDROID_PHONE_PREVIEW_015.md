# 安卓 0.1.5 手机体验

从发布页下载 dreamtalk-android-0.1.5-arm64.apk，下载完成后覆盖安装旧版安卓预览应用。包名和原发布证书保持；无需卸载或清除数据。Windows 版本没有改动。

首次启动会准备随包 Core 与固定检索资源，请等待打开。生成仍需配置你自己的 API；电脑上的凭据不会迁移到手机。

先验证进入首页、已有世界和角色是否保留，再查看书架、卡包及角色卡。新包默认空：通过“设计与装卡”勾选库卡并保存，随后按住封口任意一端横向划开。卡库没有角色时先用“新卡／导入”。从“全部角色卡”返回后，应只显示卡包操作；再次进入不自动带回旧选择。

再验证真实聊天、记忆、通讯录和人物关系。后台联系需要在应用内同意 API 费用并授予通知及必要后台权限；OriginOS 的后台策略和通知效果待手机验证。

如果启动失败，使用“复制启动诊断”并反馈。先保留安装包和现有数据，不必卸载重装。
