# 产品入口与本地身份边界

本页连接普通界面、会话鉴权及运行世界；现行行为见[PRODUCT](../../PRODUCT.md)，源码定位见[HANDOFF](../../HANDOFF.md)，版本／发行／验收见[状态清单](../PROJECT_STATUS.md)。不再按历史开发日期追加相互覆盖的产品切片。

## 导航和界面

书架负责世界选择、世界书管理、默认模型、存档与更新；进入世界后是聊天、通讯录、设置和“我”。宽窗口侧边导航、窄窗口底部导航与沉浸模式采用同一作用域，不改变世界／玩家身份。聊天目录和记录独立滚动，私聊／群聊共用工作区组件。显示契约见[世界内界面](../WORLD_TERMINAL.md)、[书架](../WORLD_ARCHIVE.md)和[聊天模型](CHAT_MODEL.md)。

普通界面只展示获准信息、真实状态和可执行下一步。后台候选、未公开事件、私人知识及隐藏关系数值不进入全知面板；作者地点／通讯录关系网只显示各自已批准范围。

## 本地玩家身份与鉴权

当前 app-data 代表一个本地用户，每个 World 选择一个已存在 Player 作为“我”。`local_player_bindings` 是本地产品元数据，不是 WorldEvent、PlayerKnowledge 或回放输入；绑定只引用同世界 Player，不删除其他 Player，也不定义云端多人权限。

没有绑定时，“进入世界”沿 canonical CreateLocation、CreatePlayer／PlayerPlaced 及本地绑定建立初始“家”和唯一玩家位置。多步流程保留稳定请求身份；已提交部分是真实账本事实，重试继续而不重复创建。创建世界、保存角色卡、打开通信会话不自动移动玩家或放置角色。

普通业务 HTTP／WebSocket 经版本化 CoreClient、当前会话认证和世界／玩家校验；事件查询再以绑定主体过滤。底层 capability reader 不接收任意 owner 参数。宿主发现／Bearer边界见[运行基础](RUNTIME_FOUNDATION.md)，知识SQL隔离见[访问模型](KNOWLEDGE_ACCESS_MODEL.md)。

## 资料、版本与公开授权

角色卡／世界书经过解析或手动草稿、预览、用户确认，再原子保存 authored content、来源与当前世界 accepted snapshot。同一素材在不同世界分别确认，修改某世界快照不会传播到其他世界；旧版本保留，过期更新拒绝。卡片不是 runtime Character，accepted snapshot 也不自动创建 WorldTruth 或知识。

原生编辑有条目来源对应关系，只有完整内容及触发／兼容字段未变的条目才在同世界更新事务中保留原公开授权；新增、修改、无法对应或文件替换的条目保持隐藏，须重新确认。隐含背景不会因新版保存自动公开。详见[导入](IMPORT_MODEL.md)、[大书编辑](IMPORT_MODEL.md#分页编辑与稀疏修改)和[范围反馈](../SETTINGS_FEEDBACK.md)。

卡／书删除是当前世界作者内容停用和历史保留流程；旧修订不复活，运行身份及账本不物理抹除。内容仓库的不可变图保存与产品删除服务分开，不以“底层仓库无物理删除方法”推断普通界面没有删除入口。

## 个人资料与设定身份

通用及世界专属资料分别以编辑revision保存；名称限120字符、描述限8000字符。世界称呼为空时沿用通用称呼，冲突时已确认世界专属身份优先；完整原文保留，不自动语义合并。个人介绍已进入对话输入，不是 canonical Player 身份、Truth 或自动知情证明。

设定身份支持玩家专用卡／世界书人物或原创身份，须预览确认，逐角色保存其初始认识；来源变化需重新确认。不新增NPC、不放置人物或创建关系网节点；群聊selector不读取角色私有初始认识。详见[身份手册](../PLAYER_PERSONA.md)。

## 聊天、记忆与事件

私聊／固定群聊、显式／自动选人、流式、人工回复恢复、消息编辑候选和聊天路线均有实现；候选／检查点不等于世界时间线回退。长期记忆、会话摘要、聊天历史、亲历观察分别沿来源授权组装。来源回看只读取，话题引用加入草稿后由用户发送；模型生成摘要先预览确认。详见[聊天模型](CHAT_MODEL.md)、[记忆](MEMORY_MODEL.md)、[聊天路线](../CHAT_PATHS_AND_LORE.md)。

“世界事件”分聊天获知、玩家亲历和公共动态。先有当前主体授权，再返回有限投影；角色回复独立读取本人观察，玩家列表不是角色输入的复制源。事件发布或聊天自述不证明计划完成／传闻真实。[事件手册](../WORLD_EVENT_JOURNAL.md)

## 地点、后台和媒体

地点目录及层级、角色初始位置、锁定／访问／移动策略已有实现。作者可维护已批准的地点信息，不枚举隐藏角色状态；Director按本地合法路线规划，Kernel验证后执行。单批角色／地点容量不限制世界总量。[地点](../ACTIVITY_LOCATIONS.md)／[日常](../DIRECTOR_ACTIVITIES.md)

日常、相遇、共同休闲、世界动态及在线／离线联系按各自开关、费用、暂停和防重放规则运行；启动／托盘不等于完整离线演化。双人共同联系沿真实共同休闲、群优先或原子双私聊、共享未回复门禁。用户决定先等待的场景不自动触发诊断。[Director](DIRECTOR_MODEL.md)／[联系](../PROACTIVE_CONTACT.md)

配音、图片／三库表情、聊天背景／角色立绘已有各自实现。文字与媒体权限、缓存及云端费用分开，模型环境／修复／更新由宿主管理；入口见[配音](../CHARACTER_VOICES.md)、[媒体](../CHAT_MEDIA.md)和[聊天视觉](CHAT_MODEL.md#聊天视觉与沉浸模式)。完整存档与更新保护见[存档](../DATA_BACKUPS.md)和[更新](../WINDOWS_UPDATES.md)。
