# dreamtalk 0.1.80 · 存档与更新修复

本版修复更新后启动受阻和备份被误报损坏的问题，减少正常更新需要用户处理的步骤。

- 修复旧存档升级时字段顺序校验不一致导致的启动失败，保留严格迁移检查。
- 修复读取快照产生SQLite临时文件、随后被误判为备份损坏的问题。原数据库、实际日志、配置和素材继续严格核对。
- 启动失败页也能检查更新；已知失败补丁可由修正版接续核对，不必先恢复历史备份。
- 正常启动不再逐份读取历史备份。历史快照和恢复收进展开项，修正恢复确认框尺寸。
- 新快照完成校验后才进入历史列表；修复更新保留原检查点，核对通过才进入世界，不自动重发旧生成任务。

消息与编辑即时保存，自动快照用于找回之前的内容。普通更新保留固定位置的存档，卸载保留数据与独立备份。请勿使用旧版打开已经升级的存档。

提供完整Windows x64安装包、便携ZIP和原应用更新频道。当前仍为预发布体验版，实际跨版本升级、恢复与多场景体验待用户验收；本轮仅完成源码、编译与发行文件核对，没有运行真实存档或模型。

旧程序完全没有更新入口时，需要先使用修正版入口或完整安装包。更新签名沿用原公钥；Windows发布者证书仍在申请中，首次安装可能提示未知发布者。
