# 后台启动与离线期间的消息

## 开启方法

1. 退出旧程序，使用完整当前版本，发行与工作树状态统一见[状态清单](PROJECT_STATUS.md)。不要只复制 EXE，也不要用旧版本打开已升级存档。
2. 选择世界和“我”的身份，在通讯录打开希望参与的角色私聊，使角色实例化；离线私聊不要求角色已有活动地点或开启自动活动。配置可正常使用的聊天模型。
3. 设置 → 后台运行：可开启“登录电脑后自动启动，保持窗口隐藏”和“关闭窗口后继续在托盘运行”，点击保存。默认两项均关闭。托盘双击打开；右键“退出并停止后台运行”彻底退出。便携程序文件夹移动或删除会影响已注册的自启动路径；从桌面版0.1.1起，更换包后打开新版，保持勾选自启动并点击“保存并更新启动位置”即可注册当前程序，无需先关闭再开启。“当前程序位置”显示正在运行的程序，不表示此前自启动登记的目标；只有保存成功才确认本次更新。“刷新设置”仅重新读取状态，未保存的选项会恢复为已保存值。
4. 设置 → 离线期间的消息：默认6个真实小时，允许1–168小时。首次开启明确确认后台模型用量和输入范围。应用只绑定一个世界/玩家作为离线联系目标，在另一个世界开启会替换目标。自动活动与离线联系是分别控制的开关。
5. 点击同一设置区的“刷新状态”核对已保存状态；刷新只读，不调用模型、不重新提交设置。保存中禁止重复点击；失败保留时长和授权界面，并显示具体原因。
6. 首次开启/修改时长只记录基线，不立即补发。退出/关机/睡眠经过设定时长后，登录后台启动或手动重开共用恢复流程。仅窗口隐藏、最小化或暂时不聊天，不算Core停止执行的离线间隔。

## 收到什么

一次恢复最多选择一个角色，生成一条自然问候或之后聊聊/休息的邀请；模型也可以决定不联系。Busy、暂停世界、无合适已打开角色、身份变化、同理由已处理或上条主动私聊仍未获回复都会跳过。不会按每个6小时段补发，也不会因为玩家没有回复而不断催促。

消息显示离线区间内、由规划选择的剧情时间。例如21:00退出、07:00重开，可以显示22:35。真实模型调用、用量和消息创建仍发生于07:00之后；点击“时间详情”查看真实生成时间。聊天记录按持久位置追加，旧记录与真实创建时间不重写。未读根据真实投递记录保留；实际打开可见会话后才标已读，隐藏窗口不自动消除未读。

后台隐藏窗口、其他世界或界面在线记录到期时，本地绑定玩家不被自动当作现场事件的见证者。位置不消失、不移动；已经获得的事件知情记录保留，正常角色见证规则不变。

## 模型、费用与输入

复用当前配置模型、路由和Token/金额硬预算，适用于已有各提供商适配器。Director一次有限计划选择角色/目的/时段，Character单独写最终台词；最多两个有限模型任务，单次输出不超过8192或模型更低上限，实际用量按网关记录。与每轮聊天额度、自动活动的6小时世界时间分开。

输入仅为离线前冻结的已接受角色资料、逐条确认的公共世界书背景和已有活动意图。选人和台词不读取或外发私聊正文、摘要、隐藏条目、私人记忆或未知事件；本地消息标识/位置只用于去重，不发给模型。已有计划不表示离线活动已经执行，更不表示取得成果或见过玩家。资料、玩家消息/身份/状态发生变化时，取消不再适用的结果。

每分钟轻量记录Core在线和合规输入；正常退出再保存一次，崩溃可有约一分钟误差。系统时钟向后调整不会产生负时长或倒退基线。每次恢复先持久记录，再发起模型调用；失败、被中断或模型不联系的结论不会自动付费重放。关闭开关停止未来联系，在途请求仍可能计费。它不是关机时运行的云服务。

## 当前范围与验收

本页主要说明单角色离线消息、托盘与后台启动；当前另有[在线及同事由双人主动联系](PROACTIVE_CONTACT.md)，共用未回复门禁。三人以上/任意Outreach Episode、自动关系推进和完整离线活动/成果重建仍未实现。轻量在线状态与消息回执属于操作性数据，不生成历史WorldEvent或强行给玩家知识。

离线联系按当前玩家已打开的私聊读取有限角色集合，复用既有已确认角色字段投影与公共背景选择。它不依赖Director的“已放置角色”日常活动输入；不会为保存设置创建角色地点或世界事件。

本地输入每批最多准备16位候选，并非只能拥有16位私聊角色。正常在线记录保持同一批次；符合离线时长的恢复之后为下一次准备后续批次，读到末尾再循环。每次最多检查64条私聊关联；整批关联均不可用时，后续在线记录可以继续检查下一批，不因此启动模型任务或增加补消息数量。

角色性格、描述与背景只在本次参考输入中取有界片段，按 UTF-8 与 JSON 转义后的实际字节计算；完整快照仍限制为64 KiB，公共背景与已有活动意图使用剩余空间。原角色卡、世界书和聊天保持完整，不调用模型压缩资料。单个候选关联异常只跳过该候选；公共背景暂不可用时只使用合规角色字段，不改用私密资料。

准备问题单独显示“离线联系资料暂未就绪”。后续准备成功会清除过时的准备错误，但保留真实失败／中断任务的回执，不自动付费重放。保存、刷新或重启不补发已处理的恢复。旧快照没有批次信息也能读取，投递前仍核对原资料版本、身份、状态和新消息，失效结果继续取消。工程检查与真实运行验收边界见[状态清单](PROJECT_STATUS.md)及[本次修复记录](maintenance/2026-10-19-offline-input-capacity.md)。

## 版本与启动位置

设置 → 后台运行显示桌面版本及当前程序完整路径。已开启自启动时，保存按钮仍可点击，每次显式保存通过既有官方插件登记当前程序与后台参数；启动过程不会擅自重写系统设置。读取失败可点击“刷新设置”，该操作不修改注册或调用模型。注册和托盘文件保存是两种操作；部分保存失败会明确提示可能已经更新自启动，须刷新核对后重新保存。
