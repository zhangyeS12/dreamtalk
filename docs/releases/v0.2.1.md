# dreamtalk 0.2.1 · 把角色装进卡包

角色卡现在拥有独立的可视卡库和可拆封卡包。世界书架保持原有外观；在底部胶囊切到角色卡，便可设计卡片、装包、拆包，再把喜欢的角色带入世界。

## 卡片与卡包

- 银行卡比例的角色卡以不同角度悬浮，左右循环浏览。点击后弹出正面，展开时可自由旋转；设计时整卡固定，只移动文字和贴纸。
- 正背面分别设计配色、材质、边框、图片与组件，支持一次对称和撤销。图片可选择显示区域，保留原图供以后重新裁剪。
- 创建卡包并选择装入的库卡。包体有厚度，选中后居中轻颤，可自由旋转查看独立背面；在顶部封口横向划开，卡片散出后进入原悬浮卡环。
- 卡包外观和装卡清单保存在存档中。返回卡包或重新进入角色卡页时都会重新封好，拆包不会消耗卡片；同一张原卡可以属于多个包。
- “全部角色卡”保留原卡库入口。升级不会生成演示卡包，也不会自动把已有角色装包；可以自行新建或导入，再选择收藏到包中。

## 分享与加入世界

- 库卡可分享为完整 CHARX 文件，包含角色作者内容、附带世界书、双面设计、原图及裁剪结果。接收方核对内容和正背面后收藏，仍可继续DIY。
- 自然悬浮时，可把卡片拖到下方切换胶囊，切回世界书后放到目标书上；也可使用“加入世界”按钮。核对并确认后创建独立世界副本，原卡保留。
- 初始地点默认“无”：角色可以聊天，但没有物理位置，不移动，也不出现在地点图。以后可以在世界内选择真实初始地点。
- 完整分享不包含本机各世界的聊天、记忆、位置、运行状态、API设置或凭据；卡包及其他成员卡不会随单卡分享自动导出。

## 修复与数据兼容

- 修复“本次参考内容”展开后关闭入口被旧样式隐藏的问题；长内容滚动后仍可关闭，并支持Esc与焦点返回。
- 沿既有Alembic链增加独立角色卡库与卡包数据表，保留原有世界、角色、聊天及来源关系。各世界中的旧角色不会自动合并为库卡。
- 保持原应用身份、数据位置、更新公钥与频道。升级后请不要用旧程序打开已升级的同一存档。

## 检查与体验范围

用户已反馈本轮卡包正式整合的本机体验没有明显问题。工程检查覆盖卡库／卡包保存与重开、全部历史迁移升级、完整分享导入、双面设计与裁剪、跨页拖入世界、窄屏和已确认网页的视觉对照。

本版沿项目CI门禁和build-only发行流程，发行机器只做源码／载荷隐私、签名、安装器静态解包与下载摘要核对，不运行用户应用、安装器、真实模型或用户存档。精确提交的CI和实际发布结果见状态清单及发行记录；真实应用内升级、旧存档首次升级、跨用户分享和长期使用仍按具体场景验收。
