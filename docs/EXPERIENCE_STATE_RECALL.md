# 活动经历的后续状态召回

本版包含0.1.27共同休闲、原文回看，并改进较早活动经历的聊天依据。活动开始后已经结束或中断，话题检索会优先提供该角色已亲历的实际后续状态；同一次活动不再重复占开始和终态两个名额。原始事件、记忆和聊天原文保留。

在已有真实活动的私聊/群聊里，可问“你之前在那个地点的活动结束了吗？”“那次和铃一起休息后来怎么样？”然后问“现在呢”。历史终态只说明当时结束/中断，当前近况仍由本人最新活动快照确定；工作时段结束不等于交付任务、共同休闲结束不等于关系推进。

系统只关联当前角色有权亲历的记录，以稳定开始事件ID识别同一次活动；不依据名字相同或发生时间相近猜测。只目击开始、没有获准的结束时，仍只能说当时开始。查看不到不能证明从未发生或仍在继续。检索保留近128条授权窗口，最终最多12条/8KiB，没有额外API判断；较远记录和模型语义效果仍有原先限制。

本页记录亲历状态召回的行为约定。当前版本、规范本机入口和迁移链统一见[状态清单](PROJECT_STATUS.md)；使用本机版本时从托盘完全退出旧 dreamtalk，再打开 `artifacts/local-desktop/dreamtalk-desktop.exe`，保留同目录运行资源。旧版本目录和版本号仅保留在历史记录中。

工程端只做静态检查、编译和包核对，未运行应用、数据库升级、测试或模型调用。请体验当事/旁观角色的结束、中断和仅见开始，以及不同角色/世界隔离；不宣称模型已验收。活动状态召回设计见[复用调查](research/2026-10-04-experience-state-reuse.md)。
