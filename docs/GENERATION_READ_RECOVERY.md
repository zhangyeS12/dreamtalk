# 生成失败与聊天读取恢复

本页描述当前读取超时和生成失败边界。版本、已完成检查及用户验收见[状态清单](PROJECT_STATUS.md)；最后一条未回复消息的人工恢复见[聊天手册](CHAT_FUNCTIONAL_EXPERIENCE.md)。

## 读取与语义回退

本地 GET 读取最长等待15秒，页面／作用域切换取消旧读取；世界状态刷新在上一轮完成后继续，失败时减频。读取模型状态、读取失败和确实未配置分别显示，已有会话和消息不因一次读取失败清空。重新读取或刷新记录只读，不触发生成。

付费生成和其他写入不套用 GET 的读取超时，也不会因读取超时自动重发。语义工作每次最多等待3秒，繁忙或超时沿关键词继续；同一时刻最多一个语义工作，迟到结果不进入已结束请求，工作完成后仍可复用缓存。原生库准备顺序见[启动约束](CORE_NATIVE_STARTUP.md)。

## 世界动态生成

提示提供恰好10条的结构示例，标题、正文、重复、条数和时间字段仍在本地校验。候选默认立即可用、24小时过期；实际采用最多5条进行中、绿灰补位、最近批次8／10续批，具体时间窗口及旧队列兼容见[世界事件](WORLD_EVENT_JOURNAL.md)。不再沿用早期15～45分钟随机发布说明。

失败按格式、空内容、截断、超时、额度或容量说明；安全诊断仅保留约束类别和脱敏路径，不保存失败正文、密钥或任意提供方错误。格式校验不是剧情真实性核实。失败结果不发布、不自动付费修复；显式“生成新一批（调用模型）”是独立新任务。

## 排错与验收

先区分本地读取失败、语义回退和模型任务失败。记录具体状态文字与时间，在当前授权范围内核对脱敏证据；不凭旧日志认定新的根因，不要求用户提供密钥或私聊全文。冷启动读取、跨页面／世界取消、失败后只读刷新及事件池人工新请求分别验收；不把历史编译或旧诊断扩大为当前通过。
