# 校园示例世界

当前源码提供以下受控示例。版本、公开发行与实际对话验收见[状态清单](PROJECT_STATUS.md)；首次交付和隔离检查的历史证据见[发行记录](maintenance/2026-10-16-release-0181.md)与[开发记录](maintenance/2026-10-16-ci-campus-example.md)，不代表当前真实API表现已验收。

在世界书架点击“体验校园示例”，查看角色与世界书，再点击“确认设定并创建示例世界”。示例不会在启动时自动导入，也不会替换已有世界。

示例名为“晴川高中 · 青春日常”，包含：

| 角色 | 简单设定 |
| --- | --- |
| 沈清禾 | 清纯文静的校花，温柔慢热，喜欢读书与画画。 |
| 夏小满 | 青梅竹马的女同桌，活泼直率，爱吐槽也很关心你。 |
| 周明远 | 经常一起行动的好兄弟，开朗讲义气，喜欢打球和聊天。 |

三位均为17岁的高二学生。世界书只有校园背景、班级与同学、常去的地方、校园生活四条简单设定；不预设恋爱或复杂剧情。创建前可以逐条决定是否作为公共背景，确认后仅选中的条目提供给角色。教室、操场、图书馆、食堂会通过正常地点创建流程加入，角色初始位于教室，你仍从家开始。

创建不调用模型、不读取密钥，不开启活动、主动联系、动态或配音。首次聊天前仍需要填写或导入API配置；正式聊天按当前模型配置与额度执行。角色卡开场白只作为设定保存，不伪造已发送消息。

示例创建后就是普通世界。可在通讯录编辑或删除角色，在书架管理世界书；身份在“我”中修改。可以按正常流程删除整本示例世界。

本机创建中断时保留同一次请求与进度。未完成的世界不出现在正常书架；重新打开示例入口可点击“继续创建”。已完成请求再次确认只返回原世界，不覆盖后续编辑或重新公开已隐藏条目。

内容为项目原创，随仓库Apache-2.0提供。实现参考成熟产品的预置内容入口，沿用本项目现有角色卡、世界书预览确认、世界管理和Kernel命令，不复制第三方角色或源码。
