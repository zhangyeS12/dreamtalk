# dreamtalk 0.1.77 · 配音与表情可靠性修复

本次修复0.1.76代码审查发现的问题，继续提供Windows x64安装包和便携版，仍为预发布体验版。

- 本地配音可持续生成，消除服务累计任务记录达到上限后无法继续配音的问题；六小时声音缓存和旧任务防重复生成规则保持。
- 开启“表情不限频率”后，连续发表情不再重置普通图片的发送间隔；每轮仍最多一张，群聊角色共用。
- 表情列表读取只取说明等信息，原图按可见位置加载，减少大图库的额外内存占用。
- 更换图片分析API密钥会清理旧引用，保存失败重试复用同一待保存引用，避免长期更换后无法保存。
- TXT聊天导出补齐附件说明和元数据，和JSON一样不嵌入原图。
- 配音／图片凭据管理统一内部实现，旧本地配音接口不再绕过完整性检查；修正文档的旧版本、入口和重试说明。

升级前从托盘退出旧程序，再使用完整新版安装包或完整解压便携包。已部署本地配音的用户在“设置 → 角色配音”点击“一键修复本地配音”，空闲时更新桥接并重新连接；不会自动重新提交旧配音。不关闭未知程序，不重装模型权重。

声音缓存过期或失败后，点击“播放配音”可以发起一次新尝试；有有效缓存时直接重播。点击“重新配音”生成独立候选，试听结束后由你决定替换或保留。详见[配音手册](../CHARACTER_VOICES.md)和[表情与图片](../CHAT_MEDIA.md)。

本地配音效果、角色发送及新增表情识别已有前轮具体用户确认。免费云端最新版和付费配音API仍待确认，本次发布不扩大为全部媒体、升级或模型场景通过。工程端仅完成静态检查、编译和发布载荷核对，未运行自动测试、模型或真实存档迁移。
