# 世界档案库（桌面 0.1.10）

启动后的首页是横向世界书架。每本有名字的书对应现有世界档案，保留原角色、聊天、身份、事件和记忆；白灰色空白书位只是添加入口，不会保存演示世界，也不是数量限制。书的正面与书脊目前采用文字封面，三张图片封面尚未实现。

## 使用

1. 选择已有书查看摘要，点击“进入世界”。已有绑定身份时进入聊天；首次进入没有身份的世界时打开“我”，选择身份或从家开始。
2. 添加世界：点击空白书或“新建 / 导入世界”，填写世界名并确认创建档案。随后在展开的管理区域点击“新建世界书”（可手动填写或联网生成），或选择 JSON 文件导入。
3. 检查草稿、预览并确认保存。世界档案已创建时，即使取消世界书编辑，该档案也会保留，之后可以继续完善。
4. 已有世界的书右侧有“管理 / 导入世界书”。编辑、文件更新、联网生成与公共背景范围都在这里；世界内的设置页仅管理角色卡，不再混放世界书。
5. 页头“模型设置”复用原配置界面，可在进入世界前配置联网创作使用的模型。保存仍会重启核心并重新连接，因此回到书架；不会在保存配置时测试密钥或产生模型费用。
6. 进入后保留聊天／通讯录／设置／我四个底部入口，页头“返回书架”可切换世界。返回会关闭当前业务界面；有未保存的资料、聊天草稿或处理中的请求时提示确认，已发起的模型请求可能继续产生用量。

创建结果未知时保留原名称和请求 ID，点击“核对上次创建结果”，避免重复创建。明确名称校验错误允许修改。书架显示加载与失败信息，有“刷新书架”入口；刷新和预览不重放联网生成。世界时间状态通常每 15 秒只读更新。

## 信息和运行边界

- 选书只预览，不创建或绑定玩家，不自动暂停／恢复世界，不改变后台授权，也不计作玩家在线。明确进入业务界面后才报告该世界的桌面可见状态。
- 返回书架不停止 Core；已经开启的自动活动、动态池、离线联系继续遵循既有授权和开关。预览页面不显示或标记聊天消息已读。
- 摘要来自所选世界已确认的世界书；不展示假消息、推算的综合未读、关系数值或全知活动。作者管理内容不等于角色获得知识，更不等于真实世界事件。
- 隐藏世界书仍默认隐藏。希望角色或已授权后台规划参考的条目，需在书架管理里逐条确认公共背景；旧权限、预算和知识边界沿用。
- Windows 开机自启动的后台模式不变。重构没有设置或替换自启动路径，也没有更换存档、数据目录或迁移规则。

## 更新与验收

从旧托盘“退出并停止后台运行”，直接运行完整的 `world-archive/dreamtalk/dreamtalk-desktop.exe`，保留同目录 `core/`；本机已生成完整目录，不必再次解压 ZIP。在世界内“设置 → 后台运行”确认桌面版本 0.1.10；需要自启动新目录时显式点击“保存并更新启动位置”。已有存档由原 Core 读取，不要求重新导入角色或世界书。

源码审查、ESLint／TypeScript、release 编译及包内字节核对不代替实际体验。按 AGENTS 第20节未修改／运行自动化测试，也未启动应用、GUI、真实模型或用户存档诊断。既有 ProductApp 测试仍含旧首页直接展示四个标签、设置下拉切世界的断言，需要后续获准按新流程调整；本轮没有删除、跳过或弱化这些测试。

建议用户核对：空书创建、JSON 导入与确认、联网生成结果检查、已有世界进入／返回、两个世界间资料隔离、编辑取消与失败重试、键盘焦点、窄窗口和系统减少动画偏好。三张图片封面和业务页进一步视觉整理是后续任务。
