# 世界档案库

启动后的首页是一间暗着的档案室：一排首尾相接的书架，背后的大窗外是你上次进入的那个世界此刻的天空，书脊被这片天色勾出轮廓。没有上次进入的世界时，窗外是夜空。初始只看见一排书脊，不默认抽出任何书。每本有名字的书对应现有世界档案；未印刷的深色空白书只作为添加入口，不保存演示世界。书位数量为 `max(12, 世界数 + 1)`，已有世界在前、空白书在后，与真实数据顺序一致。视觉方向见[概念稿](product/world-sky-concept.html)。

## 浏览与进入

- 书架是一个环：拖动、滚轮或左右按钮浏览，首尾相接；松手后带惯性并对齐到一本书脊。离中心越远的书越往后退、越暗越虚。系统减少动画时即时切换，没有惯性。
- 鼠标停在一本书上，那本书轻轻滑出、书脊轮廓变亮；点击后完全抽出并转向展示封面，其他书变暗。右上角标签显示世界名、天色条、真实世界时间与时段、暂停状态和世界书摘要；底部是“进入世界 →”“设计这本书”“管理 / 导入世界书”和单独的“删除世界”。
- 完全抽出的书可以按住拖动 360 度查看（上下最多倾斜约 25 度），双击或“正面”回到封面；“正面 / 书脊 / 背面 / 书口”转到对应面。左右按钮切换上一本、下一本世界，Esc 或点击空白处放回书架。
- 键盘与读屏：每本书都是一个按钮（第一圈），Tab 或左右方向键在书之间移动，被聚焦的那本会转到中间；Enter、空格或读屏的“激活”抽出这本书。抽出后焦点不在书按钮上时，左右方向键每次转 90 度。
- 每本世界书的书脊顶端有一条天色带，表示那个世界此刻的时辰；暂停的世界为灰色。天色只由已读取的 `world_time` 计算，不表示事件或活动。
- 点击空白书后显示“创建世界”和“导入世界书”。创建档案后会打开该世界的世界书面板，可以添加，也可以“收起”稍后再完善。新世界印在最后一个世界之后的空白书位上：图案从书脊中线向两边铺开。世界数达到 12 本后，书架滑入一本新的空白书，保持“世界数 + 1”。删除世界后书位恢复为空白。
- 进入世界时，封面翻开，书页里是那个世界此刻的天空，随后落进世界内界面；窗外天色同时变为那个世界的时辰。减少动画或后台窗口直接进入。首次进入没有身份的世界时打开“我”。

## 实现

| 部分 | 源码 |
| --- | --- |
| 环形书架、悬停、抽出与 360 度转动 | `apps/web/src/WorldShelf.tsx`（帧循环）；位置、包圈与朝向计算在 `world/archive/ring.ts` |
| 立体书与各面绘制 | `world/archive/Book3D.tsx`；书的外观数据由 `world/archive/bookLook.ts` 从封面记录组装 |
| 档案室背景与窗外天色 | `world/archive/ArchiveRoom.tsx` |
| 页面、预览标签、面板与进入动画 | `apps/web/src/WorldArchivePage.tsx` |

帧循环只在有东西在动时运行，静止后停止。每帧只计算一次全部书位，并且只写入真正变化的样式；书本组件经过记忆化，设计一本书时只有那一本重新渲染。窗口隐藏或节流导致没有动画帧时，选中结果在动画帧停止约 0.6 秒后回报，不会在书还没抽出时提前回报。档案室舞台用 `overflow: clip`，键盘或点击聚焦书本时浏览器不会把整个舞台横向滚走。没有新依赖。

## 编辑与刷新

“管理 / 导入世界书”“模型设置”“存档”“体验校园示例”以玻璃面板打开，复用原有的手动／联网草稿、文件导入、预览确认和公共背景设置；面板打开时 Tab 只在面板内循环，Esc 收起。角色卡在世界内“通讯录”管理。书本外观见[世界书封面与书本设计](WORLD_COVERS.md)。

创建结果未知时保留原名称和请求ID，再次点击“核对上次创建结果”，避免重复创建。已有模型／世界书编辑、书本设计或未提交的名称表单，在切书或离开时提示确认。

右上角始终有“刷新书架”；读取失败提示也有刷新入口。刷新只读状态和摘要，不重放联网生成。世界状态通常每15秒只读更新，所选摘要按真实世界ID加载并防止迟到结果串入其他世界。窗口隐藏、失去焦点或两分钟无操作时，窗外星光暂停闪烁。

## 信息与运行边界

- 选书只预览，不创建／绑定玩家，不自动暂停／恢复世界，不改变后台授权，不计作玩家在线，也不加载／标记聊天已读。明确进入业务界面后才报告该世界的桌面可见状态。
- 返回书架不停止Core。已开启的自动活动、动态池、离线联系继续按既有授权和开关运行。
- 简介来自已确认世界书；不展示假消息、推算未读、关系数值或全知活动。管理设定不等于角色获得知识，更不等于真实世界事件。
