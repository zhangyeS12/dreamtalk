# dreamtalk 0.1.85 · 设定身份与角色的初始认识

- 世界内“我”页新增“设定身份与初始认识”：可明确选择当前世界书条目或角色卡对应的人物，也可填写原创身份，避免仅凭同名猜测你是谁。
- 可编辑公开身份介绍、故事起点，并分别设置每位角色与你的初始关系及起初知道的详情；预览并确认后才采用。
- 私聊、群聊和主动联系使用确认后的身份背景，按发言角色过滤私人认识；共同邀请只使用双方共有的信息。
- 绑定资料被替换、移除或停用后暂停引用，重新选择并确认后恢复。保留原玩家、聊天及已有资料，不把初始认识写成新发生的世界事件。
- 补充并发编辑、玩家切换、长资料分页及Unicode输入保护，身份数据纳入现有完整存档流程。

提供完整 Windows x64 安装包、便携 ZIP 及原应用内更新频道。沿用原应用标识、数据位置、更新公钥和一自动四手动存档，不需要清空数据。

仍为预发布体验版。隔离回归、CI和build-only打包不代表真实升级、存档恢复或模型理解效果已验收；实际应用内升级及身份体验由用户确认。更新签名不等于Windows发布者证书。
