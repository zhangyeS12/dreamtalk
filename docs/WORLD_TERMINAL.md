# 世界内的天幕界面

进入世界后，整个窗口就是这个世界的天空：天色、太阳或月亮、星星、云和远山铺满背景，界面以半透明玻璃面板浮在其上。方向由用户于2026-10-28在[概念稿](product/world-sky-concept.html)基础上确认；版本与验收状态见[状态清单](PROJECT_STATUS.md)。

## 页面结构

- 天空与标题：背景天色、日月位置与星光只由已读取的 `world_time` 计算（`apps/web/src/world/sky.ts`），暂停时云和星光停住并降低饱和度；世界名以大字写在天空上，下方为真实世界时间与时段（深夜／黎明／清晨／白昼／黄昏／入夜）和暂停／运行异常状态，右侧为普通／沉浸切换（仅聊天页）和返回书架。没有虚构天气、在线人数、活动或统计。
- 导航：聊天／通讯录／设置／我四入口位于左侧玻璃导航条，图标下方显示文字，当前入口为日金色；860px 以下改为底部横排，顺序不变。红点只显示真实未读；沉浸模式隐藏导航。
- 聊天：左侧玻璃会话目录（世界事件始终置顶、名字筛选、置顶星标、未读红点、群聊叠放头像），右侧玻璃对话面。每位角色有由身份派生的固定专属色，只用于头像底色、名字和台词旁细线，不表达关系或状态；同一群内颜色冲突时就近错开。用户上传的角色背景铺在对话面玻璃之下。
- 对话：角色回复按剧本排版，名字与时刻在左侧页边，旁白偏暗、引号台词偏亮；玩家消息为右侧月白小气泡。编辑、候选、反馈、参考内容和配音等单条操作在悬停或键盘聚焦时出现。输入区为悬浮胶囊，表情、正文与日金发送键同一行，模型状态、失败、恢复与费用提示保留在胶囊上方。
- 沉浸模式：会话目录与导航退场，对话移到左侧，用户上传的角色立绘站在右侧并被天色勾出轮廓。没有上传立绘时只显示背景，不用头像或生成图片代替。
- 通讯录、设置与“我”：沿用原有页面结构，换成同一套暗色玻璃主题；名字筛选、阵营、打开会话、草稿／导入、三维关系网、七类设置手册与身份草稿等行为不变。世界事件与来源弹窗保留原句、时间、来源和权限提示。

空白会话与未选角色页面使用原 Logo 及静态几何星轨，不放示例角色或假消息。

## 动态与可访问性

- 动态只用于天色过渡、星光、云和控件状态。窗口隐藏、失去焦点或两分钟无操作时，星光和云暂停（`world/useWindowStill.ts`），因为每一帧也会让玻璃面板重新模糊；世界时间和数据刷新不受影响。系统“减少动态效果”关闭这些动画。
- 模型状态与生成进度是一个常驻的 `role="status"` 区域，工作区提示同样常驻，读屏能听到每次变化；错误用 `role="alert"`。
- 原生表单、details 和 dialog 继续承担键盘行为。

## 检查与用户验收

`npm run test:web-smoke`（`scripts/browser-smoke.py`）在隔离数据中走完书架、示例世界、聊天、通讯录、设置和“我”的主要路径。`scripts/visual-check.py` 截取各页面截图，并在按钮文字几乎透明或通讯录详情无法滚动时失败；两者都不调用模型、不读真实存档。

用户验收重点：

1. 私聊／群聊的长消息、流式、分页、滚动、发送、已读红点、人工恢复和费用提示。
2. 会话与角色名字筛选、清除、无匹配结果；群聊创建和世界事件入口。
3. 头像和立绘上传后回到聊天，沉浸模式下有立绘与无立绘两种情况。
4. 设置与个人身份编辑后切页，确认草稿、保存结果、后台费用和错误提示完整可见。
5. 700px 以下窗口、较矮窗口、系统缩放与减少动态效果；导航与输入区不遮挡必要操作。

这些是待用户验收项，不表示工程端已执行或已通过运行验证。
