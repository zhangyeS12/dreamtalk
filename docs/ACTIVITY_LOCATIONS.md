# 地点与角色位置（0.1.41）

在当前世界的“通讯录”使用“添加／编辑地点”，入口就在“添加／编辑角色卡”下方。选择已有地点可改名称、父地点、隐藏分支和开放角色；选择“＋ 添加地点”新建。“家”是系统初始地点，不能编辑；同世界规范化同名会被拒绝。名称1–120字，当前世界最多32个地点（含家），最多16位活动角色。

地点可层层包含：璃月 → 璃月城 → 往生堂。每层都是独立的真实地点，角色可以直接处于璃月。包含关系不是道路或物理同场，不会自动移动玩家，不把世界书中的地名自动创建成地点。没有地点删除／路线／玩家前往按钮。

## 初始地点与锁定

在“角色资料”选择初始地点，点击“保存位置规则”。不需要先发送消息；新角色首次保存会创建／复用聊天身份，并放置到所选地点。初始地点是活动范围：角色只能在该地点及获准子地点之间移动，可以从往生堂返回璃月城或璃月，也可以在范围内选择另一子地点。活动仍需要在设置中独立开启，不新增付费调用或随机移动循环。

“锁定在初始地点”没有另一个目标下拉框。胡桃初始地点为璃月，如果她已移动到往生堂，保存锁定就会通过世界内核立即回到璃月，原活动结束／中断，然后只能停留在璃月。修改初始地点也会在保存时放置到新的初始地点。解锁且初始地点未变时保留合法当前位置，不自动启动活动或立即请求规划。

位置属于同一世界的稳定角色身份，更新角色卡或切换玩家不会复制角色位置。旧存档初始地点按首次真实放置恢复；既有范围外位置不会在迁移时被改写，可在这里保存规则返回，下一次活动仍必须满足新范围。

## 隐藏分支

勾选“隐藏这个分支”，再逐个选择开放角色。隐藏璃月城会限制璃月城及其所有子地点；对子地点有授权，但没有隐藏父地点的授权，仍不能进入。如果往生堂自己也设为隐藏，还需对该角色在往生堂单独开放。未开过会话的新角色可以先保存公开初始地点，或打开一次会话，再选择隐藏分支开放对象。

作者在地点图中仍能看到隐藏地点（虚线圆），角色的活动目录和执行准入按权限过滤。隐藏不会删除过去亲历记忆，也不会自动修改独立公开的世界书内容。如果某角色现在或初始地点在被隐藏的分支，需保留其开放，或者先调整其初始地点，再撤销权限。移动包含分支使当前位置越出角色范围也会被拒绝。

## 地点图

在“角色资料／编辑阵营／人物关系网”右侧选择“地点”。二维嵌套圆表示包含关系，圆形头像位于角色实际所在地点；直接在父地点的头像不会画入子地点。拖动平移、滚轮或按钮缩放、总览复位；点击头像在右侧查看全名、“初始地点－当前位置”和聊天入口。例如“璃月－往生堂”，前者是活动范围的根，后者是当前位置。尚未配置的角色在“未设置位置”中列出。

目录与位置每5秒只读刷新，离开通讯录停止刷新。图是用户明确要求的作者配置视图，不代表玩家在世界中自动获知或现场见证。相遇和共同休闲只在双方完全相同地点ID时准入，璃月与璃月城不算同场；原活动授权和节奏保持。

手动编辑不调用模型。已开启的自动活动在下一常规批次参考角色获准地点，执行时再次检查最新范围／锁定／隐藏权限。修改地点不主动产生额外重规划。网络失败保留草稿与原请求，可用原请求重试，或只读刷新；切换地点／角色时注意尚未保存的编辑。
