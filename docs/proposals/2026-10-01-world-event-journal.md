# 已批准：聊天获知和公共动态事件池

2026-10-01。用户明确批准先按讨论执行，完成两块世界事件，DeepSeek优先，之后逐步适配其他模型。本文记录已授权的范围，不是新的审批要求。

聊天回复采用同次模型请求返回reply和可选events；最多3条具体活动／计划／传闻／邀请／变化，原句精确校验和授权引用核对，保存回复与记录在同一事务。获知现实时间、获知世界时间与原话时间分开。历史保留，明确变化关联旧记录，用户可批注和隐藏。没有单独付费分类器或自动旧消息回填，没有由台词生成WorldTruth、Knowledge、Observation或Memory。

公共世界动态每世界默认关闭，首次开启授权当前公开背景和后台费用。单批10条，有界隐藏候选，Kernel在当前有效世界时间逐条发布；实际公告事实为PublicWorldEventPublished v1，不宣称正文所述物理结果已发生。固定整批80%已处理后续批；用户绿色已经历／灰色跳过均计处理，发布和过期不计处理。每批只续一次，旧未处理保留，总未处理上限100。空池未达80%或错误需要显式生成，付费任务中断不自动重发。

复用原世界scheduler、SQLAlchemy／Alembic、公开世界书筛选、受治理模型路由及预算、EventAppender／replay。世界暂停不发布，关机不调用，恢复不补造历史。与原Director日常6小时／50%机制独立，金融路由沿用director_plan，普通群聊选人不参与事件分类。

首版自动聊天提取仅官方DeepSeek JSON object，流式用已安装pydantic-core解析reply并本地严格验证events，无新依赖。其他服务保持原聊天，不擅自换模型。说明和验收边界见[使用说明](../WORLD_EVENT_JOURNAL.md)，来源／许可见[复用调查](../research/2026-10-01-world-event-journal-reuse.md)。
