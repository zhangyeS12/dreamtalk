# 可视角色卡库

首页底部的“世界书／角色卡”胶囊在原世界书架和角色卡库之间切换。世界书继续使用原来的环形书架、封面设计和进入流程。卡库是整份本机存档中的独立资料库；它不属于某一个世界，不保存各世界的聊天和角色经历。

## 卡包与装卡

切换到角色卡页先显示卡包。新存档没有演示包；“全部角色卡”保留原卡库入口，已有卡片不会因升级自动装包或丢失。可以先从空白卡位新建／导入角色，再创建卡包，在“设计与装卡”中选择要装入的库卡。一个包最多1024张卡，同一原卡可以属于多个包；装入／移出只改变有序引用，不移动或复制模板，不加入任何世界。

选中卡包后居中并轻颤，包体有厚度，可水平360度旋转和改变俯仰，正背面独立显示。拖动包体只旋转，在顶部封口任意一端按住横向划到另一端才打开；未完成、失焦或取消恢复封口。键盘方向键转动、Home回正，聚焦封口后Enter打开；减少动态效果时直接过渡。空包会提示先装卡。

卡片散出后直接进入原悬浮卡环；原卡仍保留。“返回卡包”或重新切入角色卡页时都重新封好，不保存消耗、随机抽取或永久已拆状态。在已打开卡包中新建／导入角色时，同时加入该包；如果装包请求失败，已保存原卡仍在“全部角色卡”，界面说明可返回设计器重新选择，不伪报装包成功。

卡包DIY沿确认网页的固定画布和留边侧栏，整包固定，仅文字／贴纸组件可拖动。两面分别保存材质、颜色、符号、边框、图片、文字与贴纸，支持一次对称及撤销、上传裁剪及原图重裁。图片与角色卡使用相同格式／尺寸／10 MiB安全限制，裁剪输出900×1286 WebP，读取按包ID鉴权。创建包前上传的图片仅暂存，保存包时原子提交图片引用、设计和装卡清单；取消释放暂存读取资格，暂存至多一小时。图片不进入模型提示。

保存使用包修订号CAS；同一保存的重试幂等，冲突保留草稿，不自动覆盖其他修改。包名称、介绍、设计、成员引用与图片在整份存档中保存，重开恢复；拆包过程只改变界面状态。单卡CHARX分享沿下文原流程，不自动携带所在卡包或其他卡片。

正式页和独立[网页预览](previews/CARD_PACKS.md)使用同一组`world/cards/packs/`组件、样式及箔面纹理。正式页只多`PackCollection`数据／图片适配器，未另写外观。固定视觉基准见`tests/fixtures/card_pack_visual_reference/`，合成存档的正式整合检查为`scripts/card-packs-integration-check.py`。

## 浏览、创建与加入

- 卡片按银行卡长宽比横向制作，保持间隔、不同的稳定倾角和轻微悬浮；左右拖动空白处、滚轮或左右按钮浏览，首尾相接。空白卡位为 `max(2, 8 - 角色卡数)`，点击后新建或导入。
- 点击卡片会向中间弹出并展示正面。此时拖动只旋转卡片，不移动整卡；“正面／背面”可直接翻面，“归位”回到自然悬浮状态。窗口隐藏、失焦、闲置或系统减少动画时暂停装饰性漂浮。
- 新建使用原生角色稿；文件导入复用现有 JSON／PNG／CHARX 解析器和32 MiB上限。先预览角色正文、附带世界书和兼容提示，再明确确认保存到卡库。V3不可读而采用V2时，确认按钮明确说明回退。预览不创建世界或运行角色，不调用模型。
- 悬浮状态下可以拖动整卡。在下方胶囊上停留约550毫秒切到原世界书架，卡片继续跟随指针；放到具体世界书上后，核对内容和初始地点，再确认加入。Esc取消拖动。展开及DIY状态禁止整卡拖动；展开后的“加入世界”也可选择目标世界。
- 原卡始终留在卡库。每次加入建立独立的世界内容图和运行身份，不共享不同世界的聊天、记忆或位置。之后修改原卡正文或卡面，不自动改写已加入世界的副本；世界内仍通过通讯录编辑和删除该副本。
- 同一库卡在同一世界的有效副本不重复添加；删除世界内副本后可以重新加入，旧历史保持原有规则。删除整个世界不会删除库卡，也不会删除其他世界的副本。

已有世界里的角色卡仍保留在各自通讯录，不自动迁移、合并或按同名建立库卡。可在角色卡页导入原角色卡文件；新库卡不代表已经关联原世界角色。玩家专用卡继续从“我”页导入，不进入此NPC模板库。

## 完整角色卡分享

展开库卡后点击“分享角色卡”，核对双面卡面和文件大小，再选择“保存完整角色卡”。桌面版使用系统保存窗口，网页版交给浏览器下载；取消保存不显示成功。文件使用`.charx`，整包最大32 MiB。接收方从空白卡位进入“新建角色卡 → 从文件导入”，可在确认前切换正背面核对；确认后建立新的库卡，原卡保留，不按名字覆盖。

分享包含当前角色作者内容图、卡片自带世界书及兼容扩展、与当前模板有关的原始角色文件、双面DIY设计，以及两面当前引用的原图与裁剪图。组件锚点／位置／大小／旋转／透明度、材质、边框和裁剪区域完整保留；收藏后仍可分别编辑和重新裁剪。不会附带本机的世界副本、来源关联、聊天、记忆、位置、运行状态、API设置或凭据。未引用的旧图片和原始文件历史不随包导出；再次分享不会把上一份完整分享包反复嵌套。

外层沿[Character Card V3规范](https://github.com/kwaroran/character-card-spec-v3/blob/main/SPEC_V3.md#charx)3.0的CHARX约定：根目录`card.json`提供CCv3主体，`dreamtalk.json`保存版本化卡面清单，`dreamtalk.lwcontent`复用既有原生作者内容容器保存完整语义，`assets/x_dreamtalk/images/`只包含被当前卡面引用的图片。标准主体中的单一世界书使用第一份附带书；未指定正则的关键词按字面词导出，多份书、原始未指定语义及其他作者字段在原生内容容器完整保留。dreamtalk以校验后的原生内容恢复；其他应用对扩展和卡面效果的支持取决于其实现，不承诺跨软件还原DIY。

导出绑定当前卡修订号与文件摘要，核对后发生修改会拒绝下载。导入在内存中验证版本、完整成员清单、摘要、作者图闭包、图片尺寸／格式和卡面字段；拒绝损坏、缺图、越界路径和附带未知文件的完整卡片，不静默退回仅正文导入。预览中的图片仅供当前已鉴权会话按预览ID读取；取消／过期后不可读取，确认前不建立库卡或图片元数据。确认时原子保存模板与图片元数据，独立内容寻址图片先验证写入；没有提取外部路径、下载远程资源或执行插件的过程。

成熟实现复用：CCv3 3.0公开规范（MIT，仅参考格式，独立实现）、现有`LwContentAdapter`及`JsonContentExporter`（项目Apache-2.0）、已有Pillow图片校验和Tauri原生导出保存链路；无新增依赖。设计写入与分享导入共用`application/card_design.py`的有界字段模型。

## 无地点

加入世界及世界内新建／导入角色时，初始地点默认“无”。角色具备通讯录身份，可以聊天，但没有物理位置，不移动、不参加需要在场的活动，也不显示在地点图或未放置列表中。不创建名为“无”的占位地点。

以后可在世界内“角色资料 → 初始地点与移动倾向”选择真实地点并保存，沿既有Kernel放置命令开始物理生活。已有位置不会因此次升级被清空；当前没有把已放置角色再次设为无地点的操作。玩家仍遵循唯一真实位置的既有契约。

## 卡面设计与图片

“设计卡面”沿已确认网页使用留边侧栏，背景舞台保持清晰，整卡固定；正背面分别保存配色、材质、边框、布局、图片和组件。五组配色圆点、星轨装饰、文字排版和控件分组保留原预览；“角色设定”单独编辑角色正文。材质有哑光、金属、亮面、虹彩；每面最多24个文字／贴纸组件，支持直接拖动位置，以及大小、旋转、透明度、颜色和删除控制。设计器中的角色名称和身份描述只改变卡面；角色正文通过“角色设定”单独编辑并预览确认。

“对称到背面”复制当前完整正面设计，保留文字正常阅读方向；它是一次复制，两面之后各自独立。“撤销”恢复本次复制前的背面，范围限当前设计会话。取消设计不保存，离开脏稿须确认。

添加静态JPG／PNG／WebP图片先打开裁剪器，支持拖动、滚轮／滑杆缩放、90度旋转、四角／滑杆调整固定比例裁剪框。明确使用所选区域后才替换当前面的图片；取消裁剪保留原面。原图、裁剪结果及旋转／百分比区域分开保存，可重新裁剪；正背面互不覆盖。上限10 MiB、2000万像素、最长边10000像素，复用Pillow方向校正与安全解码，输出1200×757 WebP。图片通过卡ID限定的本机会话鉴权接口读取，不使用远程图片地址或把图片塞进角色提示。

正文和卡面保存均校验卡修订号，冲突保留草稿，不静默覆盖。已发起确认的结果未知时，只能由用户再次核对相同请求；不会自动重放模型或收费任务。预览有数量和15分钟有效期限制，关闭时释放未提交预览。

已有长正文完整读取，编辑时只提交变化的字段；未修改的已接受字段和附带世界书完整保留。新建或修改的字段继续执行现有有界稿校验，不因改一个短字段而截断其他长字段。

## 已确认视觉基准

正式展示层以用户已确认的网页为基准，不能在接入数据时重新设计。固定合成基准保存在[视觉基准](../tests/fixtures/character_card_visual_reference/README.md)，不进入产品数据或运行代码。`scripts/card-library-visual-parity.py`在1440×900、900×800、390×844比较正式设计器与该基准的卡片、侧栏几何和像素；只屏蔽双方实际卡ID不同的编号文字。修改基准须有新的明确视觉决定，不能为取得通过结果改写基准。

新稿组件使用与预览相同的中心锚点；缺少锚点字段的已有卡面保持原起点坐标解释，不批量改写用户已保存的图层、图片或裁剪数据。功能回归与视觉对照分别验证，二者都不替代真实桌面用户验收。
