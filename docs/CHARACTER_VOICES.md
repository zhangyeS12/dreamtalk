# 角色配音与音色卡

当前版本沿用本地配音的长期运行上限、桥接校验、3个独立采样候选、原参考与BF16、模型最大容量、容量内整段、六小时缓存、试听替换、已登记服务自动启动和一键修复。2026-10-13用户确认本地效果良好；免费云端最新版和付费API仍待确认。这些反馈不扩大为全部缓存、替换、修复或多场景验收。当前Windows发布、CI与验收边界统一见[状态清单](PROJECT_STATUS.md)和[0.1.90发行记录](maintenance/2026-10-25-release-0190.md)。应用不下载或内置这些配音权重／参考录音；请先部署对应模型，再登记目录。

## 开始使用

1. 准备一段 WAV 或 MP3 参考人声，0.5～15 秒、最大 10 MB。建议使用 5～10 秒清晰、连续、单人说话，尽量去掉背景音乐；也可以直接使用别人提供的 .voicecard 音色卡。
2. 进入世界，在“通讯录 → 角色资料 → 角色音色”选择文件，查看预览后点击“确认导入并绑定”。例如分别给胡桃、钟离、香菱绑定各自参考人声。
3. 打开“设置 → 角色配音”。本地方式选择已部署的模型目录，勾选开启并保存；默认地址服务随 dreamtalk 启动，不需保留终端。远程方式填必要密钥与确认项后保存。
4. 正常聊天。角色文字回复完整保存后才生成声音并播放，群聊逐人按回复顺序播放。

没有显卡可选择官方演示免费额度或付费云服务。导入参考人声不会训练模型，也不会立即发送到服务；首次为角色回复配音时才使用它。声音相似度取决于参考录音和模型，应用不内置角色录音。

## 绑定、试听与导出

每位角色同时使用一张音色卡，同一张卡可给多位角色使用。绑定属于当前世界，跟随角色的稳定身份；改名、换头像、更新角色资料不会串音或丢失绑定。在另一世界使用同一音色，需要导出并重新导入。

- “试听参考人声”播放导入录音，不调用配音模型。
- “保存角色音色”确认选择；选择“不配音”并保存可解除绑定。
- “导出音色卡”保存可分享的 .voicecard 文件，不含服务密钥、云账户音色 ID 或聊天内容。
- “删除音色卡”会解除当前世界所有使用该卡的角色绑定；文字、记忆和历史已生成声音不因此删除。

聊天消息旁可手动播放或停止。声音从生成成功并保存时起缓存6小时，音色与配音设置未改变时，期间重播不调用模型、不计生成次数，也不延长有效期。没有有效缓存、上次失败或缓存已过期时，点击“播放配音”会创建新的生成尝试；正在生成则继续等待同一个任务。切换会话或页面、回到书架、窗口隐藏或失去焦点会停止播放。重新打开会话不会自动朗读旧历史，后台主动联系不会在隐藏窗口中配音。

密钥在桌面版的本机安全凭据存储中保存。浏览器版可以使用匿名官方演示；需要安全密钥的服务请用桌面版。

## 播放与费用限制

配音设置按世界独立，默认关闭。开启后新回复自动发起配音，付费确认同时授权这些自动任务，配音费用独立于文字聊天 Token 额度。

- 每条最多 1～2,000 字，默认 1,600；超长完整保留文字并提示，不悄悄裁掉后半段。
- 本地配音不设每日次数上限；云端路线默认20，可设1～1,000。UTC日期按本机所有世界云端累计与当前世界设置比较，失败或未知结果也计次；新增本地回执不占云端次数，旧版无法分类的回执保守计入当天云端准入。
- 一次只生成／播放一条，等待播放队列最多 8 条；超过队列的消息可手动选择。
- 声音缓存保存6小时，到期自动清理；退出期间不执行清理，下次启动先清理过期声音。所有世界合计仍最多256 MB，容量不足可能提前清理，任务与次数回执保留。没有有效缓存时，手动点击会重新生成；失败或结果不明不会自动重试，付费路线的新尝试另计费用。
- 停止配音只停止等待和播放，不承诺撤回服务已接纳的生成任务或费用；重启不会重放中断任务。
- 默认跳过括号中的内容和独立一行的星号动作描写。规则是文字清理，不调用其他模型分析；若括号中也有台词，可关闭此项。

云服务的积分查询不是锁价或人民币账单硬上限。平台价格变化、排队与最终音色效果需实际体验确认。没有绑定音色、服务失败或声音播放受限时，会给出提示；文字回复、聊天记忆和继续聊天仍可用。

## 可选本地部署

这部分只适合希望自行部署模型的用户，普通用户可直接使用上述远程路线。模型与项目 Core 使用不同环境，不要把 Torch、CUDA 或模型权重安装到 dreamtalk 的 Core 环境。

先按 [IndexTTS 官方中文说明](https://github.com/index-tts/index-tts/blob/main/docs/README_zh.md)在一个独立目录安装当前 IndexTTS 2.5，下载 IndexTeam/IndexTTS-2.5 到 checkpoints，确认存在 config.yaml。Windows 可用官方 `uv sync --extra webui` 路线，避免默认安装较难配置的 DeepSpeed；显卡、CUDA 和模型环境以官方要求为准。模型使用 [Bilibili Model Use License](https://github.com/index-tts/index-tts/blob/main/LICENSE)，本项目不分发其权重。

已完成本地部署的用户直接在设置选择包含 `.venv`、`checkpoints`、`indextts` 和密钥文件的模型目录，无需再次下载或创建密钥。默认地址由应用管理，保存开启后随应用启动。

首次自行部署时，可将包内 [serve-indextts.py](../scripts/serve-indextts.py)复制到官方项目目录；仅在本地访问密钥文件尚不存在时执行以下命令。已有密钥不要覆盖，否则已保存的服务配置会失配。命令只生成文件，不打印密钥：

```powershell
$voiceAccess = ([guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N'))
Set-Content -LiteralPath (Join-Path (Get-Location) 'dreamtalk-voice-token.txt') -Value $voiceAccess -NoNewline -Encoding ascii
Remove-Variable voiceAccess
```

需要独立管理服务或使用自定义地址时，可以在同一目录用官方模型环境手动启动桥接服务；使用应用管理方式不必执行这一步：

```powershell
uv run python serve-indextts.py --model-dir ./checkpoints --token-file ./dreamtalk-voice-token.txt --port 7861
```

应用管理默认地址时，从已登记目录读取密钥并通过本机安全存储配置，无需前端回显。独立管理其他本地地址时按该服务填写地址与访问密钥。密钥文件不要上传、分享或放进音色卡。服务只监听本机、按需加载模型；文字聊天与配音失败分开。

桥接请求 BF16、使用标准 PyTorch 路径并关闭可选自定义 CUDA 内核编译，不要求为此安装完整 Toolkit。上游自动选择可用设备，也有 CPU 路径；实际 GPU 与精度需要运行证据，不能只看请求参数。安装文件或服务监听成功不等于生成与声音效果已经验收。

使用已登记目录和默认地址时，开启配音后重启 dreamtalk 会启动独立服务；无法连接或提示旧服务时，点击设置中的“一键修复本地配音”。程序会核对并更新确认归属且空闲的旧桥接、同步凭据并重新连接。正在生成或无法确认归属的服务会保留并显示原因；修复不重发配音、不续期缓存。自定义地址仍由用户管理，旧手动启动器不是普通使用步骤。

### 如何制作音色卡

1. 用音频剪辑工具准备一段单人的清楚人声，建议 6～12 秒，避免配乐、多人重叠、削波和长静音。当前导入支持 0.5～15 秒 WAV／MP3，文件最多 10 MiB。
2. 在“通讯录 → 角色资料 → 角色音色”选择音频，试听参考人声，填写名字，确认导入并绑定。试听参考人声不调用模型。
3. 点击“导出音色卡”，保存 `.voicecard`；其他用户导入后再绑定自己的角色。角色绑定、服务密钥、聊天和模型权重不随卡导出。

音色卡是参考人声与声明式配置的包装，不是训练后的模型。直接导入 WAV／MP3 会自动生成中文、语速 1 的卡；同一音频与同一配置的推理效果相同，打包不会改善音质或降低模型显存需求。卡的好处是将名字、语言、语速和作者说明与音源一起保存、复用和分享。改变音源或实际推理参数才可能改变效果；录音文字说明目前不参与推理。

## .voicecard 格式

文件是 ZIP，恰好包含 manifest.json 和 reference.wav 或 reference.mp3；不包含程序、模型权重或服务密钥。直接导入原始音频会自动生成中文、语速 1 的音色卡。

```json
{
  "format": "dreamtalk.voicecard",
  "version": 1,
  "engine": "indextts-2.5",
  "name": "角色音色",
  "language": "ZH",
  "reference": "reference.wav",
  "reference_text": "",
  "description": "",
  "author": "",
  "license": "",
  "speed": 1
}
```

language 可为 ZH、EN、JA、ES、AR；speed 范围 0.5～2。reference_text 是可选录音文字说明，目前只保存和导出，不参与推理。卡中不能包含其他未定义字段。语言、语速和作者说明可由制卡者写入文件后导入；本版界面不提供音频剪辑、训练或情感曲线编辑。

### 随应用启动与真实进度

本地方式登记已部署模型目录后保存开启。之后启动 dreamtalk 会在后台启动服务，首次配音才加载模型；退出关闭应用启动的服务，托盘保持运行。遇到旧服务提示或未启动，可在设置点击“一键修复本地配音”，结果直接显示在页面；不需要自行查进程／端口。自定义地址、未知程序或早期无法核对空闲的服务不自动关闭，具体边界见[修复说明](maintenance/2026-10-13-local-speech-one-click-repair.md)。

配音显示加载模型、文本处理、第几段合成、保存声音、准备播放与实际播放，以及等待时间。阶段没有更新会提示耗时较长，不把服务在线当作推理必然有进展。前台停止不撤销已接纳的任务，完成后可点击原消息读取缓存；退出或结果不明不会自动再次生成。详情见[维护记录](maintenance/2026-10-12-speech-progress.md)。

上次配音失败时，修正服务问题后可再次点击原消息的“播放配音”发起新尝试，不需要新建聊天回复。生成中重复操作复用同一任务；同一请求编号不会重复提交。原任务和次数记录保留，程序启动、刷新或后台不会自行重试。详情见[6小时缓存说明](maintenance/2026-10-12-speech-cache-retry.md)。

## 等待时间与常见提示

| 提示 | 含义与处理 |
| --- | --- |
| 正在加载本地模型 | 收到任务后惰性加载，首次使用可能较慢；不能仅按加载时间判断后续合成速度 |
| 第1/1段、已等待68秒 | 第几段来自最近的合成回调；秒数是从任务登记起的总时间，包含此前连接、加载和处理，不是纯合成耗时 |
| 此阶段耗时较长 | 最近阶段／段数长时间没有变化；能查询状态不代表推理必然有进展，可停止前台等待 |
| 本地连接检查未在10秒内完成 | 状态检查无法完成；不同于模型任务或已创建服务的启动期限 |
| 本地服务未在20秒内就绪 | 应用持有服务进程但未在启动等待期限内确认就绪，按实际服务日志排查 |
| 配音未完成／缓存已过期 | 没有有效音频；修正服务问题后可手动点击原消息重新生成，付费路线按新任务计费 |
| 准备播放／播放器未能播放 | 模型声音已经返回；仍需核对前台音频读取和播放器，不将其说成模型仍在合成 |

当前没有测得“多少字必在多少秒内完成”的保证，也没有完整冷／热启动、设备和分阶段性能结论。最新耗时问题的证据、参数和后续排查见[交接说明](maintenance/2026-10-12-speech-latency-handoff.md)。

点击“重新配音”会再次调用所选服务，本地不限生成次数；云端计入一次生成次数和该路线可能的费用；已有声音仍保留。新声音完成后点击消息下方“试听新配音”，播放结束后必须选择“替换之前的配音”或“保留之前的配音”。中断试听不确认替换；离开会话不自动决定，返回可继续处理。新旧音频都按各自成功保存起六小时清理，替换不延长期限。

本地桥接revision8将防重复的请求标识及固定结果持久保存在独立模型环境，不保存台词／参考录音；音频仍六小时过期，内存缓存有界。不会因累计1,024个任务拒绝新生成。更新旧服务请使用设置中的“一键修复本地配音”；不再支持缺少健康／版本校验的旧服务直连。详见[审查修复记录](maintenance/2026-10-14-review-fixes-release.md)。
