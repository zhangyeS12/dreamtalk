# dreamtalk 0.1.42 · 地点与模型适配体验版

本版合并0.1.41地点优化与0.1.42模型服务适配，并包含0.1.38～0.1.40维护。用户于2026-10-08明确授权发布到GitHub；按预发布提供Windows x64完整便携包，不推定最新版整体验收。

## 下载和开始

- 在[本版Release](https://github.com/zhangyeS12/dreamtalk/releases/tag/v0.1.42)下载 **dreamtalk-0.1.42-windows-x64.zip**，完整解压后打开`dreamtalk/dreamtalk-desktop.exe`，保留同目录`core/`。GitHub的Source code附件是源码，不能直接运行。
- Windows 10/11 x64，需要WebView2 Runtime；无需安装Python、Node或Rust。
- 使用自己的模型服务和API Key；保存设置不会探测密钥或调用模型，聊天及明确启用的后台任务可能产生服务商费用。后台功能默认关闭。
- 更新前先从旧版托盘退出并备份重要应用数据。程序尚未签名，没有自动更新；自启动路径需在新版显式保存更新，升级后的存档不要交给旧版打开。

## 本版变化

- 地点与角色初始位置移到通讯录：多层父子包含、根与子地点往返、初始活动范围、锁定立即返回初始地点、隐藏分支逐角色开放；二维嵌套圆与头像显示当前位置，详情显示初始地点－当前位置。相遇/共同活动要求完全相同地点。
- OpenAI Responses、Anthropic Messages、Gemini Interactions和兼容Chat Completions服务接入同次聊天事件/长期记忆；不额外补提取，合法完整普通台词也允许没有新条目。
- 改进厂商原生JSON Schema的wire副本兼容，本地继续按原始schema严格校验；高级模型设置可显式保存超时及按具体型号确认的原生能力。
- 保留严格整轮Token硬上限，显示一次调用的输入预留与回复所需额度；群聊选人、多个角色和内部重试仍共享额度。Claude/Gemini继续可信模型容量预留，不将估算作为严格上界。
- 继承通讯录主区扩大、条件邀约/主动邀请记录、世界动态最多5条进行中/绿灰补位/历史折叠、持久全文/向量派生索引和最多200条聊天窗口。
