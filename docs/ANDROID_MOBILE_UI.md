# 安卓手机界面

首页按用户最新要求保留上下等半，并复用 Windows 的书本、角色卡与卡包设计及操作。普通世界内界面沿已确认网页的夜色蓝、月白、暖金、Logo 和阅读层次。世界、角色、关系、存档与消息来自 Core，不把合成预览内容装入应用。工程检查与用户验收分别记录在[状态清单](PROJECT_STATUS.md)。

## 首页与世界书

可用应用视口从水平中线等分：上半世界书架，下半卡包与独立卡库；安全区计入各自半屏。两半屏独立循环。书架复用 Windows 的 WorldShelf，横向跟手、松手衰减和停靠沿原控制器；卡环复用 CardRing，保留自由停留的位置。手机横拖卡面或空白处浏览，明确竖拖卡片才进入持卡；超过阈值后锁定本次方向。按下立即捕获，拖动与轻点分开，取消不误打开；减少动态时保留跟手并简化动画。

世界书沿 Windows 的 WorldShelf、ArchiveRoom、Book3DFaces 和 bookLook；NativeBookShelf 只测量当前舞台，在物件坐标系上适配半屏，控制栏保持手机实际触控尺寸，拖动坐标按舞台比例换算。逻辑书位至少十二，已有世界在前；首帧和后续都最多挂载二十五个附近物件，并保留所选书。材质、厚度、正面／书脊／背面、贴纸及天窗沿保存设计，书脊间距继续按原厚度计算，扩大点击区域不再扩大视觉间距。

点书后，同一个书本物件在原书列中连续抽出，归位也回到原书位；不另挂一份查看模型。背景书列沿原逻辑退暗；查看层可拖动旋转360度、上下倾斜约25度，并直接转到正面、书脊、背面、书口。双击回正面，收起、Escape或点击查看区域空白归位。查看不进入世界、不初始化玩家、不标记聊天已读或调用模型。设计书本使用原编辑器，取消与保存继续保护草稿。明确进入世界后才切到业务界面。

窗外天色读取兼容键 livingworld.lastWorldId 对应世界的真实 world_time；缺少有效世界时使用默认夜空。只预览其他书不改最近进入世界。返回首页会按最近进入的世界取色，页面可见时每十五秒只读刷新世界时间；不因刷新取消手势或重新创建世界。世界时间按共享 worldClock／formatClock 显示。

## 角色卡与卡包

下半屏先显示真实卡包；首次无包时只有创建入口，不自动生成演示包、角色或把旧通讯录角色收集进库。“全部角色卡”始终保留。由卡包浏览页新建的角色在预览确认保存后，直接进入真实卡环查看；在包内创建并成功装入时保留包范围，装包结果不明时展示已保存的原卡并明确提示待核对。

卡包直接使用现有 CardPackLibrary、PackBody／PackFace、PackEditor、PackSpill 与原箔面样式。手机浏览轨道按连续位移跟手，同一包体从浏览进入选中；不再把浏览和选中拆成两套物件。浏览首尾循环；选中后居中，包体有厚度，可拖动旋转查看独立正背面。按住顶部封口一端横向划到另一端才打开，未完成、取消或失焦恢复封口；键盘可转动、回正和打开。空包在封口处和操作栏直接提示先装卡，突出“设计与装卡”并将封口标为不可用；保存至少一张有效库卡引用后恢复拆封。新建包不会自动收集库中角色。封口说明明确从任意一端划到另一端，中央起手或其他失败原因在操作栏可见，不能只留给屏幕阅读器。

剪开只改变界面状态，散出的卡片落入同一角色卡环；包内数量不减少。返回卡包、重新进入或重开应用都会重新封好。散卡期间卡环不能被提前激活；手机动画最多绘制前十六张，完整成员始终可在卡环中浏览。

“设计与装卡”复用原编辑器；手机编辑器挂到应用根层，避开半屏场景的隔离层和首页标题；上方固定物件画布、下方独立滚动编辑区，保存／取消保留固定位置。装卡复选框22px、整行至少44px，不沿通用文本框撑满宽度。保存包名称、介绍、双面材质／配色／图片／图层以及有序库卡引用。支持组件拖动、对称与撤销、上传裁剪和原图重裁。同一原卡可被多个包装入，加入／移出只改变引用，不复制模板或加入世界。包内新建／文件导入角色时，先保存原卡再装包；装包结果不明时明确提示原卡已保存，不能伪报装包成功。

保存继续沿现有修订号CAS与同次保存重试契约；冲突保留草稿。删除先确认对象和范围，后端确认后才播放原燃烧消散效果；删除包不删除库卡，各世界副本保留。失败、冲突或未知结果不自动重试。卡包没有新增整包分享或导入格式；单张角色卡继续分享完整CHARX。

角色卡直接使用 Windows CardRing 和 CardFaces，按银行卡比例、真实双面设计及原倾角陈列。同一个卡片物件完成浏览、抽出、360度旋转、编辑返回和归位，选中后在下半屏居中摆正，周围卡片退暗；正面、背面或归位按钮可直接操作。设计、设定编辑、分享、加入世界和删除继续调用原组件。加入前预览、初始地点选择与确认保持，原卡和各世界副本独立；角色卡删除也从卡包引用中移除，保留各世界副本。

从卡环返回卡包时，同时退出角色卡查看、重置翻面请求并清理持卡及目标高亮；在绘制前同步卡包阶段，恢复卡包／卡库数量和浏览操作栏。再次进入卡环从未选中状态浏览，编辑器关闭返回仍沿当前卡片预览。

跨区向上持卡可放到世界书：仅打开已经预选目标世界的加入预览，用户明确确认后才提交。取消／松在空白处不加入；已有副本不重复加入。按钮“加入世界”继续走同一预览确认契约。卡包本身与角色卡都不调用生成模型。

## 视觉、资源与运行成本

半屏内展示和操作分别适配，保持品牌、物件材质和主体比例。控制栏集中到边缘，保留44px触控高度及完整无障碍名称；短横屏把标题与操作排到左右两侧，物件保留每半屏可用高度。书的四个切面收入展开菜单，卡片翻面、设计、加入及归位在紧凑操作栏中。所选书卡不使用管理弹窗代替旋转。设计／导入／确认等表单仍使用受保护的编辑层。立体物件的容器保持 preserve-3d，不施加会压平子面的 filter／透明度分组；远近明暗在书面层绘制。

书架只挂载附近实例、上限二十五；角色卡与浏览卡包各五个。封面只读取可见及展开世界的素材，图片超时不阻断真实文字。卡包元数据不等待图片完成才显示；只请求附近包和有限散卡素材，最多两路并发、三十二个缓存URL，取消读取并在离开时释放。

拖动、旋转和衰减通过原控制器更新变换；窗口范围变化才调整挂载列表。保留 Windows 原有的轻微悬浮与包体等待动作，减少动态、隐藏／失焦或空闲时按原 useWindowStill 暂停；选中停稳后不维持逐帧交互循环。没有引入物理引擎或 WebGL。原单卡CHARX的Core容器限制保持，Android通用64 MiB传输保护不会放宽后端内容规则；保存沿系统文档选择器，取消不重导出。实际Android触摸、内存、耗电与vivo表现仍待用户验收。

复用本项目Apache-2.0源码边界b235670及安卓既有迁移副本中的书卡／卡包组件和共享HTTP客户端。没有新增框架、依赖、数据库、模型或模型部署入口。

## 世界内界面

聊天、通讯录、设置、我四入口及未保存输入保护保持。会话目录使用真实头像、姓名／群成员搜索、私聊／群聊筛选、既有置顶与未读排序，每页三十项；DTO没有消息摘要／时间时不补假内容。

直接与群聊复用既有工作流，私密遮罩、历史分页、流式、费用／Token上限及恢复保持。通讯录保留资料、动态卡片、地点、阵营、表情包、音色和世界风格，人物关系继续二维阵营圆环，地点继续包含图。十一类设置、Keystore和玩家身份／角色卡确认流程不变。

## 源码与验收

- mobile/ArchiveHome.tsx：真实世界、卡库与卡包编排、天色和编辑确认入口。
- WorldShelf.tsx、mobile/NativeBookShelf.tsx：原书架控制器、有限实例、物件舞台及坐标比例。
- world/cards/CardRing.tsx、mobile/ArchiveCardDeck.tsx：原角色卡物件、双面旋转、窗口化和手机方向锁定手势。
- mobile/useMobilePacks.ts：数据、可选素材和原保存／装卡接口。
- world/cards/packs/：原包体、封口、散卡、设计／装卡与删除效果；手机适配通过可选embedded属性。
- mobile/archive.css、mobile/design.css：半屏与手机视觉；其余聊天／资料组件入口保持。

本机交付沿[本机验收](ANDROID_LOCAL_ACCEPTANCE.md)。工程使用合成数据和隔离存储，浏览器和数据库检查不读取日常模拟器中的用户内容，也不代表原生视觉、真机性能或用户通过。
