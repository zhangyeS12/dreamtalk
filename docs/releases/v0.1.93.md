# dreamtalk 0.1.93 · 天幕界面与书本设计

本版本未独立发行，开发阶段改动已合并进入[0.2.0前端里程碑](v0.2.0.md)。以下保留准备阶段的范围；当前发行及验收以状态清单为准。

## 本次更新

- 全新的启动动画：一本印着 dreamtalk 标识的书在台灯下自己翻开，纸艺立体的星空、新月和山脊从书页间立起；书架准备好后，镜头飞进那片纸做的天空，光圈打开，书架出现。系统开启“减少动态效果”时仍显示静态标识。
- 进入世界后，整个窗口是这个世界此刻的天空：天色、太阳或月亮、星星、云和远山随世界时间变化，聊天、通讯录、设置和“我”以半透明玻璃面板浮在上面；世界暂停时天空随之停住。
- 角色回复改为剧本式排版：名字与时刻在左侧，旁白偏暗、引号里的台词偏亮；你的消息仍是右侧的小气泡。每位角色有固定的专属颜色。
- 世界书架改为首尾相接的环：鼠标停在书上会轻轻滑出，点击后完全抽出，可以按住拖动 360 度转着看。窗外是你上次进入的那个世界此刻的天色。
- 新增“设计这本书”：可以选择模板、材质、颜色、厚度、书口金边和整体书衣，上传正面／书脊／背面图片，设置书名的字体、颜色和横竖排，添加内置或自己上传的贴纸，放置显示世界天色的小窗，也可以关闭 dreamtalk 标识。旧封面会自动转换。
- 聊天可设置当前世界的通用背景和角色专属背景，并为角色上传表情立绘；聊天页可切换“普通／沉浸”。沉浸模式下按角色最新回复的语气显示对应立绘；没有上传立绘时只显示背景。
- 会话可以置顶；有未读角色消息的会话排在前面。角色回复下方可以点赞或点踩，作为之后回复风格的参考，不写入角色卡、记忆或世界事实。
- 书架和书本设计器支持键盘和读屏：每本书都能用 Tab 选中、Enter 抽出；设计画布上的书名、贴纸和天窗可以用方向键微调。
- 窗口在后台、失去焦点或两分钟没有操作时，星光和云停止动画，降低显卡占用。

## 数据与兼容

- 新增两个只追加的数据迁移：`0060_chat_preferences`（会话置顶、回复反馈）和 `0061_chat_visuals`（聊天背景与表情立绘）。旧消息和已有字段不变；首次启动时自动升级，并沿用更新前备份。
- 书本设计保存在原有的世界封面记录中，没有新增迁移。旧版本程序打开时会忽略设计数据，仍显示原来的标题和图片。
- 应用标识、更新签名公钥和更新频道不变。

## 验证边界
