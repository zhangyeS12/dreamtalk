# 星梦启动与应用标识

用户于2026-10-04确认使用自己提供的日月星轨 Logo，要求真正三维的梦幻流星漩涡，准备好后镜头进入中心并显示书架。Desktop **0.1.35**；本轮另修复主动联系HTTP设置保存，不改协议、迁移、模型调用规则或系统启动注册。

## 当前效果与实现

- `apps/web/public/brand/dreamtalk-logo.png`保留用户原PNG字节（1350×1165、RGBA）。HTML预启动、React启动页、书架及世界内页头共用它；书籍左上角dreamtalk文字标识保留。
- 原图嵌入透明方形SVG，仅补上下留白，不裁切、拉伸、重绘。复用Tauri CLI **2.11.4**生成Windows多尺寸ICO、默认窗口/托盘PNG与浏览器favicon；`scripts/generate-brand-icons.py`可复现转换，不依赖用户Downloads文件或额外图像库。
- Three.js **0.186.1**的PerspectiveCamera/WebGLRenderer/BufferGeometry/ShaderMaterial渲染26条真实空间轨道：轨道分布在5层深度、整体倾斜、前后透视、近大远小、光头与渐淡光尾。中央不透明珍珠色球体遮挡后方轨迹，暖金/月蓝光源形成球面明暗；900个空间星点有透视尺度及缓慢亮度变化。不是平面Canvas/CSS旋转圆环。
- 原Logo与银蓝/暖金深空从HTML首屏出现；JS接管后渐入三维画面，正常界面不显示“正在连接核心”。保留无障碍启动状态文字，开发者检查器仍可显示技术状态。
- 原核心发现、health及generation确认仍保留15秒期限，独立并行于动画。用户新增要求：前台从首帧三维画面开始，至少可见旋转1.5秒；即使核心和书架已就绪也不跳过。最低展示满足且真实世界列表/有界封面已准备好后，才进行约900ms相机推进与透明交接（快速启动通常是1.5秒展示加0.9秒交接，另有模块准备时间）。书架已挂载于背后且启动期禁止操作；不是让核心多连接1.5秒、不伪造进度、不进入世界或调用模型。
- 书架准备另有15秒失败期限。封面元数据失败可用默认外观，图片读取总计最多等待5秒后回退已有缓存/文字外观；不会因可选图片永久挡住进入。正常刷新书架可以重新读取，不改已存图片。
- 核心或书架失败显示“暂时无法打开世界书架”和“重新打开”；按钮只重新发现/读取，不重启付费任务或修改保存内容。真正Core启动失败仍可能需要用户退出后重开，不把动画当修复。

## 性能与生命周期

三维场景按需加载，共享关系网已有Three.js依赖；不增加框架或外部CDN。GPU计算光尾曲线，复用几何/材质/纹理，像素比上限1.65，不使用整屏多级后处理。

document可见性与Tauri原生窗口visible/minimized状态共同控制：原生可见性尚未确定时不提前结束；隐藏自启动不创建WebGL、不强制展示，数据就绪后可完成。最小化/后台暂停渲染和前台展示计时，完成后取消RAF、监听、计时器与ResizeObserver并释放资源。减少动态效果使用静态Logo至少1.5秒再短淡出，WebGL不可用同样保留静态标识。

原生可见性查询失败保守使用静态版本；三维模块加载或首帧准备最多3秒，失败/超时释放未完成场景并回退静态Logo。核心快速就绪不再阻止三维模块建立；1.5秒从首帧而非组件挂载开始计算。后台数据准备不依赖requestAnimationFrame，避免隐藏窗口无法退出启动状态。

## 用户验收

1. 先从托盘退出旧版，再从`artifacts/portable/startup-proactive-fix/dreamtalk/dreamtalk-desktop.exe`打开0.1.35。确认标题栏、任务栏、托盘及页头新标识。
2. 正常启动看到深空Logo及前后流星光尾，球面明暗/遮挡和相机推进有纵深；进入的是原世界书架，书本与封面出现正常，无技术连接文字或空白闪屏。
3. 快速再次打开也应看到至少1.5秒旋转，再镜头推进；真实准备较久时展示自然延长，失败可重试。减少动态效果/图形不可用时至少展示1.5秒静态Logo。
4. 最小化/托盘返回、隐藏自启动、减少动态效果与实际设备流畅度由用户体验。更换便携路径不会自动改自启动；需要在新版设置显式保存并更新启动位置。

以上是验收步骤，不表示工程端已执行。
