# dreamtalk 0.1.86 · 酒馆角色卡兼容优化

- 修复 character_book 为 null 时整张角色卡被拒绝的问题；常见缺失字段、空值、单条问候和旧版字段写法可兼容转换，原始内容保留。
- 扩展 V1、V2、V3 JSON／PNG 与旧 Pygmalion 角色卡导入，增加 CHARX 包内角色主体读取；未提取附件会明确提示。
- 角色主体可用时，异常附带世界书、个别条目或可选元数据单独提示，不再一并阻断主体。没有启用的部分保留来源，不会静默丢弃。
- PNG 优先读取有效 V3；若只能读取 V2，预览和确认按钮会明确说明，用户确认后才保存。
- 文件与 JSON 容量统一为 32 MiB；导入错误会区分字段、格式、容量与连接问题，批量兼容提示可以展开查看涉及字段。

提供完整 Windows x64 安装包、便携 ZIP 及原应用内更新频道。保留原更新公钥、应用标识、数据位置、身份、聊天及完整存档，不需要清空数据。

仍为预发布体验版。本次按用户要求不运行 CI 或自动化测试，只核对源码、编译、静态载荷、签名和下载；真实导入、保存重启、导出往返、升级与恢复仍待用户验收。导入兼容不代表支持酒馆所有插件、脚本或提示编排；更新签名不等于 Windows 发布者证书。
