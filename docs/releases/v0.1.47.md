# dreamtalk 0.1.47

新增角色卡和地点删除入口，阵营删除按钮及限制提示更清楚。

- 在角色资料或角色卡管理中删除角色卡；历史聊天和事件保留，旧私聊与含该角色的群聊转为只读。
- 在地点编辑中删除不再使用的地点；有子地点、角色初始／当前位置或玩家停留时会提示先调整，避免误删。
- 已删除角色退出通讯录、关系图和后续活动／主动联系，重新导入会创建新身份。

包含 0.1.46 新增的应用更新入口、全局“不再自动弹窗”设置、完整 Windows 签名安装包和升级恢复保护，以及此前世界独立模型配置、角色常驻／远行优化和封面缓存回收。

此版本为预发布体验版，删除和跨版本更新仍待用户验收。旧无更新器的便携版本需先退出程序，再手动安装。世界及聊天数据保留；更新签名不等于 Windows 发布者证书。
