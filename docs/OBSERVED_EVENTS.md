# dreamtalk：已获知事件与聊天

本版补充现有世界事件入口的详情，以及角色自己的亲历事件输入。单聊、群聊、聊天回忆、可确认记忆摘要和流式功能保留。

聊天 → 左侧置顶“世界事件” → 查看详情 → “聊聊这件事” → 选择已有私聊/群聊 → 核对输入草稿 → 手动发送。每条详情来自当前世界、当前绑定玩家的亲历记录；角色回复另读它自己的记录。没有亲历的角色不能因为后台存在记录而自动知情。聊天中听到的说法仍是消息，不自动确认世界事实。

当前支持移动/放置事件的有限中文模板。旧观察、未知版本和其他事件只显示通用标题；不显示关系数值或私人背景。名称为当前世界实体标签，不是历史名称快照。玩家列表最多100条；角色输入最多12条、8KiB。普通 UI 尚无移动操作、初始放置不产生亲历记录，所以没有这些记录的存档仍可能显示空时间线；本版不伪造活动、不回填历史授权。

Director 批量计划、角色自动活动、相遇和主动联系尚未实现。没有新增数据库表或额外模型调用；既有存档如果还未升级到前版的0024，会由原启动迁移流程升级摘要表，升级后不要用不认识该 schema 的旧程序打开。

源码审查、lint/type、Core/desktop 编译与包内哈希核对完成后才交付。按项目约定，未新增/执行测试、启动应用、调用真实 API 或操作用户存档；具体聊天效果和权限隔离由用户验收。可检查既有亲历记录是否正确描述/引用，换世界/身份是否隔离，未亲历角色是否避免装作知情。若没有这类记录，空时间线是预期，不应为了验收修改真实存档或重复生成角色卡。
