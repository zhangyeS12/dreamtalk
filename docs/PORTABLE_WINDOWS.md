# dreamtalk Windows 便携版

将整个 `dreamtalk` 文件夹解压后运行 `dreamtalk-desktop.exe`。请勿只复制 exe：`core/` 文件夹包含随附的 Python Core 和迁移脚本。使用 Windows 10/11，并确保系统有 WebView2 Runtime。无需另行安装 Python、uv、Node 或 Rust。

应用数据保存在本机用户的 Tauri app-data 目录，不会写入解压目录。此版没有代码签名或自动更新；Windows 可能显示未知发布者提示。请先在非重要数据上试用，并保留自己的应用数据备份。

首次打开显示世界档案书架，可创建或选择世界；页头“模型设置”与世界内设置都可以配置自己的模型服务。常见服务与模型会自动匹配容量，通常只需选择回复长度；未识别的模型需在高级设置核对输入容量。DeepSeek 官方文本聊天按当前上下文保守预留额度，其他暂不支持的服务仍按模型容量预留；程序不会在保存模型配置时测试密钥。后台功能默认关闭；已经明确开启的自动活动和离线联系在启动恢复后可能调用模型并产生费用。角色对话需要可用的模型服务和用户自己的 API 凭据，可能产生服务商费用。

本地便携版不是 GitHub 正式发布。项目源码采用 Apache-2.0 许可证；发布前仍需完成产品功能与用户验收。

角色卡入口：进入当前世界后，打开“通讯录 → 添加角色卡”，点击“新建角色卡”。世界书入口：在书架选择世界，点击“管理 / 导入世界书 → 新建世界书”。可以直接填写，也可以输入“生成一个绝区零里艾莲的角色卡”并点击“联网生成”。配置的模型负责整理搜索摘要，生成会产生模型用量；联网搜索还需要本机能访问搜索引擎。查看出处、修改字段后点击“预览并保存”，最后确认加入当前世界。角色在通讯录中显示；世界书条目默认隐藏，可在书架管理中逐条设为公共背景。

已有内容可点击“编辑”，文件导入位于“从文件导入”。生成等待超时或重启后，可以重新打开相应新建界面点击“检查生成结果”；此操作只读取结果。需要重新生成时，新的生成会产生新的模型调用。新版本自动增加独立生成回执表；更新前关闭旧程序，再解压整个新版目录，应用数据仍使用原来的 app-data 位置。

搜索、解析与请求预留组件的第三方许可证附在 third-party-licenses/；源码许可证见 LICENSE。联网资料依据目前为检索摘要，确认保存前请核对出处和 AI 创作建议。

后台自启动、托盘和离线期间的消息见随包 OFFLINE_MESSAGES.md，自动活动见 DIRECTOR.md。离线联系可以使用尚未设置活动地点的私聊角色；设置区的“刷新状态”仅核对保存结果，不调用模型。两个后台模型功能分别开启、分别授权，默认均关闭。

桌面版0.1.1：在“设置 → 后台运行”核对当前版本和程序位置。更换包后，保持勾选自启动并点击“保存并更新启动位置”，无需关闭再开启；只有显式保存才更新登记。“刷新设置”只读取状态。退出旧程序应使用托盘右键“退出并停止后台运行”，再打开完整新版文件夹，避免单实例机制继续展示旧进程。源码、Core和协议的兼容标识保持原样，0.1.1是桌面版本。

桌面版0.1.2新增“设置 → 角色初始活动地点”：先在通讯录打开私聊，再明确选择角色和地点并确认，角色才有参与自动活动所需的初始位置。保存不调用模型，已有位置不可在此修改；自动活动按独立开关运行。详见随包ACTIVITY_LOCATIONS.md。后台版本显示及显式更新自启动位置继续沿用0.1.1功能。

桌面0.1.3补齐角色自身活动的聊天情境：在既有自动活动真实开始后，可以问角色“你在忙什么？”；私聊和群聊按发言角色的自身观察与当前世界时间参考活动。没有额外后台模型任务，过期时段不会冒充完成成果。完整操作与边界见随包DIRECTOR.md。更换目录后仍需显式保存并更新自启动位置。

桌面0.1.4强化活动回答的主体对应：本人活动和目击他人分别标记，私聊/群聊共用活动规则，提供明确的休息/工作/自由活动类型。询问近况时应使用发言角色自身记录，不能把他人活动或已过时段当作本人当前活动。正常聊天计费方式保持；没有新增核对模型或后台任务。

桌面0.1.5新增两块世界事件：聊天获知随正常DeepSeek回复整理并保留原句／获知时间／计划变更；世界动态在设置单独授权后每批生成10条、逐条发布，右侧手动红／绿／灰标记，整批80%处理后续批。详见随包WORLD_EVENT_JOURNAL.md及EVENTS.md。新增0028应用数据表；启动新版后不要用旧schema程序打开同一存档。此次没有测试／真实API／用户DB验收，操作效果由用户核对。

桌面0.1.6修复同次聊天事件提取的输出指令顺序，并对官方DeepSeek两类小JSON任务关闭默认thinking；保留额度、用量结算和严格校验。失败细分空回复／格式／截断。事件池在排队前核对可用公共背景，不合格给出常驻／公开设置路径，不再显示“已排队”。本机已生成完整目录可以直接运行，无需再解压ZIP；必须先退出旧托盘程序，保留core目录。


## 桌面0.1.7新增

聊天顶部“长期记忆”可管理随正常回复自动保存的重要信息。角色也可参考近期亲历及活动结束/中断，见[使用说明](LONG_TERM_MEMORY.md)。请保留完整包，退出旧后台后启动新exe；自启动需在新版保存更新路径。存档正常升级到0029后不要用旧程序打开。工程端只做静态检查、构建及字节核对，实际体验由用户验收。


## 桌面0.1.8空回复兼容修复

普通官方DeepSeek聊天使用完整reply/events/memories格式提示和现有严格本地校验，避开服务端强制JSON输出路径；仍在一次正常回复中提取事件和长期记忆。群聊和私聊共用此修复，未改变世界动态、角色卡/世界书生成或其他模型的传输方式。失败不自动重试。

从旧托盘“退出并停止后台运行”，直接打开新完整目录exe，在“设置 → 后台运行”核对0.1.8，使用自启动时保存更新位置。本机完整目录无需解压，保留core/。无需重新生成角色卡或删除记忆，也不应拿旧schema程序打开存档。

若仍空回复或格式失败，请保留本次提示和时间，新版非流式安全日志可区分结束原因、实际Token与长度上限；没有记录回复/聊天正文或密钥。这是兼容修复包，静态检查和编译不代表真实模型验收成功。


## 桌面0.1.9聊天格式兼容修复

0.1.8的真实日志显示一次回复已返回33个输出Token、正常结束，但在JSON解析时失败。0.1.9把普通聊天与附带事件／记忆的格式校验分开：完整普通台词可保存，完整JSON或单层JSON代码块按原规则提取；截断和损坏的JSON仍拒绝。这次普通台词没有新条目，但历史原文与已有记忆仍可召回，不追加API调用补提取。

先从旧托盘选择“退出并停止后台运行”，直接运行本机完整的dialogue-resilience/dreamtalk目录中的exe，在“设置 → 后台运行”核对0.1.9。无需再解压、导入或删除角色；保留core目录。使用自启动时在新版显式保存更新启动位置。编译与静态检查已完成，实际模型回复仍由用户验收。


## 桌面0.1.11世界书架空间与动效

启动只展示横排书脊，不默认选书或显示右侧内容。已有世界与空白书都支持悬停轻抽，点击后完整抽出并转向封面，再出现详情或创建／导入选项；切换、再点所选书、“归位”或Esc归位。窄窗口详情在下方，减少动画时即时切换。书的正面和书脊显示世界名，三图封面留后续。

世界书手动／联网创建、文件导入、编辑和公共背景范围仍在书架，角色卡保留在世界内设置。选书只预览，明确进入后显示四个业务入口；返回书架不暂停世界，预览不计玩家在线。详情见 [WORLD_ARCHIVE.md](WORLD_ARCHIVE.md)。

退出旧托盘后直接打开本机完整 `world-shelf-motion/dreamtalk` 目录中的exe，保留core，不必重新导入已有内容。自启动需在新版显式保存更新位置。只完成静态检查、编译和包内字节核对，真实界面与旧存档体验由用户验收；没有改写存档或调用模型。
