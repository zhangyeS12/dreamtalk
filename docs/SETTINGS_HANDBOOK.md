# dreamtalk 设置手册

进入世界后，点击底部“设置”，从左侧目录选择分类。设置的作用范围不同：模型、时间和活动属于当前世界；后台运行属于整个应用；每轮聊天额度是本机各世界共用。切换分类保留尚未保存的输入，但实际使用的仍是已保存配置。

## 模型与聊天

### 默认模型与世界独立模型

书架右上角“模型设置”保存默认配置。没有独立设置的世界继承它，修改默认会影响这些世界。

世界内保存模型后，该世界成为独立配置，不再跟随默认，也不会改变其他世界。点击“恢复使用书架默认配置”可重新继承。聊天、群聊、角色卡 / 世界书生成、摘要、活动、动态和主动联系均使用对应世界的模型。

### 服务配置

| 字段 | 说明 |
| --- | --- |
| 服务商 | 选择 OpenAI、Claude、Gemini 或兼容服务入口。DeepSeek、Kimi、GLM 等须使用服务商明确支持的兼容接口 |
| 模型名称 | 使用服务商提供的完整型号名称；同品牌不同型号的能力可能不同 |
| 服务地址 | 官方服务使用对应官方地址，代理使用代理提供的地址；不要填写普通网页地址 |
| API 密钥 | 自行申请。保存到本机安全凭据存储，不随导出文件分享；编辑时不要因输入框没有显示旧密钥就误认为丢失 |
| 回复长度 | 简短 2,048、标准 8,192、较长 16,384 或自定义 Token，限制最大回复量，不保证用满 |
| 逐步显示回复 | 模型支持时边生成边显示，不兼容时可关闭；失败不会自动重发付费请求 |

高级设置包含：

| 字段 | 说明 |
| --- | --- |
| 输入容量来源 | 自动匹配已知型号；找不到可信信息时，按该服务的官方说明手动指定 |
| 模型输入容量 | 填真实上下文容量，不能为减少预留而虚填较小数值 |
| 原生 JSON Schema 支持 | 让明确支持该能力的型号使用结构化结果。只在具体服务和型号确认支持后开启；普通聊天记录记忆、事件不要求开启此项 |
| 请求超时 | 1～600 秒，默认 30 秒；慢速模型可适当增加，超时不会自动重发 |

保存会重新连接本地服务，不会调用模型检查密钥。因此“配置已保存”和“服务可正常生成”是两件事。

### 每轮聊天额度

这是本机所有世界共用的聊天上限，不能理解为某个世界的账单上限。一次尝试内的输入、选人、多个角色发言以及内部重试共用同一额度。“回复长度”只限制输出，“每轮额度”还要包含输入。

Token 是模型处理文字量的单位，不等于中文字符数。系统会先作可信的保守预留；部分服务需要按完整输入容量预留，所需额度会比较大。页面会显示不足原因和所需数值，核对真实模型容量后再调整。资料生成和后台功能另有费用，不受这个聊天上限统管。

回复失败时查看会话内提示。最后一条尚无回复的消息若支持人工恢复，可明确开启新的生成尝试，使用新的额度并可能再次计费。已经有部分群回复、结果不确定或仍在生成的尝试不会盲目重发。

## 后台运行

| 选项 | 说明 |
| --- | --- |
| 登录时启动 | Windows 登录后在后台启动，不主动弹出主窗口 |
| 关闭窗口到托盘 | 关闭窗口后继续运行；可从托盘重新打开 |
| 保存并更新启动位置 | 保存选项并登记当前程序路径；便携版换目录后需再保存 |
| 刷新 | 读取实际保存状态，同时重新显示已保存的选项，不调用模型 |

彻底退出请从托盘选择“退出并停止后台运行”。睡眠、关机和完整退出期间不会继续执行本地模型任务。自动活动不是云端全天运行服务。

## 世界时间

暂停和恢复只作用于当前世界。暂停后时间与活动调度停止推进；已发出的模型请求可能仍计费。

时间倍率可设置为 0.01～1,000，默认正常流速。提高倍率会让日常、冷却和其他按世界时间计算的间隔更快到来，可能使后台规划更频繁，请连同费用一起考虑。

玩家的“忙碌”不会暂停时间。私聊和群聊不会移动玩家或角色；一个玩家同一时刻只处于一个地点。

## 角色活动

先在通讯录配置地点和每位角色的初始位置，再在这里开启活动。地点包含关系、地区、隐藏分支、角色常驻倾向和锁定均在通讯录管理；[地点手册](ACTIVITY_LOCATIONS.md)。

| 选项 | 说明 |
| --- | --- |
| 自动活动 | 默认关闭，首次开启确认后台费用。安排已有地点中的休息、工作、自由活动与移动，不自动创建地点或任务成果 |
| 每批规划人数 | 1～16，默认 8，从所有已配置角色中轮换选择；点击“保存规划人数”后在新的轮换批次生效。未选中者保留已有位置和状态，不限制通讯录角色总量 |
| 角色相遇 | 默认关闭，需开启自动活动。只有真实处于完全同一地点、双方活动合适时才可见面；父子地点不算同一个地点 |
| 共同休闲 | 默认关闭，需先开启自动活动和相遇。已相识的角色可以一起休息或自由活动，通常持续 15～30 世界分钟 |
| 刷新状态 | 查看当前许可和规划状态，不调用模型 |
| 请求新规划 | 需要人工处理时显式请求新批次，会调用模型；普通刷新不会重发失败任务 |

常规批次覆盖 6 个世界小时，一次规划多位角色。最多安排两次问候 / 共同开始，见面与共同活动还受冷却和持续同场限制。地点不相同、活动不适合或条件不满足时，可能一批都没有相遇。

关机和退出后不补造没有实际发生的移动、见面或成果。修改常驻倾向等配置用于下一常规批次，不会为了每次编辑立即额外请求模型。锁定初始地点则按确认规则让角色立即返回并保持在初始地点。

## 主动联系

“可联系 / 忙碌”属于当前世界的玩家状态。可联系允许角色在有合法理由时联系，忙碌跳过普通联系，世界时间仍正常流逝。

### 在线主动联系

默认关闭，开启前确认后台费用，需开启自动活动。角色根据实际休闲等合适理由来找你；最小间隔可设 15～1,440 世界分钟，默认 360 分钟。首次开启从当前时刻计时，不立即发送。

双人联系需要真实共同休闲，且两人围绕同一事由。它还依赖相遇与共同休闲设置，不会把两件无关的事强行放进一个群。

### 离线联系

只能指定一个世界。换到另一个世界开启，会替换之前的目标世界。默认真实离线阈值 6 小时，可设 1～168 小时；首次开启不会马上补消息。

恢复使用并满足阈值后最多补一条问候或邀请。忙碌、暂停或已有待回复联系时跳过。消息在恢复时生成，不代表电脑关闭期间仍调用了模型。

### 等待回复和费用

在线、离线以及不同角色共用等待回复限制。收到主动联系后，需要在原私聊 / 群聊里回复，才允许下一次。阅读只清除未读提示，不解除等待；开关和重启也不解除。

主动联系不会为了寻找理由读取全部私聊、摘要或私人记忆。刷新设置不生成消息；失败或中断不会自动重复付费生成。没有合适理由时一直不联系，也可能是正常结果。

## 世界动态

默认关闭，首次开启确认后台费用。先在书架的世界书管理中确认所需条目公开、启用，并满足使用条件。

每批生成 10 条进入消息池，按时间顺序最多显示 5 条进行中：红色“未经历”保留位置，绿色“已经历”和灰色“跳过”腾位，后面的消息依次补入。处理过的消息可在历史里回看。最近一批处理达到 8 / 10 时可自动补一批，旧未处理消息保留。

“刷新状态”读取本地结果；“生成新一批”会调用模型。暂停不发布，过期不补造历史。动态是公开消息或传闻，不一定都是被证实的世界事实；手动标绿也不证明某件行动已经完成。

## 关于与诊断

显示桌面版本、程序位置、本地服务连接与模型配置状态。刷新连接状态只读取本地健康信息，不测试服务商密钥、余额或真实生成，不产生模型费用。

## 其他常用入口

| 入口 | 说明 |
| --- | --- |
| 我 → 通用资料 | 称呼和“关于我”供各世界使用 |
| 我 → 世界专属资料 | 当前世界的称呼与身份介绍优先于通用资料；世界称呼留空时使用通用称呼 |
| 我 → 身份绑定 | 选择已有玩家身份或按提示进入世界；一个世界绑定一个本地玩家，修改介绍不等于新建身份 |
| 聊天 → 长期记忆 | 查看、搜索、置顶、停用 / 恢复、查来源；关闭自动记录不会停用已有记忆 |
| 聊天 → 会话摘要 | 主动生成、编辑、预览和确认摘要；生成可能收费 |
| 书架 → 新更新 | 查看更新说明，选择稍后或更新；勾选不再自动弹窗仍保留手动入口 |
| 通讯录 / 书架 / 会话菜单 → 导出 | 导出已保存资料或完整聊天，不调用模型；不是完整世界备份，聊天文件目前不能导入 |

世界书导出含隐藏条目，分享前请核对。删除整个世界会清空所有角色、聊天和记忆，必须确认且无法撤销；解散群聊只隐藏群并停止发言，保留已有记忆和来源。完整功能说明见[项目主页](../README.md)。
