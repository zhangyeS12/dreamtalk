# 已批准：表情库与聊天配图

2026-10-13用户逐项确认并授权实现；2026-10-14追加批准最新库摘要与表情包不限频率选项。当前只在本地工作区开发，不授权GitHub发布；工程端验证仍按具体范围，见本轮[记录](../maintenance/2026-10-14-sticker-library-freshness.md)。

## 确定的行为

- 通讯录增加公共表情库、角色专属库和我的表情库。公共与专属库按世界隔离，换世界需要重新创建；用户库跨世界共用。
- 专属库绑定稳定角色卡根身份，改名、换头像、卡版本更新不改变归属。其他角色的专属库在检索之前排除。
- 用户私聊发送表情时同步收录给对方；在固定群聊发送时收录给每个角色，包括未发言成员。角色发送的表情只收录给自己，不转入其他成员的专属库。
- 聊天类型明确区分sticker与image。表情可复用，发送过的网络表情加入发送者专属库；普通图片只用于当前消息，不进入表情库，聊天历史保留图片。
- 角色依场景判断是否发送，可只有图片。每轮最多一张；设置频率N表示任意连续N轮最多一次，不意味着满N轮必须发送。按会话共用，群聊所有角色合计；用户手动发送不消耗角色频率。
- 2026-10-14追加“不限制角色发送表情包的频率”：默认关闭，开启后每轮都可按环境发表情，群聊／恢复仍每原轮合计最多一张；普通配图保持原N轮间隔。关闭恢复保存的间隔，回执不重置。
- 一轮定义为一次玩家持久发送发起的聊天轮次，恢复尝试不新算一轮。频率以真实消息位置及持久回执核验，刷新、重启、改名不重置。
- 角色先在同次正常回复中表达媒体意图。表情只在确实需要且已授权库没有匹配时联网；关键词结合人设、情绪和风格。普通图片按聊天主题搜索，不复用表情库。
- 每原聊天轮次最多一次图片查询，群聊与恢复尝试共用；无结果、超时或失败保留自然文字回复，不自动搜索第二次、不增加文字模型重试。
- 图片来源保留在详情，网络配图不认证角色实拍、世界事件或亲历证据。

## 分析与费用

用户批准手写说明及可选一次性视觉分析。设置单独配置本机Ollama或Chat Completions兼容视觉服务、每日次数和输出上限；默认不启用自动分析或联网。
远程分析须在设置确认图片外发及可能费用，密钥由桌面原生保险库保存，仅引用进入配置。分析只含当前图片与固定描述指令，不附聊天、角色资料或私人记忆。
已分析图片保存说明并复用。动态图片只分析首帧，不能宣称理解整个动画；失败／未知调用保留计次，不自动重放，用户可手动重新分析。
图片分析的独立次数及输出上限不是人民币或全部输入Token硬上限。文本媒体意图和候选说明仍进入原聊天请求，受既有整轮硬Token预算治理。

## 实现边界

沿用React、版本化HTTP、FastAPI、SQLite和Alembic；0048仅增加聊天媒体数据与附件字段，不写WorldTruth、Belief或Observation。
图片管理采用分页和可编辑说明，提示最多五条授权候选说明，使用已有jieba做本地词法检索。不是整库图片逐轮外发，也不保证所有同义词或复杂梗都命中。
2026-10-14修正候选不等于完整库的语义：每轮读取最新授权库数量与完整性，五张以内展示全部，大库优先两条最近新增并补相关项，总计仍最多五条；冷却只限制发送，不限制读取该角色当前授权库摘要。历史无导入时间的条目不补造时间，说明保持非特权数据。
库删除与聊天历史分开；世界删除清除本世界媒体／库／设置／搜索回执，保留全局用户库。聊天导出携带附件描述和元数据，不把原图二进制打进现有TXT／JSON格式。
成熟实现、版本和许可取舍见[调查](../research/2026-10-13-chat-media-reuse.md)。用户入口与验收见[使用说明](../CHAT_MEDIA.md)。

世界删除不退还当日已接纳的图片分析次数。无图片、说明或聊天正文的分析计次回执保留，避免删除世界绕过全机每日上限；世界素材与凭据仍按原规则清除。
