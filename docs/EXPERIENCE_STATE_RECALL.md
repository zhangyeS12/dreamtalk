# 活动经历的后续状态召回

本页维护当前亲历状态召回契约；实现／发行／验收见[状态清单](PROJECT_STATUS.md)。活动开始后已经结束或中断时，话题检索优先提供该角色获准亲历的实际后续状态，同一次活动不重复占开始和终态两个名额。原始事件、记忆及聊天原文保留。

在已有真实活动的私聊／群聊里，可问过去某次活动后来怎样，再问“现在呢”。历史终态只说明当时结束／中断，当前近况仍由本人最新活动快照确定；工作时段结束不等于任务交付，共同休闲结束不等于关系推进。

系统只关联当前角色有权亲历的记录，以稳定开始事件 ID 识别同一次活动，不按名字相同或时间接近猜测。只目击开始、没有获准结束时，只能确认当时开始；查看不到不能证明从未发生或仍在继续。近128条授权窗口、最终最多12项／8KiB及词法检索限制保持，不另调 API 判断终态。

源码入口是 `services/core/src/livingworld/application/experience_lifecycle.py` 及 `infrastructure/persistence` 下的观察检索／事件投影；本人当前活动另由 `character_activity_context.py` 读取。设计来源见[复用调查](research/2026-10-04-experience-state-reuse.md)，其中历史授权和检查不延续到当前任务。

核对当事／旁观、正常结束／中断／仅见开始，以及角色／世界隔离；工程检查和实际模型效果分别按状态清单记录，不从旧包或旧检查推定验收。
