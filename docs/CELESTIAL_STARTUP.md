# 星梦启动与应用标识

当前开屏为“夜读”：书在台灯下翻开、纸艺天空立起，书架就绪后镜头飞入天空。用户于2026-10-29明确重做，旧流星漩涡／观星室方案仅供追溯，不再限定当前视觉；Logo沿用用户提供的原图。版本、实现与验收统一见[状态清单](PROJECT_STATUS.md)。

## 当前效果与实现

“夜读”保留至少1.5秒前台展示：

- 预启动 HTML 与 React 首帧相同：深夜底色上的原 Logo 和 dreamtalk 字标，不需要 JavaScript 即可显示。
- 三维画面接管后，Logo 落到一本合着的布面书封面上（金色压框，书躺在台灯光里）。书自己翻开，纸艺立体书一样从书缝里立起一层层纸片：星空与晚霞、新月、云、三道山脊和亮着窗的小屋，偶尔有流星划过，台灯光里有细尘漂浮。底部浮出一行“每一本书里，都有一片天空。”
- 书架准备好后，镜头穿过纸山飞进那片纸做的天空，中心一道暖光，随后从 Logo 位置开出圆形光圈，露出早已在背后挂好的书架（约1.1秒）。如果书架在立体书完全立起之前就准备好，进入动作会顺带把翻书和立起做完，衔接剩余进度；实际流畅度仍按设备验收。
- 实现：`apps/web/src/startupScene.ts`（Three.js，几个盒子与平面加画布绘制的纸纹贴图，Lambert 材质，无阴影贴图、无后处理），`StartupSplash.tsx` 负责可见性、计时与回退，`startup.css` 负责预启动构图、字幕和光圈过渡。场景里没有任何真实世界的内容。
- 原 Logo PNG 字节不变，标题栏、任务栏、托盘与页头的图标沿用原转换结果。
- 存档检查、连接期限、书架15秒失败期限、封面图片5秒回退、“重试启动”和恢复页的规则与前一版相同。

## 性能与生命周期

三维场景按需加载，复用关系网已有的Three.js依赖；产物体积以对应构建记录为准，不增加框架或外部CDN。纸纹用一张小噪点图平铺，不逐像素处理大画布；像素比上限1.5；书架接管后场景立即释放。

document可见性与Tauri原生窗口visible/minimized状态共同控制：原生可见性尚未确定时不提前结束；隐藏自启动不创建WebGL、不强制展示，数据就绪后可完成。最小化/后台暂停渲染和前台展示计时，完成后取消RAF、监听、计时器与ResizeObserver并释放资源。减少动态效果使用静态Logo至少1.5秒再短淡出，WebGL不可用同样保留静态标识。

原生可见性查询失败保守使用静态版本；三维模块加载或首帧准备最多3秒，失败/超时释放未完成场景并回退静态Logo。核心快速就绪不再阻止三维模块建立；1.5秒从首帧而非组件挂载开始计算。后台数据准备不依赖requestAnimationFrame，避免隐藏窗口无法退出启动状态。

## 用户验收

1. 从当前完整包或规范本机入口打开；快捷方式存在时须核对实际指向。确认标题栏、任务栏、托盘及页头沿用原标识；用户无需拆换程序文件。
2. 正常启动先看到 Logo，随后它落到书的封面上，书翻开、纸片立起，最后镜头飞进纸天空、光圈打开进入原世界书架；书本与封面正常，无技术连接文字或空白闪屏。
3. 快速再次打开也应至少展示1.5秒，再进入书架；真实准备较久时立体书继续停在台灯下，失败可重试。减少动态效果或图形不可用时至少展示1.5秒静态 Logo。
4. 最小化/托盘返回、隐藏自启动、减少动态效果与实际设备流畅度由用户体验。更换便携路径不会自动改自启动；需要在新版设置显式保存并更新启动位置。

以上是验收步骤，不表示工程端已执行。
