# dreamtalk 0.1.76 · 配音、表情包与聊天图片大更新

这次更新将角色配音、三套表情包库和聊天配图加入公开 Windows 体验版，并包含自0.1.53以来的播放、模型服务及界面维护改进。

## 角色配音

- 在通讯录为角色导入参考人声或.voicecard音色卡，预览、绑定、试听与导出；不同世界独立保存绑定。
- 支持本机IndexTTS2.5、官方免费演示与付费API三条路线。配音默认关闭，云端需使用自己的账户并确认相关外发／费用。
- 消息旁“播放配音”可生成并播放声音。成功保存后缓存六小时，期间重播复用缓存；过期后再次点击才重新生成。
- “重新配音”生成独立候选，下方试听完成后明确选择替换或保留原声音。
- 本地保留三个独立采样候选，选择正常结束的结果。模型容量内尽量整段生成，超出容量才优先按完整句号分段。
- 增加“一键修复本地配音”，检查并重新连接已登记且可信的本项目服务；正在生成的任务与未知程序保持，修复不自动重发台词。

用户已反馈本次本地配音效果良好。**免费云端最新版和付费API尚未测试，仍待确认**；平台排队、免费额度与付费服务的可用性由相应平台决定。

## 表情包与图片

- 通讯录新增公共表情、角色专属和我的表情三套库，可导入PNG、JPG、WebP及GIF，并编辑说明。
- 公共／角色专属库按世界隔离；公共库供当前世界角色使用，专属库只属于对应角色。我的表情可跨世界使用。
- 用户发送表情给私聊角色会收录到对方专属库；发到群聊会收录给每位角色。角色自己发送的表情只收录给本人。
- 角色按性格与聊天环境选择表情，可只发表情；普通配图保留聊天历史，不加入可复用表情库。
- 最新授权库每轮刷新，提供有界素材说明并标记可靠的最新加入项，修复新增表情被旧对话忽略的问题。“本次参考内容”可查看提供的表情条数。
- 设置可调整发送频率，或勾选“不限制角色发送表情包的频率”；每原轮仍最多一张，群聊所有角色共享。
- 可选联网找图：需要表情且授权库无匹配时才搜索；普通图片按聊天主题搜索。每原轮最多一次搜索，失败保留文字，联网默认关闭。
- 可选本机或云端图片分析，保存说明供后续选择，减少重复发送图片。自动分析默认关闭；本机等待窗口及固定错误类别已完善。

用户已确认角色能够发送表情，并确认本次新上传表情识别问题解决。这是具体体验结果，群聊、联网和其他场景仍需继续确认。

## 本机服务与维护

- 已登记的本地配音、图片服务随dreamtalk启动；开启并保存程序的开机后台启动后，也会随登录启动。
- 本地配音与本机图片分析取消每日次数上限。云端保留次数、费用与授权规则，文字聊天的整轮额度保持。
- 改进地点页串行刷新、未变化快照复用、头像读取与缓存，以及确定性移动计算。
- 修正媒体设置读取地址、角色表情回复格式、频率状态提示与新增素材上下文位置。
- 强化源码、便携包与安装器解出载荷的隐私检查，不将存档、个人配置、参考录音、聊天导出或发布私钥放入下载包。

## 下载与更新

推荐使用Windows x64安装包，也提供完整便携ZIP。安装包有应用更新签名，但尚无Windows发布者证书。便携版需完整解压，从文件夹运行dreamtalk-desktop.exe。

**配音和视觉模型需要另行准备，下载包不包含这些模型权重或参考录音。** 本地配音使用IndexTTS2.5；图片分析可使用Ollama及Qwen3-VL4B Instruct Q4_K_M。也可手动填写表情说明，不部署视觉模型。
