# dreamtalk 0.1.83 · 共同邀请与稳定性维护

- 双人共同邀请优先投递到成员恰好为这两位角色的已有群聊；没有这样的群时，两位角色分别私聊你，不会自动建群。
- 回复任意一位角色即可回应这次共同邀请，另一条消息仍保留独立未读状态。角色需要有真实的共同目的，后台联系继续遵守已有开关、费用及等待回复规则。
- 整理世界／身份切换、事件草稿和异步操作的状态管理，防止旧请求覆盖当前界面，并阻止重复提交同一待处理操作。
- 统一业务接口结构校验，扩展关键后端代码的类型检查；修正新用户未配置模型时可能被误判为服务缺失的问题。
- 精简重复文档，统一功能实现、工程检查与用户验收状态的记录入口。

提供完整 Windows x64 安装包、便携 ZIP 及原应用内更新频道。沿用原应用标识、数据位置、更新公钥和五位置存档，不需要清空或手动恢复数据。

仍为预发布体验版。本次工程检查及 build-only 打包不等于真实安装、应用内升级、恢复或模型效果已经验收。真实升级与存档连续性由用户在正常使用中确认；不要用旧程序打开已被新版使用的存档。更新签名不等于 Windows 发布者证书，安装包不包含本地模型权重。
