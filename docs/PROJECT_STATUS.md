## 如何读状态

| 状态 | 含义 |
| --- | --- |
| 已实现 | 当前代码中有实际接线，不代表最新版本已通过真实运行验收。 |
| 历史体验可用 | 用户曾明确报告相关体验正常；只覆盖当时反馈，不扩展到所有后续版本/场景。 |

| 明确限制 | 当前实现的范围边界，不等于已复现 bug；扩大范围可能需要具体方案。 |
| 尚未实现愿景 | 原始产品方向有描述，但具体方案未冻结；不自动成为下一轮开发授权。 |
| 撤回/未批准 | 不属于当前推进范围。 |

## 四、确实仍有的范围限制

| 已有能力 | 目前限制，不得误报 |
| --- | --- |
| 本地记忆/RAG | 有界候选和渐进索引，不是无限全历史覆盖；长文本编码截断/相似阈值与实际效果未全面测量。自动提取可漏记，合法普通台词可能不附带条目。 |

| 世界书 | 支持有限激活条件，非完整酒馆概率/递归/时序/脚本/插入位置兼容；隐藏设定没有通用逐角色授权传播产品流程。 |
