# 表情包与聊天图片

0.1.76将表情包和聊天图片纳入本次公开大更新，使用说明见[更新说明](releases/v0.1.76.md)。2026-10-14用户确认角色能够发送表情，以及新上传公共表情识别问题已解决；最新库摘要放在本轮私聊问题前，带可靠入库标记，“本次参考内容”可查看提供条数。具体证据见[修复记录](maintenance/2026-10-14-sticker-context-position.md)，不扩大为全部群聊、联网或视觉场景已验收。

## 在哪里添加

进入世界，在通讯录右侧选择“表情包”。可批量导入PNG、JPG、WebP或GIF，每张最多8 MB；填写图片内容、语气和适用场景，后续可逐张修改。

| 库 | 谁可使用 | 跨世界 |
| --- | --- | --- |
| 公共表情 | 当前世界全部角色 | 不共用 |
| 角色专属 | 绑定角色 | 不共用 |
| 我的表情 | 用户在聊天输入区手动选择 | 共用 |

角色只拿到公共与自己专属库的候选。换世界公共／专属库需要重新建立，改名或更新同一角色卡不重置其专属库。
导入完成后的下一轮聊天会读取最新库摘要，发送冷却期间也会读取。五张以内提供全部说明；较大库优先展示新导入及相关素材，并明确不是完整清单。只导入“我的表情”不会直接向角色公开，需要发送给对方后收录；不用清理缓存或额外调用图片分析来刷新库。

## 怎样发送与收录

聊天输入区点击“表情”，从我的表情中选择，可以附文字或只发送表情。发给私聊角色会收录给对方；群聊会收录给全部成员。角色发送的表情只收录给自己，不加入其他群成员的专属库。

角色会根据聊天环境决定是否使用，允许只发图。联网表情发送成功后收录给发送者；普通配图只保留在当前消息和历史，不进入可复用表情库。详情可查看网络来源，配图不代表角色实拍。
删除某库中的表情不抹掉聊天历史。删除世界清除该世界内容，共用的我的表情保留。

## 频率与联网

设置 → 表情与图片，可开启／关闭角色配图并设置频率。频率4表示任意连续四轮中至多一次；达到间隔后也可以一直不发送。私聊按会话计算，群聊所有角色共用一次限额，表情与普通图片共同计数。玩家一次发送发起一轮，恢复尝试不增加轮数；用户手动发送不占角色限额。
勾选“不限制角色发送表情包的频率”并保存后，每轮都可以发表情，仍由角色按环境选择；每轮最多一张，群聊所有角色合计。此时数值频率只限制普通配图，原间隔值保留；取消勾选并保存可恢复原规则。

联网默认关闭。开启后，表情仅在模型认为需要发送且库中没有匹配时搜索，关键词结合人设、情绪和风格；普通配图按聊天主题搜索。每原轮次最多一次查询，找不到或出错就正常文字回复，不自动反复查找。

## 可选图片分析

**首次使用需要先部署视觉模型。** “已保存”只表示设置已保存，不代表模型已安装或服务已验证；聊天模型与IndexTTS配音模型不会自动用于图片分析。没有视觉模型也可以手动填写表情说明。

本机已独立部署Ollama0.40.3和Qwen3-VL4B Instruct Q4_K_M，并核对vision元数据，实际图片效果待用户验收；准确填写方式见[部署记录](maintenance/2026-10-13-local-image-model-deployment.md)。模型文件和运行环境只保存在本机独立目录，不包含在dreamtalk便携包中。

在“图片分析与用量”中填写本机Ollama视觉模型，或云端Chat Completions兼容服务。此功能不会下载模型。本机路线登记已部署目录并保存完整模型名称后，服务随dreamtalk启动；设置中可检查并启动或选择目录。模型首次分析时加载，程序启用开机后台启动后无需再双击独立脚本。
自动分析默认关闭；启用后新素材分析一次并保存说明。也可在库中点击“分析图片”；失败可点击“重新分析”，它是一次新的调用并重新计次。云端需确认图片外发与可能费用，密钥由桌面版安全保存。分析只发送图片，不发送聊天或人设。

GIF保留动画播放，但分析只取首帧。未启用分析时，角色根据用户说明和搜索主题选图，不能保证理解反话或复杂梗；完善说明可改善选择。

本机图片分析不设每日次数限制。云端图片分析按UTC日期、全机云端已提交次数计数，失败及未知结果也占次数；新增本地回执不占云端次数，旧版无法分类的回执保守计入当天云端准入。每次输出有单独上限，输入图片仍可能收费，这些限制不等于账单金额上限。历史通常只给聊天模型短说明，避免重复发送原图。聊天本身仍受原有整轮Token上限约束。

实现依据见[批准方案](proposals/2026-10-13-chat-media.md)与[成熟实现调查](research/2026-10-13-chat-media-reuse.md)。

世界删除不退还当日已接纳的图片分析次数。无图片、说明或聊天正文的分析计次回执保留，避免删除世界绕过全机每日上限；世界素材与凭据仍按原规则清除。
