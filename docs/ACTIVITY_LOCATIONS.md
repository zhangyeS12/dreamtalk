# 地点与角色移动（0.1.47）

在当前世界“通讯录”使用“添加／编辑地点”，入口在角色卡管理下方。选择已有地点改名称、父地点、地区标记、隐藏分支和开放角色；“＋ 添加地点”新建。“家”是系统初始地点，不能编辑。同世界规范化同名会被拒绝；名称1–120字，当前最多32个地点（含家）、16位活动角色。

地点可层层包含：璃月 → 璃月城 → 往生堂。每层都是独立真实地点，角色也可停留在璃月。包含关系不是道路或物理同场，不自动移动玩家，不把世界书地名自动创建成地点；地点编辑底部可删除不再使用的地点；含子地点、活跃角色初始／当前位置或玩家所在位置时会提示先调整。“家”不可删除。移除作者目录保留旧事实，同名重建是新地点。没有交通／玩家前往按钮。

## 常驻中心与地区

“角色资料 → 初始地点与移动倾向”选择初始地点并保存。初始地点现在是常驻中心，替代0.1.41子树硬范围；可以去父地点，也可以直接从往生堂去万民堂，不补造经过璃月城的停留。角色只去获准地点，离常驻中心越远越少见，外出路线包含返回中心。

在地点编辑将璃月、蒙德等勾选为“地区”，它们的子地点归属最近的地区节点。即使共同包含在提瓦特下，也会区分城内活动和跨地区远行。无标记时按最上层地点划分，不根据名称猜测。先建立真实地点并标记地区，再在世界书提供公开设定，模型不会自行创建或标记地区。

常驻倾向为一般／强／很强，默认强。普通六小时批次的类别倾向分别为50/40/10、70/25/5、85/14/1：留在中心／附近／同地区较远。先选类别，再按树距离选地点，添加很多店铺不会稀释留驻权重。附近为距中心至多两条树边；类别没有可选地点时留驻，不转为远行。真实离开中心越久，返回倾向越强。这不是精确停留时长承诺。

跨地区另有1%远行机会，两次判定至少间隔24小时世界时间，实际返回常驻地区后冷却7天。门禁与本批结果持久保存，重启、开关或重规划不会反复抽取。远行批次必须安排返程日常；执行中断时不编造已返回，下一常规批次优先真实返回。极低概率不会保证短时间看到远行，也不增加逐移动模型调用。

活动仍需要在设置中独立开启，沿既有六小时批量规划、许可和费用治理；关闭／完全退出不会产生独立移动循环，暂停冻结世界时间。单改倾向保留当前位置和已开始活动，新设置等下一常规批次；修改地点规则可能使未开始候选失效，按既有批次阈值处理，不主动触发编辑付费调用。

## 锁定与已有存档

“锁定在初始地点”没有另一个目标选择。胡桃初始地点为璃月，若已在往生堂或其他地区，保存锁定会通过Kernel立即回到璃月，原活动结束／中断，之后只能在那里。修改初始地点也在保存时放置到新中心。解锁且中心未变时保留合法当前位置，不自动开启活动或请求模型。

位置绑定同世界稳定角色身份，改卡或切换玩家不复制位置。旧存档初始地点按首次真实放置恢复，旧实际位置／历史不在迁移时重写，旧角色默认常驻倾向强。新包含0039配置／门禁增量迁移，工程端没有运行真实存档升级。已升级存档不要再用旧版打开。

## 隐藏分支

隐藏璃月城会限制它及所有子地点；对子地点开放但没获隐藏祖先授权，仍不能进入。若往生堂也隐藏，还需在往生堂单独开放。新角色可先保存公开初始地点，或打开一次会话，再选择隐藏分支开放对象。

作者地点图仍显示隐藏地点（虚线），角色目录和执行准入先过滤权限。历史亲历记忆不被删除，独立公开世界书也不会自动隐藏。角色当前或初始地点在该分支时，需保留其开放，或先调整初始地点再撤销权限。改变包含关系不再以“越出初始子树”拒绝，循环、跨世界及撤销实际／初始位置权限仍拒绝。

## 地点图与相遇

“角色资料／编辑阵营／人物关系网”右侧的“地点”页用二维嵌套圆显示包含关系，圆形头像位于真实当前位置；直接在父地点的头像不画入子地点。拖动平移、滚轮／按钮缩放、总览复位，点击头像看姓名、“初始地点－当前位置”和聊天入口。例如“璃月－往生堂”，前者是常驻中心，后者是当前位置。

每5秒只读刷新，离开通讯录停止刷新；未设置角色单独列出。图是作者配置视图，不授予玩家现场见证。相遇和共同休闲仍须双方完全相同地点ID；璃月与璃月城不算同场，原授权、冷却和持续同场去重保持。
