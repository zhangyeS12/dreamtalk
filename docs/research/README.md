## 研究记录要求

每份后续研究记录写明：问题与相关 FR 编号、研究日期、来源链接与版本、可验证的证据、证据与推断的区别、候选方案与取舍、未验证事项、结论及其状态。协议与产品能力以正式规范或官方资料为优先证据；不得虚构来源或将未执行的验证写成已通过。

研究结论不自动成为产品规则或架构决定。需要作出架构决定时，按 [ADR 规范](../architecture/ADR/README.md) 记录；涉及冻结规则含义不清时，先保留开放问题。
