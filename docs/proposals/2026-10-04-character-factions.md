# 角色阵营、头像与关系网（2026-10-04，用户已确认）

## 产品规则

- 在当前世界的通讯录创建、重命名、迁移、删除空阵营；可无限层级设置子阵营，角色可同时加入多个阵营。删除只允许无成员、无子阵营的节点。
- **同一个阵营的直接成员**默认互相认识；子阵营成员不因父子关系认识父阵营其他成员。直接共属建立持久相识，退出阵营或删除空阵营不抹去相识；人物在不同阵营共属时只画一条线。图中不按父子层级推导联系，也不按亲密度数值或一次问候猜测正式相识。
- 阵营归属依角色卡的稳定根导入 ID 保存；更新角色卡保留归属和头像，世界之间隔离。相遇、共同休闲和角色各自见闻仍记录实际发生的经历；已有相识不补造过去相遇、见闻或私人信息。
- 实际共同休闲仍要求双方真实同地点、同类日常、授权和 Kernel 当时复核。同阵营直接成员满足原先“此前实际碰面”的相识前提；不取消日常、相遇、共同休闲的独立开关或活动时长/冷却限制。只有同一次实际共同休闲才可发同目的双人邀请。
- 人物头像为本地用户上传的 JPG/PNG/WebP，可移除；未上传显示名字首字。复用已有世界封面图片的大小、静态解码与本地资产存储/读取，不新建在线图片服务。头像只影响通讯录与关系网展示，不自动修改角色卡/世界真值。
- 聊天仅向当前发言角色提供其直接加入阵营的名称、获准同阵营角色姓名与已建立相识（最多 8 个阵营、每阵营 16 名、24 名相识，合计 4 KiB，容量不足可整体省略）；不能把阵营相识推成同享见闻、私聊或亲密度。
- 关系网在通讯录内，用头像节点和相识连线展示。画布可拖动/缩放；点击角色时动画聚焦，右侧小窗展示全名、所属阵营及聊天入口。空间感使用前景、阴影、景深和层次布局，不假称完整 3D 场景。

## 成熟实现与复用选择

- [React Flow 官方站点](https://reactflow.dev/)：MIT，已内建 React 节点、边、平移、缩放、视图动画。使用 `@xyflow/react` 12.12.0 实际渲染关系网；不用自己重写鼠标相机/缩放/边连线。
- [Cytoscape.js 官方项目](https://github.com/cytoscape/cytoscape.js)：MIT，擅长图分析与大网络渲染。当前需求更重头像交互与右侧 React 详情，React Flow 的 DOM 节点更容易实现；若将来大规模节点性能成为事实问题，再按测量评估替换。
- 图片校验与持久化复用现有 `WorldCoverService` / Pillow / ContentAssetStore；数据库只保存角色头像所指向的当前世界图片 digest。

## 落地边界与验收

新迁移 `0036_character_factions` 只追加阵营、成员、头像和持久相识四表，不更改旧消息或事件。加入阵营时与该阵营当前直接成员建立无向相识；单写事务确保重复加入不产生重复连线。撤出只改变当前归属；已建立相识与过去真实见闻保留，不补造认识时的地点、谈话或活动。没有额外模型调用；下一次常规日常批次/聊天请求可能因新增少量关系上下文而使用更多输入 Token，仍按现有额度/任务预算。

需要用户体验确认：建立“维多利亚家政”后，艾莲/莱卡恩/丽娜三人直连；只在子阵营的两人互连但不连父阵营其他人；跨阵营角色形成多组联系；上传/移除头像、点击居中与聊天跳转、角色卡更新/重启后的归属保留。打包/静态检查不等于真实存档升级、模型自然回答或双人联系已验收。

依赖原文与锁定版本见 [关系网许可清单](../licenses/relationship-network/README.md)。旧的数值关系对象保持原样；此次不增加亲密度算法、关系传播、共同委托或付费重试。头像当前用于通讯录和关系网，自动居中裁切为圆形；不上传至模型。
