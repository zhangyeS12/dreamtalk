# 安卓地点与人物关系图

本轮提供二维地点包含图、个人关系图、全局关系图和备用列表；三维轻量模式尚未启用。所有数据沿现有位置目录和 socialSnapshot，不增加 API、数据库迁移、模型调用、记忆或费用规则。

## 地点包含图

世界总览的大圆包含下级地点。点地点逐级展开，面包屑返回上级或世界总览，也可用“跳转地点”直接定位。每次只展开当前层级，避免一次画出所有层级和角色。圈大小只用于排版，不代表实际地理面积。

角色只在已初始化的当前位置出现一次，初始地点不产生第二个头像。地点中的人数包含其下级地点，头像只在具体所在层级展开。未初始化、目录外位置和不存在的角色不会虚构成图中在场者；位置尚未读取时显示未知，不显示成零人。

这是沿已批准边界开放的地点作者视图。隐藏分支保留虚线与文字标识，进入隐藏父分支仍有提示；地点图不向聊天模型、角色知识或玩家事件投影增加权限，也不显示隐藏活动成果。

## 人物关系图

默认进入阵营分区的完整环形总览，人物沿圆环多排排列，曲线连接已确认相识。图形不再按十二人切页；没有连线的人物仍可出现，空世界保持真实空态。可按姓名搜索、按明确的直接阵营成员筛选；父子阵营不自动共享成员。

每个稳定 root 只画一次。多阵营成员按完整阵营路径的稳定顺序选择一个显示分区，其他归属在资料中列出；这不设置“主阵营”或写回世界状态。分区位置、曲线颜色和头像间距都是排版，不能推断实际地点或亲疏。

点选人物后，该头像进入中心，其他头像保持原有圆环位置，相关线突出。再选另一人打开底部双人资料面板；面板只显示双方已有资料、明确相识状态与已有阵营相识依据。无相识记录时保留未知，不画演示边，不补互评、剧情、关系类型或隐藏数值。可打开任一人物档案或把另一人设为中心，原有未保存资料选择保护继续生效。

绘图接口不可用或绘制抛出异常时，显示固定错误码并自动转为可读列表；用户可手动“重新绘图”。失败时停止头像裁切请求，列表仍保留姓名、阵营和资料入口。绘图失败不触发模型、网络重试或世界写入。

全局／个人都保留列表入口。个人列表只列已确认相识，列表主按钮沿原契约打开档案，另提供聚焦按钮；列表每页三十人。筛选后只画筛选内实际存在的边，删除人物后不保留其头像、焦点、双人面板或连线。

## 触摸、可访问性和成本

- 拖动平移、双指缩放，范围 100%–600%，提供缩放与复位按钮。拖动、捏合、取消和丢失捕获后不会误选人物。
- 小头像先放大分区或局部区域；密集单阵营不会因重复点选停在同一倍率。阵营按钮可直接放大分区，搜索结果可直接聚焦，放大后显示名字。
- 图上支持键盘左右选择、Enter／Space 聚焦，真实 HTML 搜索／阵营／名单按钮保留。双人原生 dialog 提供完整无障碍名称、焦点、取消／原生关闭及返回；关闭双人面板保留图中相机位置。原生关闭仅在弹层当前确实关闭时同步状态，忽略已重新打开后的过期关闭事件。
- 使用 Canvas2D 和确定性圆环坐标，无力导向、WebGL、持续粒子或闲时绘制循环。星点和选中柔光为静态；仅输入、数据或头像就绪时重绘。双人面板短过渡尊重 reduced-motion。
- 关系网基础样式适用于手机窄屏，不放在桌面宽度媒体规则中。按外层方形容器测量尺寸，Canvas 绝对定位铺满，不用自身像素缓冲参与布局。逻辑绘制宽度最高 720px、DPR 最高为 2，像素缓冲最高 1440×1440，仅在尺寸变化时重新分配。看不清的分区标签保留在图外按钮中，避免强行重叠。
- 只请求视口内达到可辨尺寸的头像；手势停止后再更新请求集合。关系页最多两张本地图片并发读取／裁切，输出 112px 正方形缩略图，及时关闭原始 bitmap。不可用图片保留姓名首字。
- 缩略图按摘要缓存，重复聚焦与缩放复用。非当前使用的缓存最多保留约 160 项；当前可见集合可超过该数，避免丢失人物。切换世界、可见性、页面或卸载时清理对应 URL。
- 地点图保持原来的 SVG 包含图，每页最多十二个地点／角色气泡，列表每页三十人，双指与位置唯一规则不变。关系图与地点图使用不同绘制策略。

## 复用依据与许可

复用已有 d3-hierarchy **3.1.2，ISC** 的 hierarchy／pack，来源为项目已安装依赖及 [D3 官方 Pack 文档](https://d3js.org/d3-hierarchy/pack)。它已用于 Windows 地点包含图，适合已有父子地点契约，无需新增图形框架。地点渲染和手势继续使用既有 React／TypeScript／SVG。关系网使用浏览器原生 Canvas2D、ImageBitmap 和 dialog，布局、裁切与交互由项目独立编写，不新增运行依赖或图形框架。

视觉结构参考[Cat Forest 原神关系网](https://ties.catforest.dev/genshin)，未使用其图片、语音、剧情数据或源码；数据始终来自本项目获准的 socialSnapshot。[MDN Canvas 优化](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas)作为缓存、限制重复绘制和图层成本的实现参考。

## 源码与验收

关系网入口为 ContactRelations.tsx、RelationshipAtlas.tsx、atlasLayout.ts、atlasPaint.ts、RelationPairSheet.tsx；atlasAvatars.ts 与 WorldContent.tsx 负责有界小图读取、缓存及清理。地点仍由 PlaceDiagram.tsx、DiagramCanvas.tsx 与 diagramLayout.ts 负责。

Diagrams.test.tsx、atlasLayout.test.tsx、atlasAvatars.test.tsx、atlasStyles.test.tsx 及 Contacts.test.tsx 覆盖相识边界、双人关闭、删除／筛选、选择保护、密集布局、小图并发／裁切／取消、手势、窄屏样式作用域、高 DPR 尺寸稳定和绘图失败回退。当前检查、本机包与用户验收只见[状态清单](PROJECT_STATUS.md)。

日常界面查验由用户从本机入口进入“通讯录 → 人物关系”完成；工程自动化只用隔离合成数据。DOM 与几何测试不代表真实 Canvas 绘制；隔离浏览器像素检查也不代表 Android WebView、实际触摸、vivo 性能或耗电验收通过。
