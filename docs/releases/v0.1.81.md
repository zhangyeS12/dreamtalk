# dreamtalk 0.1.81 · 校园示例与可靠性更新

第一次使用不必先找角色卡：在世界书架点击“体验校园示例”，预览并确认后即可创建“晴川高中 · 青春日常”。

- 包含简单高中世界书和三位同学：清纯文静的沈清禾、青梅竹马女同桌夏小满、形影不离的好兄弟周明远。可自行修改，不预设恋爱剧情；创建不调用模型或开启后台生成。
- 启动检查、核心连接和书架准备继续使用原开屏动画，减少白底检查页抢先出现。
- 修复完整快照恢复、异常模型配置修复和启动重试，补充API授权失败时的明确指引。
- 修复创建世界时玩家绑定的并发锁冲突；完善普通退出的收尾等待，减少Core尚未结束就被强制停止。
- 补齐跨平台CI、原生窗口及完整载荷检查；发布构建必须有同一完整提交的成功CI记录。更新既有source-map-js补丁版本。

提供完整Windows x64安装包、便携ZIP及应用内原更新频道。已有用户可在应用中检查更新。存档位置、应用标识和更新公钥保持；更新不会自动重发旧模型任务。请勿使用旧程序打开已经升级的存档。

仍为预发布体验版。隔离自动检查不代替真实更新、存档恢复和模型效果验收；免费云端最新版及付费配音API仍待确认。安装包不含本地配音／视觉模型权重。当前更新包有完整性签名，Windows发布者证书仍在申请中，首次安装可能显示未知发布者。
