# 世界自动活动体验说明

本版实现已获批准的 Director 批量规划与基础角色日常。它还不是完整自主世界。

1. 关闭旧窗口，打开本包 dreamtalk-desktop.exe。旧数据会按原流程增量升级到当前版本；请勿再用旧程序打开已升级存档。
2. 在当前世界选择自己的身份；通讯录选择要参与的角色。打开聊天不会设置物理地点；保存初始位置时会创建／复用稳定角色身份。
3. 通讯录 → 角色资料 → 初始地点与移动倾向，选择常驻中心并保存。地点管理在角色卡管理下方；可多层包含、隐藏分支逐角色开放、锁定初始地点。设置不调用模型，不移动玩家；改初始地点／锁定会通过Kernel放置或返回。
4. 设置 → 世界自动活动 → 开启 → 首次确认后台模型用量。若此前因无可规划角色停止，设置地点后显式点击“重新规划”；该操作是新的模型任务。采用当前已配置模型，各提供商使用同一治理。
5. 等待规划状态完成。角色可以开始休息、工作或自由活动；已有多个地点时可移动。只有“家”时可先选择家作为初始地点，不虚构新地点。
6. 查看聊天中的世界事件：只显示自己实际获知的变化。点已有“聊聊这件事”自行发送，或问角色近况；角色只参考自己的亲历记录，开始活动不保证任务成果。

每批6小时世界时间；少数偏差取消对应候选，至少2条且达原批50%失效才提前续批。输出上限为模型cap与8192的较小值，独立于每轮聊天额度，仍服从既有硬Token/金额预算。规划失败/空输出/重启遗留不会自动付费重放；“重新规划”明确开启新任务。

每世界默认关闭。暂停后不执行候选或开始新批；已发给模型的请求可能仍产生费用。关闭自动活动阻止新的规划/活动，已开始的活动仍会自然到期并记录结束；已提交事件保留，迟到模型结果不会重新启用。彻底退出应用时没有AI后台进程；可以另行设置关闭窗口到托盘，后台Core仍会运行。返回时不补造已经错过的活动：尚在有效时段的候选可按当前时间开始，已过结束时刻的候选expire；旧窗口外不生成未规划的历史。

当前容量：最多16名已放置角色、32个地点、64候选/批，必要输入64KiB；超出时明确提示并停止，不静默漏掉角色。输入含已接受角色卡的描述/性格/背景、同世界位置及当前世界已公开的世界书背景；不含隐藏条目、私聊、摘要或私人记忆。世界书按来源常驻/字面关键词条件选择，关键词匹配角色名和各自当前地点名；明确限制生成类型时需允许quiet后台生成。共享聊天已有最多16条、title/content共12KiB背景上限，规划读取最多512条公开启用条目、每条关键词/条件16KiB，超限提示且不派发模型。未来计划没有普通UI浏览入口。

日常事件记录开始、时段结束和中断及可选位置变化；结束由Kernel记入事件与获准亲历记录，不宣称完成了工作或取得成果。单角色离线问候/邀请已作为独立开关接入，见[离线消息](OFFLINE_MESSAGES.md)。短暂相遇、共同休闲与同事由双人主动联系已有实现，见[主动联系](PROACTIVE_CONTACT.md)。地点层级编辑和范围／隐藏／锁定已在0.1.41实现；广泛剧情／关系演化和完整离线活动重建仍未实现。

本轮只做源码复核、Ruff/ESLint/TypeScript和编译打包，没有运行测试、迁移、应用或真实API。实际开启、计划质量、事件与知情隔离、暂停/关闭/恢复仍请按你的体验验收。


## 公共背景参与日常规划（本版新增）

在“书架 → 管理 / 导入世界书”保存世界书，并把希望日常规划参考的条目逐条设为公共背景。常驻背景无需关键词；普通关键词可使用角色名或其当前地点名。条目详情同时显示聊天与日常规划的参与条件，未支持来源条件不会猜测为可用。用户已具体授权这一数据范围发往当前配置模型；首次开启自动活动时也说明数据范围和后台用量。

公开/隐藏或更新内容不会另行触发模型调用，新资料等下一次正常批量规划。若本批选入背景在开始模型任务前或返回计划时已经隐藏/更新，则停止并提示，返回计划不接纳，绝不自动重放。已经开始的请求可能产生用量；已经提交的真实活动保留，已经接受的批次不会因后来的背景编辑重写历史。旧版无背景字段的计划可继续按原窗口处理，无新增迁移。

建议先用简短常驻公共条目体验，在通讯录明确设置角色初始地点，再开启自动活动观察实际亲历事件。模型有机会选择更符合设定的活动，但本版动作仍只有休息、工作、自由活动及已有地点移动，不创建背景中提到的新地点或宣称完成任务。公共条目不能因此授予私人知识，计划未执行前仍不是已发生事实。功能与隔离验收由用户完成，工程端不运行应用、测试或真实API。


## 常驻中心与移动倾向（0.1.44）

初始地点不再限制子树。角色可直接到父或兄弟地点，地点编辑增加地区标记，角色资料提供三档常驻倾向。普通强倾向为70/25/5类别权重；跨地区另有1%机会，至少24小时WorldTime才判定一次，返回地区后冷却7天。路线含返程，模型不得为相遇改路线。配置及隐藏／锁定变化在派发、接纳和Kernel执行复核，改变的迟到计划提示后不自动付费重放。门禁与计划持久保存，实际位置仍由Kernel权威；[完整说明](ACTIVITY_LOCATIONS.md)。

## 添加活动地点

现在可以在“通讯录 → 添加／编辑地点”管理场所与父子层级、隐藏分支和开放角色，在角色资料配置常驻中心／移动倾向／锁定，并在“地点”页查看作者配置图和实际位置。保存不调用模型；下一常规批次先按常驻倾向、地区和距离确定路线，再由模型安排日常，执行时再次核验最新规则；父子地点不算相遇同场。不会移动玩家。背景描述仍在世界书填写并逐条确认公共；详细操作见[活动地点](ACTIVITY_LOCATIONS.md)。


## 程序开关与离线时间

当前自动活动运行在本地Core中：电脑开机、应用未退出、世界未暂停并且自动活动已开启时执行；可以把窗口最小化或切换到其他页面。退出应用、关机或进入系统睡眠后不持续执行AI活动。它不是云端常驻服务。

重开时，未暂停世界按离线经过时间和倍率推进WorldTime；暂停世界不补进暂停时长。已有计划只在仍有效的时段按当前时间启动，已过时的候选过期，旧窗口耗尽按已有规则继续规划；不完整重建关机期间的生活、亲历事件或成果。已经中断的模型请求不自动重放，需手动处理；已发出的请求可能已经产生费用。

单角色离线主动私聊已实现独立默认关闭的入口：满足真实离线时长且有合适理由，恢复后最多一条；同理由去重、未回复抑制、Busy/暂停取消。详见[离线消息](OFFLINE_MESSAGES.md)。自动活动开启不自动开启联系；在线及同事由双人首版已接入；三人以上/任意Episode与完整离线世界重建仍未实现。

## 在聊天中问角色正在做什么（桌面0.1.3）

打开已设置初始地点的角色私聊，按原有授权开启世界自动活动，等待实际活动开始后，可以问“你在忙什么？”或“刚才做了什么？”。私聊与群聊回复会参考发言角色自己的真实活动记录，并区分当前原定时段与过去的开始。没有记录时不能保证角色有日常经历；本功能不为了回答问题额外规划或调用模型。

活动时段结束不表示任务完成；不能据此认定工作成果、收入、物品或关系变化。聊天和提及活动也不会移动玩家，或把玩家登记为事件目击者。隐藏活动仍不直接列到普通事件页面。真实活动结束/中断、短暂相遇与长期聊天记忆已接入；活动终态不等于任务成果，详见当前状态清单。

## 自己的活动与目击他人（桌面0.1.4）

角色回复的资料现在明确区分“我做过”和“我看到别人做过”，并提供本人休息/工作/自由活动类型。可以分别在私聊和群聊询问“你在做什么”“你刚才在休息还是工作？”；回答应对应发言角色自己的真实活动。角色卡改名或与别的角色同名，不会改变事件主体的对应关系。

没有对应自身活动、只有他人活动或原定时段已过时，不应编造自己的当前任务或完成成果。此版增强资料与生成规则，没有新增付费核对模型；语言模型仍可能出错，请核对实际台词。角色日常活动需要已有初始地点和独立开启的自动活动。


## 近期经历进入聊天（桌面0.1.7）

当前聊天读取该角色对应的活动开始及实际终止状态，同时提供最多6条本人亲历的近期移动与活动。Kernel在到期或状态被合法放置改变时一次记录结束/中断；这不证明任务成果，不把后台历史全部公开给玩家。暂停/恢复与重启沿用世界时间，不按现实时间补造。详见[长期记忆与近期经历](LONG_TERM_MEMORY.md)。

## 桌面0.1.24经历召回

已有授权亲历现在可按当前话题检索，保留近期并补最多4条旧相关项，最终仍12条/8KiB；仅近128条词法召回，无额外API、事件/知识写入或自动Observation→EpisodicMemory。当前活动快照保持优先，目击不等于相遇剧情。见[体验说明](EXPERIENCE_RECALL.md)。真实模型效果待用户验收。

## 0.1.25短暂相遇

[角色相遇](CHARACTER_ENCOUNTERS.md)默认关闭，开启后在同一日常批次附带有限候选；只有真实休息/自由活动同地点才记录双方碰面，迟到不补演，关闭取消待执行项。普通界面不会展示未知后台计划。配置采用独立授权revision，不使已有日常失效，不改变原半批失效规则，不增加逐相遇API。

## 0.1.26相遇节奏

用户接受后，将相遇schema及Kernel每plan_id成功上限从8降到2，允许0次。每角色滚动24小时WorldTime最多一位首次实际记录的见面对象，老对象重逢仍遵循同场去重与6小时pair冷却；持续同地换活动不再重复普通问候，真实离开才结束该段。额度/去重不满足只取消相遇、不影响日常失效比例、不补选或额外重规划。旧候选也受新准入限制，旧事实不撤销。没有新迁移或逐相遇API，详见[相遇说明](CHARACTER_ENCOUNTERS.md)。
