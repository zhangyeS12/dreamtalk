# 世界内的观星室界面

当前Desktop **0.1.40**（2026-10-07）继承0.1.37观星室，按截图反馈扩大通讯录主区。观星室原切片日期2026-10-05。用户不满意0.1.36，要求结合原日月星轨Logo继续重构启动、聊天、通讯录等界面。当前实现采用墨蓝空间、月白正文、银蓝辅助信息与暖金主操作；覆盖原浅色纸面设计。原四入口和业务流程保持。研究见[成品与复用](research/2026-10-05-observatory-design.md)。

## 页面结构

- 页头：原Logo、当前世界名、已读取的真实世界时间/暂停或异常状态，以及返回书架。没有虚构在线人数、活动或统计。
- 底部：聊天/通讯录/设置/我，收拢为窗口底部居中的四入口导航。窄窗口仍保持这个顺序和文字，红点仍显示真实未读。
- 聊天：取消重复可见页标题，左侧收拢为会话目录，右侧为完整阅读面。名字筛选仅处理当前已加载角色/群成员；世界事件始终置顶；新建群聊在目录顶部。原会话选择、消息权限、历史排序、滚动锚点和已读逻辑保持。
- 对话：圆形头像、日期细分隔、较低对比的辅助元信息与大段正文；玩家消息用银蓝底区分。输入框为底部独立写作区，费用、失败、恢复及模型状态保留在相关位置。刷新记录和原生会话工具保留键盘入口。
- 通讯录：0.1.40按截图反馈隐藏重复页标题、移除重复世界／角色说明和添加按钮，收拢为可展开的角色卡管理入口；桌面名单220px、主区更靠上靠左，缩小头像及留白、减少资料内边距，阵营编辑不再套65vh内部滚动。名字筛选、姓名、真实阵营、打开会话、草稿／生成／导入与三维关系网保留；窄窗口继续原响应式结构。此变化待用户体验。
- 设置与“我”：保留七类手册与通用/世界身份草稿，用暗色目录和连续正文区组织；所有保存、只读刷新、首次费用授权和错误状态保持。
- 世界事件与来源弹窗：统一暗色主题，保留原句、时间、来源和权限提示；红/绿/灰经历标记保留颜色及文字语义。

空白会话与未选角色页面使用原Logo及静态几何星轨，不放示例角色或假消息；世界内没有持续背景粒子和装饰循环动画。书架沿原布局，三维关系网继续按需加载与释放。

## 实现与边界

`world-terminal.css`替换0.1.36样式层，变量限定`.world-workspace`。`WorkspacePrimitives.tsx`提供小型线性图标、目录搜索和空态；`ProductApp.tsx`与`WorldContent.tsx`接入已授权的现有数据。没有新依赖、存储、迁移或API，没有扩大知识、生成和费用范围。原Logo文件未编辑。

动态只用于控件状态过渡；减少动态效果关闭过渡。启动独立遵循[启动说明](CELESTIAL_STARTUP.md)。正文15px、辅助12～13px为主，长正文限制阅读行宽；原生表单、details和dialog继续承担键盘行为。

## 检查与用户验收

0.1.37原轮ESLint/TypeScript与两份CSS解析通过（世界内346条规则、启动40条），10组代表性不透明配色计算最低5.60:1；该数值不是全页面渲染对比度认证。0.1.40本轮ESLint／TypeScript与世界内349条CSS规则解析通过，未重新测量渲染对比度。便携构建与交付结果见[交接第6节](../HANDOFF.md#6-交付与证据)。未运行浏览器／桌面smoke、自动测试、模型或真实存档。

用户验收重点：

1. 私聊/群聊的长消息、流式、分页、滚动、发送、已读红点、人工恢复和费用提示。
2. 会话/角色名字筛选、清除、无匹配结果；群聊创建和世界事件入口。
3. 头像上传后回聊天、长姓名/阵营标签、图内选人、三维关系网及切页释放。
4. 设置/个人身份编辑后切页，确认草稿、保存结果、后台费用和错误提示完整可见。
5. 700px以下窗口、较矮窗口、系统缩放与减少动态效果；固定导航及写作区不遮挡必要操作。

这些是待用户验收项，不表示工程端已执行或已通过运行验证。
