# dreamtalk 0.1.82 · 五个存档位置与可靠性更新

- 书架“检查更新”旁新增“存档”入口。选择专用文件夹后，提供一个自动存档和四个手动位置，支持命名、保存时间、替换与导出。
- 每次启动保存一次自动档。手动位置可保存当前全部世界、角色卡、世界书、身份、记忆、聊天和关联素材，也可把原自动档另存下来。
- 选择文件或填写完整路径即可导入，导入只显示在所选位置，不立即加载。加载前会提醒：全部数据将切换到所选存档，自动档也随之覆盖；需要保留原自动档时，请先另存到手动位置。
- 普通界面移除清空本机原始数据的入口。日常内容仍即时保存，更新保护快照独立保留，不占用四个手动位置。
- 完善存档校验、中断恢复和他人配置隔离。API密钥、模型程序路径及费用保护沿用本机规则，旧生成任务不会自动重发。
- 改善启动失败提示和更新检查：失败时保留原数据，更新入口不会被开屏遮挡，网络检查失败不会冒充“已是最新版”。
- 表情读取失败可手动重读；重新配音失败明确保留原配音，可选媒体的诊断写盘失败不再阻断正常文字回复。

提供完整Windows x64安装包、便携ZIP及原应用内更新频道。已有0.1.81用户可通过“检查更新”升级；应用标识、当前数据位置和更新公钥保持不变，不需要先恢复或清空存档。

仍为预发布体验版。发布构建与隔离检查不等同真实升级、掉电恢复或模型效果验收。请在实际使用后反馈更新与存档体验；不要为测试而用旧程序打开新版本已经使用的存档。安装包不包含本地配音／视觉模型权重，当前更新签名也不等同Windows发布者证书。
