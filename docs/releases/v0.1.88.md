# dreamtalk 0.1.88 · 消息候选、聊天分支与高级世界书

- 私聊和群聊消息新增“消息操作”：编辑正文、创建另一份候选回复、从此分支、保存检查点。编辑保留原文及旧路线，不会覆盖已经保存的历史。
- “会话工具 → 分支、检查点与候选”可选择、命名和查看已有路线。检查点保存固定记录，从检查点建立分支后可继续聊天；路线列表显示创建时间，打开较早消息的操作时会定位到预览面板。
- 候选回复在预览、确认后才生成，可能产生模型费用；群聊重新生成整轮，并继续使用该次尝试共享的输入＋输出硬额度。切换已有候选不调用模型，失败或结果不确定时不会自动重发模型请求。
- 消息历史、记忆、摘要、聊天获知事件、检索与导出按所选路线读取。聊天分支不回退世界时间、实际位置、权威事件、关系或费用。
- 世界书条目新增“高级触发与插入位置”：概率、递归、按消息数持续／冷却／延迟、互斥组优先选择及历史插入深度。递归仍先经过公开授权过滤；持续／冷却跟随当前路线，只有实际保留在通过容量检查的请求中的条目才开始计时。

提供完整Windows x64安装包、便携ZIP与原应用内更新频道。沿用原应用标识、更新公钥和数据位置，不需要清空数据。新结构由迁移自动创建，原消息与旧路线保留。

仍为预发布体验版。功能实现阶段已获准进行合成数据库、模拟服务与内存界面的隔离检查；本次发行只做静态检查、编译、载荷／签名和下载摘要核对，不运行CI、应用、安装器或真实模型，不接触真实存档。真实升级、旧用户库迁移、长期使用和实际模型效果仍待用户验收。

高级世界书不是完整酒馆行为复刻；正则／模板关键词、向量触发、脚本、插件和其他插入模式不在本次执行范围。世界时间线分支与合并也不在本次更新范围。
