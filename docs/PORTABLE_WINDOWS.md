# dreamtalk · Windows 安装与使用

dreamtalk 帮你创建世界、管理角色和背景，与角色聊天、积累记忆，并按需开启活动与主动联系。当前发布版本为 0.1.53，仍是体验版。

## 下载和安装

前往 [0.1.53 下载页](https://github.com/zhangyeS12/dreamtalk/releases/tag/v0.1.53)。

- 推荐使用 dreamtalk_0.1.53_x64-setup.exe，按提示安装。
- 便携版选择 dreamtalk-0.1.53-windows-x64.zip，完整解压到固定目录，再打开 dreamtalk 文件夹里的 dreamtalk-desktop.exe。不要只复制 EXE 或在压缩包内直接运行。
- Source code 是源码，不是安装包。

支持 Windows 10 / 11 的 64 位系统。若缺少显示组件，安装 [Microsoft WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)。不用另外安装开发工具。

更新包有完整性签名，但还没有 Windows 发布者证书，首次安装可能提示未知发布者。下载页附 SHA256SUMS.txt 供核对，请不要关闭系统安全防护。

## 第一次使用

1. 在书架右上角“模型设置”填写自己的服务商、模型名称、地址和 API 密钥。应用不附共享密钥，服务商可能收费。
2. 点击空白书创建世界；在所选世界管理中创建或导入世界书，逐条确认希望公开使用的背景。
3. 进入世界，在“我”中填写称呼和身份并确认进入。
4. 在“通讯录”添加或导入角色卡，每位角色选择初始地点；可以先添加地点，再确认角色资料。
5. 打开角色会话即可聊天，也可以创建固定成员群聊。Enter 发送，Shift + Enter 换行。

各世界可保存独立模型，未设置的世界继承书架默认。自动活动、相遇、共同休闲、世界动态和主动联系默认关闭，开启前阅读各页的费用与条件说明。普通聊天不会遇到未知知识就自动联网搜索。

详细功能与所有选项见[项目主页](https://github.com/zhangyeS12/dreamtalk)和[设置手册](SETTINGS_HANDBOOK.md)。

## 更新已有版本

启动有新版本时可查看说明，选择“稍后”或“更新”。勾选“不再自动弹窗”后，书架仍保留“新更新”入口。

更新在确认后才下载，保留世界和聊天，并尝试更新已启用的自启动与对应快捷方式，清理此次更新管理的旧程序。其他目录的手动副本或下载压缩包不会被扫描删除。失败时保留恢复材料并提示处理。

没有更新器的旧版先从托盘“退出并停止后台运行”，再手动安装完整新版；仅关闭窗口可能仍在运行旧程序。便携版手动换目录后，在新版“设置 → 后台运行”点击“保存并更新启动位置”。

0.1.46 / 0.1.47 若因旧清单问题拒绝更新，请看[更新修复说明](WINDOWS_UPDATES.md)。不要用旧程序打开已经升级的同一存档。

## 数据、导出和删除

数据保存在本机用户目录，不在便携程序文件夹中。Windows 默认数据位置为 %APPDATA%/app.livingworld.desktop；重要数据可在应用完全退出后保留完整副本，避免只复制正在写入的单个数据库文件。

角色卡可导出 V2 / V3 JSON，世界书可导出 World Info JSON，聊天可导出 TXT / JSON。导出不调用模型，角色 JSON 不打包头像，世界书包含隐藏条目。资料导出不是完整世界备份，目前没有聊天导入或整个运行世界的一键恢复。

解散群聊保留记忆与来源；删除角色保留历史、相关会话只读；删除世界会永久清除该世界的所有资料、聊天和记忆，书位恢复空白。请仔细阅读确认提示。

## 运行与反馈

托盘中继续运行时，已开启的后台功能可以工作。彻底退出、关机或睡眠后不会继续调用模型，也不会补造未发生的完整生活。

0.1.53 完成源码、格式、类型及编译打包核对；应用运行、老存档升级、实际聊天和自动更新效果仍需用户体验验收。

通过 [GitHub Issues](https://github.com/zhangyeS12/dreamtalk/issues) 提供版本、操作步骤、预期与实际表现，分享截图前遮住密钥和私人聊天。源码采用 [Apache-2.0](../LICENSE)，第三方许可在随包 third-party-licenses 和 docs/licenses 中。
