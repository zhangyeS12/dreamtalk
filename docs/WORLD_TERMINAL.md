# 世界内的天幕界面

进入世界后，整个窗口就是这个世界的天空：天色、太阳或月亮、星星、云和远山铺满背景，界面以半透明玻璃面板浮在其上。方向由用户于2026-10-28在[概念稿](product/world-sky-concept.html)基础上确认；历史版本与验收证据见[状态清单](PROJECT_STATUS.md)。

## 页面结构

- 天空与标题：背景天色、日月位置与星光只由已读取的 `world_time` 计算（`apps/web/src/world/sky.ts`、`WorldScene.tsx`），暂停时云和星光停住并降低饱和度；世界名以大字写在天空上，下方为真实世界时间与时段（深夜／黎明／清晨／白昼／黄昏／入夜）、暂停／运行异常状态，右侧为普通／沉浸切换（仅聊天页）和返回书架。没有虚构天气、在线人数、活动或统计。
- 导航：聊天/通讯录/设置/我四入口位于左侧玻璃导航条，图标下方显示文字，当前入口图标为日金色；860px以下改为底部横排，顺序不变。红点仍显示真实未读；沉浸模式隐藏导航。
- 聊天：左侧玻璃会话目录（世界事件始终置顶、名字筛选、置顶星标、未读红点、群聊叠放头像），右侧玻璃对话面。每位角色有由身份派生的固定专属色，只用于头像底色、名字和台词旁细线，不表达关系或状态；同一群内颜色冲突时就近错开。用户上传的角色背景铺在对话面玻璃之下。
- 对话：角色回复按剧本排版，名字与时刻在左侧页边，旁白偏暗、引号台词偏亮；玩家消息为右侧月白小气泡。编辑、候选、反馈、参考内容和配音等单条操作在悬停或键盘聚焦时出现。输入区为悬浮胶囊，表情、正文与日金发送键同一行，模型状态、失败、恢复与费用提示保留在胶囊上方。沉浸模式下会话目录退场，对话移到左侧，用户上传的角色立绘站在右侧并被天色勾出轮廓；没有立绘时不显示占位图。
- 通讯录沿用可展开的角色卡管理入口；名字筛选、真实阵营、打开会话、草稿／生成／导入与三维关系网保留，窄窗口继续响应式结构。具体布局验收见[状态清单](PROJECT_STATUS.md)。
- 设置与“我”：保留七类手册与通用/世界身份草稿，用暗色目录和连续正文区组织；所有保存、只读刷新、首次费用授权和错误状态保持。
- 世界事件与来源弹窗：统一暗色主题，保留原句、时间、来源和权限提示；红/绿/灰经历标记保留颜色及文字语义。

空白会话与未选角色页面使用原Logo及静态几何星轨，不放示例角色或假消息；世界内没有持续背景粒子和装饰循环动画。书架沿原布局，三维关系网继续按需加载与释放。

## 实现与边界

世界内外壳（天幕、导航、提示）位于`apps/web/src/world/`，使用CSS Modules与`tokens.css`，不新增依赖；页面内部仍在逐步迁移。`world-terminal.css`替换0.1.36样式层，变量限定`.world-workspace`。`WorkspacePrimitives.tsx`提供小型线性图标、目录搜索和空态；`ProductApp.tsx`与`WorldContent.tsx`接入已授权的现有数据。没有新依赖、存储、迁移或API，没有扩大知识、生成和费用范围。原Logo文件未编辑。

动态只用于控件状态过渡；减少动态效果关闭过渡。启动独立遵循[启动说明](CELESTIAL_STARTUP.md)。正文15px、辅助12～13px为主，长正文限制阅读行宽；原生表单、details和dialog继续承担键盘行为。

## 检查与用户验收

0.1.37原轮ESLint/TypeScript与两份CSS解析通过（世界内346条规则、启动40条），10组代表性不透明配色计算最低5.60:1；该数值不是全页面渲染对比度认证。0.1.40本轮ESLint／TypeScript与世界内349条CSS规则解析通过，未重新测量渲染对比度。便携构建与交付结果见[交接第6节](https://github.com/zhangyeS12/dreamtalk/blob/485b512a5dac8da7077326d1cd3daea5eb3304c8/HANDOFF.md#6-交付与证据)。未运行浏览器／桌面smoke、自动测试、模型或真实存档。

用户验收重点：

1. 私聊/群聊的长消息、流式、分页、滚动、发送、已读红点、人工恢复和费用提示。
2. 会话/角色名字筛选、清除、无匹配结果；群聊创建和世界事件入口。
3. 头像上传后回聊天、长姓名/阵营标签、图内选人、三维关系网及切页释放。
4. 设置/个人身份编辑后切页，确认草稿、保存结果、后台费用和错误提示完整可见。
5. 700px以下窗口、较矮窗口、系统缩放与减少动态效果；固定导航及写作区不遮挡必要操作。

这些是待用户验收项，不表示工程端已执行或已通过运行验证。
