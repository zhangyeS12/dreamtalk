# dreamtalk 0.2.0 · 前端焕新：从书架走进世界

这是 dreamtalk 的前端里程碑更新：书架、启动、世界内界面与聊天工作区采用统一视觉和交互。原准备中的0.1.93未独立发行，其改动合并进入本版。

## 全新的世界入口

- “夜读”启动动画：台灯下的书自己翻开，纸艺星空、新月与山脊从书页间立起，书架就绪后镜头进入天空。减少动态效果或无法建立WebGL时使用静态标识。
- 环形世界书架：悬停轻抽、点击完全抽出，按住拖动可360度查看；窗外天色对应上次进入世界的世界时间。
- “设计这本书”：模板、材质、颜色、厚度、书名排版、正面／书脊／背面图片、贴纸、天窗与可关闭的标识。旧封面沿现有记录转换；只设置书脊或背面图片也能正确显示。
- 书架支持键盘与读屏操作，设计画布可用方向键微调书名、贴纸和天窗。

## 走进世界后的界面

- 世界时间驱动天空、日月、星星、云和远山，聊天、通讯录、设置和“我”浮在玻璃面板上；暂停、隐藏和空闲状态沿现有规则减少动画。
- 角色回复采用剧本式排版，名字与时刻在左侧，旁白与引号台词区分；每位角色保留由身份派生的专属颜色。
- 当前世界通用／角色专属聊天背景、角色表情立绘与普通／沉浸切换；仅使用用户已上传素材，没有立绘时显示背景。
- 私聊与群聊合并排序，按置顶、未读和最近活动排列。回复赞踩作为有界风格参考，不改写角色卡、记忆或世界事实。
- 聊天记录和会话目录独立滚动，长记录不再带动整页；进入会话定位最新已加载消息，上翻和加载更早记录保留位置，已读只确认真实可见消息。

## 数据、兼容与交接

- 从公开0.1.92升级，沿既有Alembic链新增0060会话偏好和0061聊天视觉；不重写旧消息或财务回执。应用标识、存档位置、更新公钥与频道保持不变。
- 书本设计沿原封面记录保存。升级后不要再用旧程序打开已升级的同一存档；应用内更新与五位置存档继续使用既有保护流程。
- 同步整理现行手册、架构契约和AI交接入口，修正旧检索／协议／迁移／发行描述；历史记录保留原日期与证据范围。
